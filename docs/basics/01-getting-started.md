学完本篇，你将能够：

## 2. 基础概念

**工作簿与工作表**：一个 Excel 文件就是一个工作簿（Workbook），扩展名通常是 `.xlsx`；工作簿里可以放多张工作表（Worksheet），底部的工作表标签就是各张表的入口。日常说的"打开一张表"，多数时候是指打开一个工作簿里的一张工作表。

**功能区（Ribbon）**：窗口顶部的带状工具栏，由"选项卡＋命令组"构成。"开始"选项卡放最常用的字体、对齐、数字格式；"插入"放图表、数据透视表；"公式"放函数库；"数据"放排序、筛选、分列、获取数据。找不到某个命令时，先想它属于哪类操作，再去对应选项卡找，比满屏乱点快得多。

**单元格与名称框**：行列交叉处就是单元格，用列字母＋行号定位，如 `B3` 表示 B 列第 3 行。左上角的名称框显示当前选中单元格的地址，直接输入 `D20` 回车即可跳转到 D20；输入 `B2:B10` 回车可一次选中一个区域。

**文件格式**：`.xlsx` 是不含宏的常规工作簿；`.xlsm` 是启用宏的工作簿，含 VBA 代码时必须存为此格式，否则宏会被丢弃；`.xls` 是 2003 及更早版本的旧格式，功能受限，新文件不要用它；`.csv` 只有纯文本数据，无格式、无公式、无多表，导出给其他系统时常用。

**视图与窗口**：普通视图是日常编辑视图；页面布局视图按打印效果显示，能看到页边距与页眉页脚；分页预览用蓝色虚线标出打印分页，调打印区域时用它最直观。冻结窗格（视图→冻结窗格）可以把标题行固定在屏幕上方，滚动大表时标题不跑丢。

## 3. 操作步骤

1. 打开 Excel：开始屏幕选"空白工作簿"，或按 `Ctrl + N` 新建一个空白工作簿。
2. 认识界面：顶部是功能区，左上角是名称框，底部是工作表标签，右侧与底部是滚动条；选中任一单元格，看名称框显示它的地址。
3. 保存文件：按 `Ctrl + S`，第一次保存会弹出对话框，选位置、起名字、确认格式为"Excel 工作簿（*.xlsx）"后保存；此后每改动一次就按一次 `Ctrl + S`。
4. 管理工作表：右键底部工作表标签可重命名、移动、复制、隐藏、删除；点标签右侧的 `+` 号新建一张工作表；双击标签可直接改名。
5. 切换视图：视图选项卡里点"页面布局"看打印效果，点"分页预览"看分页线，点"普通"回到编辑视图；用"视图→冻结窗格→冻结首行"把标题行固定。
6. 关闭前检查：确认标题栏没有星号（未保存标记）或已按 `Ctrl + S`；含公式的工作簿关闭时如弹出"是否保存"，点"保存"。

## 4. 图文示例

新建一个"一周开支记录"工作簿练手：A1 输入"日期"，B1 输入"项目"，C1 输入"金额"；A2:A4 依次输入 11 月 2 日、11 月 3 日、11 月 4 日，B2:B4 输入"午餐"、"交通"、"文具"，C2:C4 输入 28、15、36。选中 C2:C4，在开始选项卡把数字格式设为"货币"；把工作表标签重命名为"开支"，再点 `+` 新建一张表改名"汇总"；最后 `Ctrl + S` 存为"开支记录.xlsx"。

## 5. 公式和代码

```excel
=SUM(C2:C4) → 79
=AVERAGE(C2:C4) → 26.33
=MAX(C2:C4) → 36
```

- `=SUM(C2:C4)` → 79：C2:C4 求和：28+15+36=79，本周三天开支合计
- `=AVERAGE(C2:C4)` → 26.33：三天日均开支 79÷3≈26.33（保留两位小数）
- `=MAX(C2:C4)` → 36：单笔最大开支是文具 36 元

## 6. 实际工作场景

### 新人第一天：接手同事的报表

同事发来一个工作簿，底部有 5 张表。先别急着改：点每张表看标题行（冻结窗格帮你定位），用 `Ctrl + End` 跳到每张表的已用区域右下角，确认数据范围；再用名称框跳到关键单元格核对。看懂结构再动手，比直接改少踩一半坑。

### 月度报表：每月新建一张表

每月一张表的做法是：右键上月工作表→"移动或复制"→勾选"建立副本"，再把副本改名为本月（如"11 月"），清空旧数据保留格式与公式。这样表结构与汇总公式每月一致，汇总表用跨表引用（如 `='11月'!C10`）一次取数。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 保存后公式没了 | 存成了 .csv 或旧 .xls 格式 | 另存为时选"Excel 工作簿（*.xlsx）"；需要宏才用 .xlsm |
| 找不到某个命令 | 在错误的选项卡里找 | 先定性：格式类去"开始"，函数类去"公式"，数据类去"数据"；再用左上角搜索框搜命令名 |
| 滚动后标题行看不见 | 没有冻结窗格 | 选中标题行下一行，视图→冻结窗格→冻结拆分窗格 |
| 工作表标签找不到了 | 工作表被隐藏 | 右键任一标签→取消隐藏，勾选要恢复的表 |

## 9. 练习题

1. 新建一个工作簿，把 Sheet1 改名为"练习"，再新建一张表改名为"备份"，保存为 .xlsx 格式。名称框输入 D20 会跳到哪里？
2. A1:A5 依次是 10、20、30、40、50，用公式求和与求平均，结果分别是多少？
3. 同事发来的文件是 .csv，打开后发现数字格式与多张表都没了，为什么？
