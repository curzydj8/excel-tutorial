# 单元格与区域操作：选定、行列、合并与名称框

- **所属栏目**：C01 入门基础 ／ C01-L2-3 单元格与区域操作
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：入门
- **预计阅读时长**：15 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 用鼠标与键盘快速选定连续区域、不连续区域、整行整列与全表
- 插入、删除、隐藏、调整行高列宽，并理解删除行对公式引用的影响
- 正确使用合并单元格，知道它会带来哪些排序与引用问题
- 用名称框与定位功能在几千行的大表里瞬间跳转

## 2. 基础概念

**区域（Range）**：一组连续单元格，用左上角:右下角表示，如 `B2:D10`。多数操作（求和、排序、复制）都是以区域为单位进行的；先选对区域，再执行操作，是 Excel 操作的第一性原理。

**选定技巧**：点列标选整列、点行号选整行；`Ctrl + A` 在数据区按一次选当前连续区域，按两次选全表；`Ctrl + Shift + 方向键` 扩展到数据边缘，是选中整列数据的神器；`Ctrl + 点击` 加选不连续区域；`Ctrl + Shift + *`（数字 8 上档键）选中当前数据区域。

**行列操作**：右键行号/列标可插入、删除、隐藏行列。插入行会把公式引用自动下移（引用跟着数据走），删除行则可能让引用该行的公式变成 `#REF!`——删行前先检查有没有公式引用它。

**合并单元格**：开始→合并后居中。合并后只有左上角单元格保留内容，其余格的内容会被丢弃；合并过的区域不能直接排序、不能用填充柄、透视表也不认它。标题行合并一次尚可，数据区不要合并。

**名称框跳转**：名称框输入地址回车即跳转；输入区域如 `B2:D100` 回车即选中该区域；输入已定义名称（如"销售数据"）可跳到命名区域。配合 `Ctrl + End`（已用区域右下角）与 `Ctrl + Home`（回 A1），大表导航不用滚轮。

## 3. 操作步骤

1. 选中整列数据：点任意数据格，按 `Ctrl + Shift + ↓` 选中从该格到数据底端；再按 `Ctrl + Shift + →` 可扩展到多列。
2. 插入一行：在行号上右键→插入；插入一列：在列标上右键→插入列；一次插多行：先选中多行行号再右键插入。
3. 调整列宽：双击列标右边界自动按内容适配宽度；拖动边界手动调；选中多列后拖动其中一列边界可等宽批量调。
4. 合并标题：选中标题行区域（如 A1:F1），开始→合并后居中；取消合并用同一按钮再次点击，或右键→取消合并单元格。
5. 隐藏与取消隐藏：选中行/列右键→隐藏；取消隐藏时先选中跨越隐藏区的行/列再右键→取消隐藏。
6. 跳转检查：按 `Ctrl + End` 看数据实际用到哪一行哪一列，发现远超预期的"幽灵区域"（如到了 XFD1048576）说明有残留格式，用定位条件选常量清理或删除多余行列。

## 4. 图文示例

一张 1000 行销售明细表：点 A2，按 `Ctrl + Shift + ↓` 再 `Ctrl + Shift + →`，一次选中 A2:F1001 整个数据区；右键列标把 F 列（金额）列宽双击自适应；标题行 A1:F1 合并居中并加粗；把第 1 行冻结，滚动到底部核对最后一行；用名称框输入 `F1001` 跳到最后一格核对金额。

## 5. 公式和代码

```excel
=SUM(B2:B6) → 550
=ROWS(B2:B6) → 5
=COLUMNS(B2:D2) → 3
```

- `=SUM(B2:B6)` → 550：B2:B6 是 100、120、90、110、130，求和 100+120+90+110+130=550
- `=ROWS(B2:B6)` → 5：ROWS 返回区域行数：B2 到 B6 共 5 行，核对选区行数时用
- `=COLUMNS(B2:D2)` → 3：COLUMNS 返回区域列数：B 到 D 共 3 列

## 6. 实际工作场景

### 接手一张 2 万行大表

先 `Ctrl + End` 看已用区域：若到了第 20000 行之后很远，说明底部有残留格式或空行，先删掉多余行再操作，否则排序筛选会把空行也算进去。冻结首行后用名称框跳转，少用滚轮翻页。

### 做一张要打印的报表

标题行合并居中、列宽按内容自适应、行高统一 18；数据区绝不合并单元格（否则排序与筛选全废）。打印前用分页预览确认每页断在哪里。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 排序后数据错位 | 排序前只选中了一列，行与行对应关系被打乱 | 排序前选中整个数据区，或点数据区内任一格直接点排序按钮（Excel 会自动扩展选区） |
| 删除行后公式变 #REF! | 被删的行正被其他公式引用 | 删行前用公式→追踪从属单元格检查引用；改用整列引用可减少此类问题 |
| 合并单元格后无法排序 | 合并区域破坏了矩形数据区 | 数据区用"跨列居中"（设置单元格格式→对齐→水平对齐→跨列居中）代替合并 |
| Ctrl + End 跳到很远的空白格 | 曾经输入过内容又删了，格式残留导致已用区域虚大 | 选中多余行/列右键删除（不是按 Delete 清内容），保存后重开即恢复 |
