# 逻辑函数大全

逻辑函数是 Excel 公式的"大脑"，负责条件判断、错误处理和逻辑组合。本章共收录 10 个函数。注意：IFS、SWITCH 需要 Excel 2019+（IFNA 为 Excel 2013 引入）；LET、XLOOKUP 等 2021 及以上版本函数在对应章节说明版本。


## 学习目标

学完本篇，你将能够：
- 用 IF、IFS 做条件判断，并说出 IFS 的版本要求
- 用 AND、OR、NOT 组合多个条件
- 用 IFERROR、IFNA 兜底，让报错显示友好提示
---

## IF

**语法：** `IF(条件, [条件成立的值], [条件不成立的值])`

**参数说明：** 最多嵌套 64 层，但超过 3 层建议改用 IFS 或 SWITCH，可读性更好

**示例 1：** 成绩判定及格与否（A2 为分数）
```
=IF(A2>=60, "及格", "不及格")   → "及格"（设 A2=78）
```

**示例 2：** 阶梯提成：销售额≥10 万提 5%，否则 3%（B2 为销售额）
```
=IF(B2>=100000, B2*0.05, B2*0.03)   → 6000（设 B2=120000，≥10 万按 5% 提成）
```

**常见错误：**
- 文本结果要加英文双引号，数字不需要
- 条件中误用 `=` 代替 `>=` 等；文本比较如 `A2="完成"` 注意全半角一致
- 嵌套 IF 括号不匹配是新手第一大坑，写完从最内层往外数括号

---

## IFS

**语法：** `IFS(条件1, 值1, [条件2, 值2], ...)` —— 多条件判断（Excel 2019+/365），按顺序返回第一个成立的值

**示例 1：** 成绩分档（A2 为分数）
```
=IFS(A2>=90, "优秀", A2>=80, "良好", A2>=60, "及格", TRUE, "不及格")   → "良好"（设 A2=85）
```
> 技巧：最后一个条件写 TRUE，相当于"其他情况"，避免无匹配时返回 `#N/A`

**示例 2：** 替代 4 层嵌套 IF 的绩效评级
```
=IFS(B2>=100, "S", B2>=80, "A", B2>=60, "B", TRUE, "C")   → "A"（设 B2=88）
```

**常见错误：**
- 条件按顺序判断，范围有重叠时把最严格的放前面
- 无任何条件成立返回 `#N/A`，记得加 TRUE 兜底
- 旧版 Excel 不支持，发给别人前确认对方版本

---

## AND

**语法：** `AND(条件1, [条件2], ...)` —— 所有条件都成立返回 TRUE，否则 FALSE

**示例 1：** 判断是否同时满足：销售额≥10 万且回款率≥90%（B2 销售额，C2 回款率）
```
=AND(B2>=100000, C2>=0.9)   → TRUE（设 B2=120000、C2=0.95，两条件都成立）
```

**示例 2：** 配合 IF 做双条件判断
```
=IF(AND(A2>=60, B2>=60), "双科及格", "需补考")   → "双科及格"（设 A2=78、B2=85，两科都及格）
```

**常见错误：**
- AND 返回的是逻辑值 TRUE/FALSE，显示为英文；要显示中文需套 IF 转换
- 参数中有错误值时整个返回错误值

---

## OR

**语法：** `OR(条件1, [条件2], ...)` —— 任一条件成立返回 TRUE

**示例 1：** 判断是否为节假日或周末（A2 为日期，D2:D10 节假日）
```
=OR(WEEKDAY(A2,2)>5, COUNTIF(D2:D10, A2)>0)   → TRUE（设 A2=2026-11-07（周六）；第 1 条件已成立）
```

**常见错误：** 与 AND 混淆口诀：AND 是"且"，OR 是"或"

---

## NOT

**语法：** `NOT(逻辑值)` —— 取反

**示例 1：** 筛选未完成项（A2 状态）
```
=NOT(A2="完成")   → FALSE（设 A2="完成"，取反为假；等价于 A2<>"完成"）
```

**示例 2：** 反选：找出不在黑名单中的客户
```
=NOT(COUNTIF(黑名单!A:A, A2)>0)   → TRUE（设 A2="张三"，黑名单里没有张三）
```

**常见错误：** 连续两次 NOT 等于没写，注意检查多余嵌套

---

## XOR

**语法：** `XOR(条件1, [条件2], ...)` —— 奇数个条件成立返回 TRUE（Excel 2013+）

**示例 1：** 互斥校验：两个选项只能勾选其一（A2、B2 为 TRUE/FALSE）
```
=XOR(A2, B2)   → 只勾一个时 TRUE，都勾或都不勾时 FALSE
```

**常见错误：**
- 三个条件时：成立 1 个或 3 个返回 TRUE，成立 2 个返回 FALSE（奇偶性），容易误解
- 使用频率低，多数场景 AND/OR 更直观

---

## IFERROR

**语法：** `IFERROR(公式, 出错时返回的值)` —— 万能错误捕获

**示例 1：** VLOOKUP 查不到时显示"未找到"而不是 `#N/A`
```
=IFERROR(VLOOKUP(A2, 表!A:B, 2, 0), "未找到")   → "未找到"（设 A2=1009，表!A 列为 1001~1008，无 1009）
```

**示例 2：** 除数为零时显示 0
```
=IFERROR(A2/B2, 0)   → 25（设 A2=100、B2=4，未出错返回原值 25）
```

**常见错误：**
- 会掩盖所有错误（包括公式本身写错），调试阶段先不用，定稿再套
- 只想捕获 `#N/A` 时用 IFNA 更精确，避免把 `#REF!` 等严重错误也藏起来

---

## IFNA

**语法：** `IFNA(公式, 为#N/A时返回的值)` —— 只捕获 `#N/A`（Excel 2013+）

**示例 1：** 查找不到时显示空文本，但其他错误（如 #REF!）仍会暴露
```
=IFNA(VLOOKUP(A2, 表!A:B, 2, 0), "")   → ""（空文本；设 A2=1009，表!A 列为 1001~1008，无 1009）
```

**常见错误：**
- 与 IFERROR 区别：IFNA 只处理 `#N/A`，这是它存在的意义
- 2013 以下版本不支持

---

## LET

**语法：** `LET(名称1, 值1, [名称2, 值2], ..., 计算式)` —— 给中间结果命名，避免重复计算（仅 365/2021+）

**示例 1：** 销售额提成公式中，B2*0.05 出现两次，用 LET 只写一次
```
=LET(提成, B2*0.05, IF(B2>100000, 提成*1.2, 提成))   → 7200（设 B2=120000：提成=6000，>10 万再乘 1.2，得 7200）
```

**示例 2：** 复杂查找中复用同一个 XLOOKUP 结果
```
=LET(结果, XLOOKUP(A2, 表!A:A, 表!B:B), IF(ISNA(结果), "无", 结果))   → "张三"（设 A2=1001，表!A:A 工号、表!B:B 姓名，1001 对应张三）
```

**常见错误：**
- 名称不能与单元格地址冲突（如不能叫 A1）
- 旧版 Excel 会 `#NAME?`，注意兼容性
- LET 的核心价值是性能+可读性，简单公式没必要用

---

## SWITCH

**语法：** `SWITCH(表达式, 值1, 结果1, [值2, 结果2], ..., [默认值])` —— 精确匹配多分支（Excel 2019+/365）

**示例 1：** 部门代码转中文名（A2 为代码）
```
=SWITCH(A2, "XS", "销售部", "JS", "技术部", "CW", "财务部", "未知部门")   → "技术部"（设 A2="JS"）
```

**示例 2：** 替代多层 IF 的星期转换
```
=SWITCH(WEEKDAY(A2,2), 1,"一", 2,"二", 3,"三", 4,"四", 5,"五", 6,"六", "日")   → "一"（设 A2=2026-11-09（星期一））
```

**常见错误：**
- SWITCH 只做**精确相等**匹配，不能写 `>=90` 这样的区间条件，区间用 IFS
- 漏写默认值时无匹配返回 `#N/A`

## 练习题

1. =IF(75>=60,"及格","不及格") 的结果是什么？
2. =IFERROR(1/0,"出错") 的结果是什么？
3. IFS、SWITCH 需要哪个版本？在 Excel 2016 上能用吗？

1. 结果 "及格"，75≥60 条件为真。
