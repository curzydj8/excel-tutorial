# 文本函数大全

文本函数用于处理姓名、地址、编号、身份证号等字符串数据，是数据清洗的利器。本章共收录 18 个函数。注意：TEXTBEFORE、TEXTAFTER、TEXTSPLIT 仅 Microsoft 365 / Excel 2021 及以上版本可用。

---

## LEFT

**语法：** `LEFT(文本, [字符数])`

**参数说明：**
- 文本（必需）：要提取的源文本
- 字符数（可选）：从左起取几个字符，省略默认为 1

**示例 1：** 从手机号码中提取前 3 位（判断运营商号段）
```
=LEFT(A2, 3)   → "138"（A2="13812345678"）
```

**示例 2：** 提取年份前两位（A2="2026-10-03" 文本型日期）
```
=LEFT(A2, 4)   → "2026"
```

**常见错误：**
- 字符数超过文本长度时返回整个文本，不会报错
- 提取出的永远是文本，参与计算前先用 VALUE 转换

---

## RIGHT

**语法：** `RIGHT(文本, [字符数])` —— 从右侧提取，与 LEFT 对称

**示例 1：** 提取身份证号最后一位（校验位）
```
=RIGHT(A2, 1)
```

**示例 2：** 提取文件扩展名（A2="报告.xlsx"）
```
=RIGHT(A2, 4)   → "xlsx"（注意不含点，如需含点取 5 位）
```

**常见错误：** 与 LEFT 相同，注意返回文本类型

---

## MID

**语法：** `MID(文本, 起始位置, 字符数)` —— 从中间任意位置提取

**示例 1：** 从身份证号提取出生日期（第 7~14 位）
```
=MID(A2, 7, 8)   → "19900101"
```

**示例 2：** 提取固定格式编号中间段（A2="ORD-2026-0888"，取年份）
```
=MID(A2, 5, 4)   → "2026"
```

**常见错误：**
- 起始位置从 1 开始计数，不是 0
- 起始位置超出文本长度返回空文本，不报错

---

## LEN

**语法：** `LEN(文本)` —— 返回字符个数（中文、英文、数字都按 1 个计）

**示例 1：** 检查手机号是否为 11 位
```
=LEN(A2)=11
```

**示例 2：** 配合其他函数：去掉最后一个字符
```
=LEFT(A2, LEN(A2)-1)
```

**常见错误：**
- LEN 统计的是字符数，不是字节数；如需字节数用 LENB（中文按 2 计）
- 尾随空格也会被计入，清洗数据时先 TRIM

---

## CONCAT

**语法：** `CONCAT(文本1, [文本2], ...)` —— 合并多个文本（Excel 2016+，替代 CONCATENATE）

**示例 1：** 合并省市区（A2 省、B2 市、C2 区）
```
=CONCAT(A2, B2, C2)
```

**示例 2：** 合并区域（CONCAT 支持区域引用，这是它优于 `&` 的地方）
```
=CONCAT(A2:A5)
```

**常见错误：**
- 旧版本只有 CONCATENATE；新文件发给旧版用户会显示 `#NAME?`
- 合并数字时数字格式会丢失（如日期变成序列号），先用 TEXT 格式化

---

## TEXTJOIN

**语法：** `TEXTJOIN(分隔符, 忽略空值, 文本1, [文本2], ...)` —— 带分隔符的合并（Excel 2016+/365）

**参数说明：**
- 忽略空值：TRUE 跳过空单元格，FALSE 则保留空位

**示例 1：** 用顿号合并多个获奖人姓名（A2:A5）
```
=TEXTJOIN("、", TRUE, A2:A5)   → "张三、李四、王五"
```

**示例 2：** 合并地址并跳过空项
```
=TEXTJOIN("-", TRUE, A2:D2)
```

**常见错误：**
- 分隔符也要加引号，如 `","`
- 结果超过 32767 字符上限会返回 `#VALUE!`

---

## TEXT

**语法：** `TEXT(数值, 格式代码)` —— 按指定格式把数值转为文本

**示例 1：** 日期转"年月日"文本（A2 为日期）
```
=TEXT(A2, "yyyy年m月d日")   → "2026年10月3日"
```

**示例 2：** 金额转千分位文本
```
=TEXT(1234567, "#,##0")   → "1,234,567"
```

**常见错误：**
- 格式代码的年月日必须用英文半角：yyyy、m、d；中文引号会导致格式失效
- 结果为文本，不能直接参与计算

---

## VALUE

**语法：** `VALUE(文本)` —— 把数字格式的文本转为数值，与 TEXT 互逆

**示例 1：** 文本型数字转数值后求和
```
=SUM(VALUE(A2:A10))   → 数组公式思路，365 可直接用
```

**示例 2：** 去掉金额中的货币符号后计算（A2="¥1,200"）
```
=VALUE(SUBSTITUTE(SUBSTITUTE(A2,"¥",""),",",""))   → 1200
```

**常见错误：**
- 文本含非数字字符（如空格）时返回 `#VALUE!`，先用 TRIM/SUBSTITUTE 清理
- 空文本返回 `#VALUE!`，不是 0

---

## UPPER

**语法：** `UPPER(文本)` —— 全部转大写（仅影响英文字母）

**示例 1：** 统一工号大小写（A2="ab123"）
```
=UPPER(A2)   → "AB123"
```

**常见错误：** 对中文无影响；需要首字母大写用 PROPER

---

## LOWER

**语法：** `LOWER(文本)` —— 全部转小写

**示例 1：** 统一邮箱为小写后去重比对
```
=LOWER(A2)
```

---

## TRIM

**语法：** `TRIM(文本)` —— 删除首尾空格，单词间多个空格只保留一个

**示例 1：** 清洗从系统导出的姓名（前后有多余空格）
```
=TRIM(A2)
```

**示例 2：** 判断两个看似相同的文本是否因空格不一致（配合 EXACT）
```
=EXACT(TRIM(A2), TRIM(B2))
```

**常见错误：**
- 只能处理英文半角空格（ASCII 32）；中文全角空格或不换行空格（CHAR(160)）要用 SUBSTITUTE 单独处理
- 网页粘贴的数据常含 CHAR(160)，`SUBSTITUTE(A2, CHAR(160), "")` 先清掉

---

## SUBSTITUTE

**语法：** `SUBSTITUTE(文本, 旧文本, 新文本, [替换第几个])`

**参数说明：**
- 替换第几个（可选）：省略则替换全部出现；指定数字则只替换第 n 次出现

**示例 1：** 把日期中的斜杠换成横杠（A2="2026/10/03"）
```
=SUBSTITUTE(A2, "/", "-")   → "2026-10-03"
```

**示例 2：** 只替换第二个逗号为分号
```
=SUBSTITUTE(A2, ",", ";", 2)
```

**常见错误：**
- 区分大小写；不区分大小写的需求先 UPPER 统一
- 与 REPLACE 区别：SUBSTITUTE 按内容替换，REPLACE 按位置替换

---

## REPLACE

**语法：** `REPLACE(旧文本, 起始位置, 字符数, 新文本)` —— 按位置替换

**示例 1：** 手机号中间 4 位打码（A2="13812345678"）
```
=REPLACE(A2, 4, 4, "****")   → "138****5678"
```

**示例 2：** 统一编号前缀（把前 3 个字符换成 "NEW"）
```
=REPLACE(A2, 1, 3, "NEW")
```

**常见错误：**
- 起始位置从 1 计数；超出长度时：起始位置过大返回原文本
- 新文本长度可以与被替换的不同，结果总长度自动调整

---

## FIND

**语法：** `FIND(查找文本, 源文本, [起始位置])` —— 返回位置，**区分大小写**，不支持通配符

**示例 1：** 定位 "@" 在邮箱中的位置
```
=FIND("@", A2)
```

**示例 2：** 配合 MID 提取 "@" 之前的内容（用户名部分）
```
=MID(A2, 1, FIND("@", A2)-1)
```

**常见错误：**
- 找不到时返回 `#VALUE!`，常套 IFERROR 处理
- 要忽略大小写用 SEARCH；要用通配符也用 SEARCH

---

## SEARCH

**语法：** `SEARCH(查找文本, 源文本, [起始位置])` —— 不区分大小写，支持通配符（? 单个字符，* 任意多个）

**示例 1：** 查找文本中是否含"北京"（不分大小写场景多用于英文）
```
=ISNUMBER(SEARCH("北京", A2))
```

**示例 2：** 用通配符找 "第?章" 模式
```
=SEARCH("第?章", A2)
```

**常见错误：**
- 查找文本本身含 `?` `*` 时需加 `~` 转义，如 `"~?"`
- 找不到同样返回 `#VALUE!`

---

## TEXTBEFORE

**语法：** `TEXTBEFORE(文本, 分隔符, [第几个], [区分大小写], ...)` —— 取分隔符之前的内容（仅 365/2021+）

**示例 1：** 从邮箱提取用户名（A2="zhangsan@company.com"）
```
=TEXTBEFORE(A2, "@")   → "zhangsan"
```

**示例 2：** 取第二个 "-" 之前的内容（A2="2026-10-03"）
```
=TEXTBEFORE(A2, "-", 2)   → "2026-10"
```

**常见错误：**
- 旧版 Excel 没有此函数，会显示 `#NAME?`；替代方案用 LEFT+FIND 组合
- 分隔符不存在时返回 `#N/A`

---

## TEXTAFTER

**语法：** `TEXTAFTER(文本, 分隔符, [第几个], ...)` —— 取分隔符之后的内容（仅 365/2021+）

**示例 1：** 从邮箱提取域名
```
=TEXTAFTER(A2, "@")   → "company.com"
```

**示例 2：** 取最后一个 "-" 之后的内容（第几个用负数表示从后往前）
```
=TEXTAFTER(A2, "-", -1)   → "03"（A2="2026-10-03"）
```

**常见错误：** 同 TEXTBEFORE，注意版本兼容性

---

## TEXTSPLIT

**语法：** `TEXTSPLIT(文本, 列分隔符, [行分隔符], ...)` —— 按分隔符拆分成多行多列（仅 365/2021+）

**示例 1：** 把 "张三,李四,王五" 拆成三列
```
=TEXTSPLIT(A2, ",")
```

**示例 2：** 同时按行列拆分（A2="a1,b1;a2,b2"，逗号分列、分号分行）
```
=TEXTSPLIT(A2, ",", ";")
```

**常见错误：**
- 结果是动态数组，需要右侧/下方有足够的空单元格，否则 `#SPILL!`
- 旧版本替代方案：用「数据-分列」功能
