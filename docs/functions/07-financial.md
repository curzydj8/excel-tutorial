# 财务函数大全

财务函数用于贷款、投资、折旧等资金时间价值计算。本章共收录 9 个函数。

**统一约定（非常重要）：**
- 所有财务函数中，**现金流出为负、流入为正**（或反之，但必须统一符号）
- `type` 参数：0=期末付款（默认），1=期初付款
- 年利率与期数单位必须一致：年利率 6% 按月还款时，月利率=6%/12，期数=年数×12

---

## PMT

**语法：** `PMT(利率, 期数, 现值, [终值], [类型])` —— 计算每期还款额（等额本息）

**示例 1：** 贷款 50 万，年利率 4.5%，20 年，每月还多少？
```
=PMT(4.5%/12, 20*12, 500000)   → -3187.38（负号表示支出）
```

**示例 2：** 显示为正数（取绝对值）
```
=ABS(PMT(4.5%/12, 240, 500000))
```

**常见错误：**
- 忘记把年利率除以 12、年数乘以 12，这是最常见的错误，结果会差一个数量级
- 结果为负是正常的（代表现金流出），不是报错

---

## FV

**语法：** `FV(利率, 期数, 每期付款, [现值], [类型])` —— 计算终值（未来值）

**示例 1：** 每月定投 2000，年化 6%，10 年后有多少钱？
```
=FV(6%/12, 10*12, -2000)   → 327,095.13
```

**示例 2：** 现有 10 万本金，每月再投 2000，10 年后
```
=FV(6%/12, 120, -2000, -100000)
```

**常见错误：**
- 每期付款符号：定投是支出，写 -2000，结果为正（ inflow 视角）；符号混乱是主要坑
- 利率为 0 时公式退化为简单加总，函数仍可正常计算

---

## PV

**语法：** `PV(利率, 期数, 每期付款, [终值], [类型])` —— 计算现值

**示例 1：** 未来 20 年每年收到 5 万，年化 4%，这笔年金现在值多少？
```
=PV(4%, 20, 50000)   → -679,516.31（负号表示为得到它现在要付出的价格）
```

**示例 2：** 10 年后要攒够 100 万，现在一次性存多少（年化 5%）？
```
=PV(5%, 10, 0, 1000000)   → -613,913.25
```

**常见错误：** 与 FV 互逆，可用 `FV(4%,20,50000,-PV(4%,20,50000))` 验算应得 0

---

## NPV

**语法：** `NPV(利率, 现金流1, [现金流2], ...)` —— 净现值

**示例 1：** 项目投资：第 0 年投入 100 万，之后 5 年每年回报 30 万，折现率 8%，值不值得投？
```
=NPV(8%, 300000,300000,300000,300000,300000)-1000000   → 197,813（>0 值得投）
```
> 关键：NPV 默认第一笔现金流发生在**第 1 期末**，第 0 年的投入要单独减掉，不能放进 NPV 里！

**常见错误：**
- 把期初投入也放进 NPV 参数是头号错误，会导致结果虚高一期
- 各期现金流符号：投入为负、回报为正要统一

---

## IRR

**语法：** `IRR(现金流数组, [预估值])` —— 内部收益率（让 NPV=0 的折现率）

**示例 1：** 计算项目 IRR（A2:A6：-100万, 30万, 30万, 30万, 30万）
```
=IRR(A2:A6)   → 约 15.2%
```

**示例 2：** 现金流含多笔正负交替时，可给预估值帮助收敛
```
=IRR(A2:A10, 0.1)
```

**常见错误：**
- 现金流必须**至少一正一负**，否则返回 `#NUM!`
- 非常规现金流（符号多次变化）可能有多解或无解，结果需结合 NPV 判断
- 默认预估 10%，不收敛时换预估值试试

---

## RATE

**语法：** `RATE(期数, 每期付款, 现值, [终值], [类型], [预估值])` —— 反推利率

**示例 1：** 贷款 50 万，240 期，每期还 3187 元，实际月利率？
```
=RATE(240, -3187, 500000)*12   → 约 4.5%（年化）
```

**示例 2：** 信用卡分期手续费率验算

**常见错误：**
- 付款与现值符号必须相反（一个流入一个流出），同号返回 `#NUM!`
- 结果是每期利率，记得换算成年化

---

## NPER

**语法：** `NPER(利率, 每期付款, 现值, [终值], [类型])` —— 计算需要多少期

**示例 1：** 每月还 5000，年利率 4.5%，50 万贷款几年还清？
```
=NPER(4.5%/12, -5000, 500000)/12   → 约 10.9 年
```

**常见错误：**
- 每期还款额若小于每期利息（还不起本金），返回 `#NUM!`，这是合理的——永远还不清

---

## SLN

**语法：** `SLN(原值, 残值, 使用年限)` —— 直线法折旧，每年折旧额相同

**示例 1：** 设备原值 10 万，残值 1 万，用 5 年，每年折旧？
```
=SLN(100000, 10000, 5)   → 18000
```

**常见错误：**
- 残值不能大于原值；年限为 0 返回 `#DIV/0!`

---

## DB

**语法：** `DB(原值, 残值, 使用年限, 第几年, [首年月份数])` —— 余额递减法折旧（加速折旧，前多后少）

**示例 1：** 同上设备，第 1 年折旧额
```
=DB(100000, 10000, 5, 1)   → 36900（比直线法的 18000 多）
```

**示例 2：** 第 3 年折旧额
```
=DB(100000, 10000, 5, 3)
```

**常见错误：**
- 第几年不能超过使用年限，否则 `#NUM!`
- 首年月份数省略默认 12；不满一年购入的设备要填实际月份数
- 与 SLN 对比：DB 前期折旧快，适合技术更新快的设备
