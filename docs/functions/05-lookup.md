# 查找引用函数大全

查找引用是 Excel 进阶的分水岭：从"算得快"到"找得准"。本章共收录 14 个函数。XLOOKUP、FILTER、SORT、UNIQUE、TRANSPOSE（动态数组）仅 Microsoft 365 / Excel 2021+ 可用。

---

## VLOOKUP

**语法：** `VLOOKUP(查找值, 表格区域, 返回第几列, [精确/模糊匹配])`

**参数说明：**
- 第 4 参数：0 或 FALSE=精确匹配（常用）；1 或 TRUE=模糊匹配（要求首列升序）
- 只能从左往右查：查找值必须在区域**第一列**

**示例 1：** 按工号查姓名（A2 工号，员工表!A:D，姓名在第 2 列）
```
=VLOOKUP(A2, 员工表!A:D, 2, 0)
```

**示例 2：** 模糊匹配定税率（B2 为收入，税率表首列为起征点且升序）
```
=VLOOKUP(B2, 税率表!A:B, 2, 1)
```

**常见错误：**
- 查不到返回 `#N/A`，套 IFERROR/IFNA 美化
- 第 3 参数列号是相对区域的列数，不是工作表绝对列号
- 插入列会导致列号错位，这是 VLOOKUP 最大硬伤，重要表格改用 INDEX+MATCH 或 XLOOKUP
- 查找值与首列格式不一致（文本型数字 vs 数值）会导致查不到

---

## HLOOKUP

**语法：** `HLOOKUP(查找值, 表格区域, 返回第几行, [精确/模糊匹配])` —— 横向版 VLOOKUP

**示例 1：** 横向月份表查销售额（A2="3月"，表头在第 1 行，数据在第 3 行）
```
=HLOOKUP(A2, 数据!A1:M3, 3, 0)
```

**常见错误：** 使用场景极少，横向表建议转置为纵向后用 VLOOKUP/XLOOKUP

---

## XLOOKUP

**语法：** `XLOOKUP(查找值, 查找区域, 返回区域, [未找到时], [匹配模式], [搜索模式])` —— VLOOKUP 终极替代（仅 365/2021+）

**参数说明：**
- 未找到时：自定义 `#N/A` 的替代显示，不用再套 IFERROR
- 匹配模式：0=精确（默认），-1=精确或下一个较小值，1=精确或下一个较大值，2=通配符
- 搜索模式：1=从上往下（默认），-1=从下往上（找最后一次出现）

**示例 1：** 按工号查姓名，可向左查（VLOOKUP 做不到）
```
=XLOOKUP(A2, 员工表!A:A, 员工表!B:B, "查无此人")
```

**示例 2：** 找某员工最后一次打卡记录（从下往上搜）
```
=XLOOKUP(A2, 打卡!A:A, 打卡!C:C, , , -1)
```

**常见错误：**
- 查找区域与返回区域行数必须一致，否则 `#VALUE!`
- 旧版 Excel 不支持，注意文件分发兼容性

## INDEX

**语法：** `INDEX(区域, 行号, [列号])` —— 按行列号取区域中的值

**示例 1：** 取 B2:D10 区域第 3 行第 2 列的值
```
=INDEX(B2:D10, 3, 2)
```

**示例 2：** 取整行/整列：列号省略返回整行（365 动态数组）
```
=INDEX(A2:D10, 3, 0)   → 返回第 3 行整行
```

**常见错误：**
- 行列号超出区域返回 `#REF!`
- 单独用意义不大，威力在于与 MATCH 组合

---

## MATCH

**语法：** `MATCH(查找值, 查找区域, [匹配类型])`

**参数说明：**
- 匹配类型：0=精确匹配（常用）；1=找≤查找值的最大值（区域需升序）；-1=找≥查找值的最小值（区域需降序）
- 返回的是**位置序号**（第几个），不是值本身

**示例 1：** 找"李四"在 A2:A100 中的位置
```
=MATCH("李四", A2:A100, 0)
```

**示例 2：** INDEX+MATCH 组合：按工号查姓名，可向左查、插列不影响
```
=INDEX(员工表!B:B, MATCH(A2, 员工表!A:A, 0))
```

**常见错误：**
- 找不到返回 `#N/A`
- 匹配类型省略默认为 1（模糊），新手常忘记写 0 导致结果莫名其妙

## OFFSET

**语法：** `OFFSET(基准单元格, 下移行数, 右移列数, [高度], [宽度])` —— 返回偏移后的引用

**示例 1：** 取 A1 下方 2 行、右方 3 列的单元格（即 D3）
```
=OFFSET(A1, 2, 3)
```

**示例 2：** 动态求和区域：B2 开始，向下取与 A 列数据等高的区域
```
=SUM(OFFSET(B2, 0, 0, COUNTA(A:A)-1, 1))
```

**常见错误：**
- 易失性函数，每次重算都触发，大量使用严重拖慢表格
- 偏移超出工作表边界返回 `#REF!`
- 动态区域需求优先考虑用表格结构化引用或 365 动态数组替代

---

## INDIRECT

**语法：** `INDIRECT(文本地址, [A1样式])` —— 把文本转成真实引用

**示例 1：** 跨表动态引用：A2 中写表名"一月"，引用该表 B2
```
=INDIRECT(A2&"!B2")
```

**示例 2：** 下拉菜单选月份，自动汇总对应表数据（A2="一月"）
```
=SUM(INDIRECT(A2&"!C2:C100"))
```

**常见错误：**
- 易失性函数，性能杀手，能不用就不用
- 引用的工作簿关闭后返回 `#REF!`（跨文件时）
- 文本地址写错（如缺 `!`）返回 `#REF!`，调试困难

---

## CHOOSE

**语法：** `CHOOSE(序号, 值1, 值2, ...)` —— 按序号返回对应值

**示例 1：** 数字转中文星期（WEEKDAY 返回 1~7）
```
=CHOOSE(WEEKDAY(A2,2), "一","二","三","四","五","六","日")
```

**示例 2：** 按季度序号取季度名（A2=1~4）
```
=CHOOSE(A2, "一季度", "二季度", "三季度", "四季度")
```

**常见错误：**
- 序号超出范围返回 `#VALUE!`
- 参数最多 254 个，超长列表用 VLOOKUP 建对照表更好

---

## ROW

**语法：** `ROW([单元格])` —— 返回行号，省略参数返回公式所在行

**示例 1：** 生成连续序号（下拉填充）
```
=ROW()-1   → 在第 2 行返回 1，第 3 行返回 2……
```

**示例 2：** 配合 MOD 做隔行判断
```
=MOD(ROW(), 2)=0
```

**常见错误：** 删除行后基于 ROW 的序号会变，需要固定序号用填充而非公式

---

## COLUMN

**语法：** `COLUMN([单元格])` —— 返回列号（A=1, B=2…），与 ROW 对称

**示例 1：** VLOOKUP 第 3 参数动态化：返回 B 列用 COLUMN(B1)
```
=VLOOKUP(A2, 表!A:D, COLUMN(B1), 0)
```

---

## TRANSPOSE

**语法：** `TRANSPOSE(数组)` —— 行列转置（365 为动态数组，旧版需三键数组公式）

**示例 1：** 把 A2:A10 纵向名单转为横向
```
=TRANSPOSE(A2:A10)
```

**常见错误：**
- 365 中结果自动溢出，需保证目标区域为空，否则 `#SPILL!`
- 旧版需先选中目标区域，按 Ctrl+Shift+Enter

---

## SORT

**语法：** `SORT(数组, [排序列], [升/降序], [按行/列])` —— 动态排序（仅 365/2021+）

**参数说明：**
- 升/降序：1=升序（默认），-1=降序

**示例 1：** 按销售额降序排列名单（A2:B100，姓名+销售额，按第 2 列降序）
```
=SORT(A2:B100, 2, -1)
```

**示例 2：** 取销售额前 5 名（配合 TAKE 或 INDEX）
```
=TAKE(SORT(A2:B100, 2, -1), 5)
```

**常见错误：**
- 结果为动态数组，源数据变更自动重排，无需手动再排序
- 多列排序需求用 SORTBY

---

## FILTER

**语法：** `FILTER(数组, 筛选条件, [无结果时显示])` —— 按条件动态筛选（仅 365/2021+）

**示例 1：** 筛出销售部所有人（A 列部门）
```
=FILTER(A2:C100, A2:A100="销售部")
```

**示例 2：** 多条件：销售部且销售额>10 万，无结果显示"无"
```
=FILTER(A2:C100, (A2:A100="销售部")*(C2:C100>10000), "无")
```

**常见错误：**
- 无匹配且未设第 3 参数时返回 `#CALC!`
- 条件区域行数必须与数组一致
- 这是 365 最实用的函数之一，可替代 90% 的高级筛选场景

---

## UNIQUE

**语法：** `UNIQUE(数组, [按列], [只取唯一值])` —— 去重（仅 365/2021+）

**参数说明：**
- 只取唯一值：FALSE=去重（默认），TRUE=只保留出现一次的值

**示例 1：** 提取不重复的部门列表（A2:A100）
```
=UNIQUE(A2:A100)
```

**示例 2：** 结合 SORT 得到排序后的去重列表
```
=SORT(UNIQUE(A2:A100))
```

**常见错误：**
- 空单元格会被当作一个 0 值参与去重，注意源数据先清理
- 旧版替代方案：「数据-删除重复项」
