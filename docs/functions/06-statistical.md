# 统计函数大全

统计函数用于计数、求最值、排位、离散程度分析，是做报表和数据分析的核心工具。本章共收录 18 个函数。注意：RANK/MODE/STDEV/VAR 在新版中有 RANK.EQ、MODE.SNGL、STDEV.S、VAR.S 等精确命名，旧名仍可用。


## 学习目标

学完本篇，你将能够：
- 用 COUNT、COUNTA、COUNTBLANK 区分计数口径
- 用 COUNTIF、COUNTIFS 做条件计数
- 用 MAX、MIN、LARGE、RANK 做最值与排名
---

## COUNT

**语法：** `COUNT(数值1, [数值2], ...)` —— 只统计数字单元格个数

**示例 1：** 统计实际录入分数的人数（缺考为空）
```
=COUNT(B2:B40)   → 10（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84，其余行为空）
```

**示例 2：** 对比应到/实到：`=COUNTA(A2:A40)-COUNT(B2:B40)` 得出缺考人数

**常见错误：** 文本型数字不计入；要统计非空用 COUNTA（见下）

---

## COUNTA

**语法：** `COUNTA(数值1, [数值2], ...)` —— 统计非空单元格个数（数字、文本、逻辑值都算）

**示例 1：** 统计名单总人数（A2:A40 姓名列）
```
=COUNTA(A2:A40)   → 9（设 A2:A11 为 张三、李四、（空）、王五、赵六、钱七、孙八、周九、吴十、郑十一，其余行为空）
```

**示例 2：** 检查表格是否填完：空单元格数 = 总行数 - COUNTA
```
=ROWS(A2:A40)-COUNTA(B2:B40)   → 30（设 A2:A40 共 39 行，B2:B40 只有 9 个分数、其余为空：COUNTA=9，39-9=30 个空单元格）
```

**常见错误：**
- 公式返回的 `""` 空文本也会被计入（它不是真正的空）
- 含空格的"假空"单元格也会被计入，先 TRIM 清理

---

## COUNTBLANK

**语法：** `COUNTBLANK(区域)` —— 统计空单元格个数

**示例 1：** 统计未填手机号的人数
```
=COUNTBLANK(C2:C100)   → 2（设 C2:C11 10 个单元格中有 2 个空，其余行为空）
```

**常见错误：**
- 同样会把 `""` 空文本计为空，这是符合预期的
- COUNTBLANK 只能接单个区域，不能多区域

---

## COUNTIF

**语法：** `COUNTIF(条件区域, 条件)` —— 单条件计数

**示例 1：** 统计及格人数（B2:B40 分数）
```
=COUNTIF(B2:B40, ">=60")   → 10（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84，全部≥60，其余行为空）
```

**示例 2：** 统计某员工出现次数（考勤表 A 列姓名）
```
=COUNTIF(A:A, "张三")   → 3（设 A 列有 3 个"张三"）
```

**常见错误：**
- 条件文本加引号：`">=60"`、`"张三"`；引用单元格则 `"="&D1`
- 通配符：`"张*"` 统计所有姓张的

---

## COUNTIFS

**语法：** `COUNTIFS(条件区域1, 条件1, [条件区域2, 条件2], ...)` —— 多条件计数（最多 127 组）

**示例 1：** 统计销售部及格人数（A 列部门，B 列分数）
```
=COUNTIFS(A2:A100, "销售部", B2:B100, ">=60")   → 3（设 A2:A6 部门为销售部、技术部、销售部、销售部、技术部，B2:B6 分数为 78,85,92,67,88：销售部且≥60 的有 3 人，其余行为空）
```

**示例 2：** 统计 80~90 分段人数
```
=COUNTIFS(B2:B100, ">=80", B2:B100, "<90")   → 4（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84：80~89 分的有 85、88、81、84 共 4 个，其余行为空）
```

**常见错误：**
- 各条件区域必须大小一致，否则 `#VALUE!`
- 条件之间是"且"关系；要"或"关系用多个 COUNTIF 相加

---

## AVERAGEIF

**语法：** `AVERAGEIF(条件区域, 条件, [平均区域])` —— 单条件求平均

**示例 1：** 求及格平均分
```
=AVERAGEIF(B2:B40, ">=60")   → 83.3（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84，全部≥60，其余行为空）
```

**常见错误：** 无满足条件时 `#DIV/0!`，套 IFERROR 处理

---

## AVERAGEIFS

**语法：** `AVERAGEIFS(平均区域, 条件区域1, 条件1, ...)` —— 多条件求平均（注意平均区域在**前**）

**示例 1：** 求销售部男员工平均工资（A 部门，B 性别，C 工资）
```
=AVERAGEIFS(C2:C100, A2:A100, "销售部", B2:B100, "男")   → 10500（设 A2:A6 部门、B2:B6 性别、C2:C6 业绩同 SUMIF 例 1：销售部男性为 12000、9000，平均 10500；其余行为空）
```

**常见错误：**
- 与 AVERAGEIF 参数顺序不同（AVERAGEIFS 平均区域在前），照抄 AVERAGEIF 会错
- 同样注意各区域大小一致

---

## MAX

**语法：** `MAX(数值1, [数值2], ...)` —— 返回最大值，忽略文本

**示例 1：** 找最高分
```
=MAX(B2:B40)   → 95（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84，其余行为空）
```

**示例 2：** 配合 IF 求销售部最高销售额
```
=MAX(IF(A2:A100="销售部", C2:C100))   → 15000（设 A2:A6 部门、C2:C6 业绩同 SUMIF 例 1：销售部最高 15000；365 直接回车，旧版三键数组）
```

**常见错误：** 区域全空返回 0，不是错误值，判断时注意区分

---

## MIN

**语法：** `MIN(数值1, [数值2], ...)` —— 返回最小值，与 MAX 对称

**示例 1：** 找最低报价（三家供应商 B2:D2）
```
=MIN(B2:D2)   → 30（设 B2:D2 为 50,30,80）
```

**常见错误：** 含 0 的区域 MIN 返回 0；要排除 0 用 `MINIFS`（2019/365）或数组公式

---

## MAXIFS

**语法：** `MAXIFS(最大值区域, 条件区域1, 条件1, [条件区域2, 条件2], ...)` —— 多条件取最大值（Excel 2019+/365），只在同时满足全部条件的行里取最大值

**示例 1：** 找销售部最高业绩（A 列部门，C 列业绩）
```
=MAXIFS(C2:C6, A2:A6, "销售部")   → 15000（设 A2:A6 部门为销售部、技术部、销售部、销售部、技术部，C2:C6 业绩为 12000,8000,15000,9000,20000）
```

**示例 2：** 技术部且分数>80 的最高业绩（B 列分数）
```
=MAXIFS(C2:C6, A2:A6, "技术部", B2:B6, ">80")   → 20000（设 B2:B6 分数为 78,85,92,67,88：技术部且分数>80 的是 8000、20000，最高 20000）
```

**示例 3：** 无人满足条件时返回 0（不是报错）
```
=MAXIFS(C2:C6, A2:A6, "销售部", B2:B6, ">95")   → 0（设 B2:B6 分数同上：销售部最高分 92，无人>95）
```

**常见错误：**
- 最大值区域与各条件区域必须大小形状一致，否则返回 `#VALUE!`
- 无任何行满足条件时返回 0，不是报错也不是 `#N/A`，别把 0 当成真实最大值
- 条件之间是"且"关系；要"或"关系用多个 MAXIFS 再取 MAX
- 旧版 Excel（2016 及更早）没有此函数，会显示 `#NAME?`，替代方案用 MAX+IF 数组公式

---

## MINIFS

**语法：** `MINIFS(最小值区域, 条件区域1, 条件1, [条件区域2, 条件2], ...)` —— 多条件取最小值（Excel 2019+/365），只在同时满足全部条件的行里取最小值

**示例 1：** 找销售部最低业绩（A 列部门，C 列业绩）
```
=MINIFS(C2:C6, A2:A6, "销售部")   → 9000（设 A2:A6 部门、C2:C6 业绩同上：销售部业绩 12000、15000、9000，最低 9000）
```

**示例 2：** 技术部且分数>80 的最低业绩（B 列分数）
```
=MINIFS(C2:C6, A2:A6, "技术部", B2:B6, ">80")   → 8000（设 B2:B6 分数同上：技术部且分数>80 的是 8000、20000，最低 8000）
```

**示例 3：** 无人满足条件时返回 0（不是报错）
```
=MINIFS(C2:C6, A2:A6, "销售部", B2:B6, ">95")   → 0（设 B2:B6 分数同上：销售部最高分 92，无人>95）
```

**常见错误：**
- 最小值区域与各条件区域必须大小形状一致，否则返回 `#VALUE!`
- 无任何行满足条件时返回 0，别把 0 当成真实最小值
- 想排除 0 取最小正值，用条件 `">0"`，如 `=MINIFS(C2:C6, C2:C6, ">0")`
- 旧版 Excel（2016 及更早）没有此函数，会显示 `#NAME?`，替代方案用 MIN+IF 数组公式

---

## LARGE

**语法：** `LARGE(数组, k)` —— 返回第 k 大的值

**示例 1：** 第二高分
```
=LARGE(B2:B40, 2)   → 92（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84：第 2 大为 92，其余行为空）
```

**示例 2：** 前三名平均分
```
=AVERAGE(LARGE(B2:B40, {1,2,3}))   → 92.33（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84：前 3 大 95、92、90 的平均值；365 动态数组直接求平均）
```

**常见错误：**
- k 大于数据个数返回 `#NUM!`
- 有并列时：如两个 100 分，LARGE(…,1) 和 LARGE(…,2) 都是 100

---

## SMALL

**语法：** `SMALL(数组, k)` —— 返回第 k 小的值，与 LARGE 对称

**示例 1：** 去掉一个最低分后求平均（B2:B40）
```
=(SUM(B2:B40)-SMALL(B2:B40,1))/(COUNT(B2:B40)-1)   → 85.11（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84：去掉最低分 67 再算平均，(833-67)÷9；其余行为空）
```

**常见错误：**
- k 大于数据个数时返回 #NUM!，k 必须在 1~数据个数之间
- 有并列时 SMALL(…,1) 与 SMALL(…,2) 可能相等（如两个最小值相同），这是正常行为
- 去掉最小值求平均的经典写法：=(SUM(区域)-SMALL(区域,1))/(COUNT(区域)-1)，分母别忘了减 1

---

## RANK

**语法：** `RANK(数值, 引用区域, [排序方式])` —— 返回排名（新版建议用 RANK.EQ）

**参数说明：**
- 排序方式：0 或省略=降序（最大为第 1）；非 0=升序（最小为第 1）

**示例 1：** 成绩排名（B2 分数，B$2:B$40 全体）
```
=RANK(B2, B$2:B$40, 0)   → 4（设 B2=88，B2:B11 为 78,85,92,67,88,95,73,81,90,84：降序排第 4，95、92、90 在前；其余行为空）
```
> 注意区域要用 `$` 绝对引用，否则下拉时区域会漂移

**示例 2：** 并列处理：中国式排名（并列不占位）需用 COUNTIF 技巧
```
=SUMPRODUCT((B$2:B$40>B2)/COUNTIF(B$2:B$40, B$2:B$40&""))+1   → 4（设 B2=88，B2:B11 数据同上：不跳号的中国式排名，同样第 4；其余行为空）
```

**常见错误：**
- 忘记绝对引用是排名错误的第一原因
- 并列时 RANK 会跳号（如两个第 1，则无第 2），这是标准行为不是 bug

---

## MEDIAN

**语法：** `MEDIAN(数值1, [数值2], ...)` —— 返回中位数（排序后居中的值）

**示例 1：** 求工资中位数（比平均数更能反映典型水平，不受极端值影响）
```
=MEDIAN(C2:C100)   → 45（设 C2:C8 为 12,45,23,67,34,89,56：排序后中间值为 45，其余行为空）
```

**常见错误：** 偶数个数据时取中间两数的平均，这是定义不是错误

---

## MODE

**语法：** `MODE(数值1, [数值2], ...)` —— 返回众数（出现次数最多的值，新版建议 MODE.SNGL）

**示例 1：** 找出最常见的分数
```
=MODE(B2:B40)   → 85（设 B2:B11 为 78,85,92,85,88,85,73,81,90,84：85 出现 3 次最多，其余行为空）
```

**常见错误：**
- 无重复值时返回 `#N/A`
- 多个并列众数只返回第一个；要全部用 MODE.MULT（2010+）

---

## STDEV

**语法：** `STDEV(数值1, [数值2], ...)` —— 样本标准差（新版建议 STDEV.S）

**示例 1：** 评估考试分数的离散程度
```
=STDEV(B2:B40)   → 8.74（设 B2:B11 为 78,85,92,67,88,95,73,81,90,84：样本标准差，分母 n-1；值越大分数越参差不齐）
```

**常见错误：**
- 样本 vs 总体：抽样数据用 STDEV.S（n-1），全体数据用 STDEVP/STDEV.P（n），用错结论偏差
- 数据少于 2 个返回 `#DIV/0!`

---

## VAR

**语法：** `VAR(数值1, [数值2], ...)` —— 样本方差（新版建议 VAR.S），等于标准差的平方

**示例 1：** 与 STDEV 配套分析波动性
```
=VAR(C2:C100)   → 76.46（设 C2:C11 为 78,85,92,67,88,95,73,81,90,84：样本方差，分母 n-1；其余行为空）
```

**常见错误：** 同 STDEV，注意样本/总体的选择（VAR.S vs VAR.P）

## 练习题

1. B2:B6 是 3、9、5、9、1，=MAX(B2:B6) 与 =MIN(B2:B6) 各是多少？
2. =MEDIAN(1,2,9) 的结果是多少？
3. =RANK(90,{90,80,70},0) 的结果是多少？
