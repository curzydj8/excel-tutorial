# 统计函数大全

统计函数用于计数、求最值、排位、离散程度分析，是做报表和数据分析的核心工具。本章共收录 16 个函数。注意：RANK/MODE/STDEV/VAR 在新版中有 RANK.EQ、MODE.SNGL、STDEV.S、VAR.S 等精确命名，旧名仍可用。

---

## COUNT

**语法：** `COUNT(数值1, [数值2], ...)` —— 只统计数字单元格个数

**示例 1：** 统计实际录入分数的人数（缺考为空）
```
=COUNT(B2:B40)
```

**示例 2：** 对比应到/实到：`=COUNTA(A2:A40)-COUNT(B2:B40)` 得出缺考人数

**常见错误：** 文本型数字不计入；要统计非空用 COUNTA（见下）

---

## COUNTA

**语法：** `COUNTA(数值1, [数值2], ...)` —— 统计非空单元格个数（数字、文本、逻辑值都算）

**示例 1：** 统计名单总人数（A2:A40 姓名列）
```
=COUNTA(A2:A40)
```

**示例 2：** 检查表格是否填完：空单元格数 = 总行数 - COUNTA
```
=ROWS(A2:A40)-COUNTA(B2:B40)
```

**常见错误：**
- 公式返回的 `""` 空文本也会被计入（它不是真正的空）
- 含空格的"假空"单元格也会被计入，先 TRIM 清理

---

## COUNTBLANK

**语法：** `COUNTBLANK(区域)` —— 统计空单元格个数

**示例 1：** 统计未填手机号的人数
```
=COUNTBLANK(C2:C100)
```

**常见错误：**
- 同样会把 `""` 空文本计为空，这是符合预期的
- COUNTBLANK 只能接单个区域，不能多区域

---

## COUNTIF

**语法：** `COUNTIF(条件区域, 条件)` —— 单条件计数

**示例 1：** 统计及格人数（B2:B40 分数）
```
=COUNTIF(B2:B40, ">=60")
```

**示例 2：** 统计某员工出现次数（考勤表 A 列姓名）
```
=COUNTIF(A:A, "张三")
```

**常见错误：**
- 条件文本加引号：`">=60"`、`"张三"`；引用单元格则 `"="&D1`
- 通配符：`"张*"` 统计所有姓张的

---

## COUNTIFS

**语法：** `COUNTIFS(条件区域1, 条件1, [条件区域2, 条件2], ...)` —— 多条件计数（最多 127 组）

**示例 1：** 统计销售部及格人数（A 列部门，B 列分数）
```
=COUNTIFS(A2:A100, "销售部", B2:B100, ">=60")
```

**示例 2：** 统计 80~90 分段人数
```
=COUNTIFS(B2:B100, ">=80", B2:B100, "<90")
```

**常见错误：**
- 各条件区域必须大小一致，否则 `#VALUE!`
- 条件之间是"且"关系；要"或"关系用多个 COUNTIF 相加

---

## AVERAGEIF

**语法：** `AVERAGEIF(条件区域, 条件, [平均区域])` —— 单条件求平均

**示例 1：** 求及格平均分
```
=AVERAGEIF(B2:B40, ">=60")
```

**常见错误：** 无满足条件时 `#DIV/0!`，套 IFERROR 处理

---

## AVERAGEIFS

**语法：** `AVERAGEIFS(平均区域, 条件区域1, 条件1, ...)` —— 多条件求平均（注意平均区域在**前**）

**示例 1：** 求销售部男员工平均工资（A 部门，B 性别，C 工资）
```
=AVERAGEIFS(C2:C100, A2:A100, "销售部", B2:B100, "男")
```

**常见错误：**
- 与 AVERAGEIF 参数顺序不同（AVERAGEIFS 平均区域在前），照抄 AVERAGEIF 会错
- 同样注意各区域大小一致

---

## MAX

**语法：** `MAX(数值1, [数值2], ...)` —— 返回最大值，忽略文本

**示例 1：** 找最高分
```
=MAX(B2:B40)
```

**示例 2：** 配合 IF 求销售部最高销售额
```
=MAX(IF(A2:A100="销售部", C2:C100))   → 365 直接回车，旧版三键数组
```

**常见错误：** 区域全空返回 0，不是错误值，判断时注意区分

---

## MIN

**语法：** `MIN(数值1, [数值2], ...)` —— 返回最小值，与 MAX 对称

**示例 1：** 找最低报价（三家供应商 B2:D2）
```
=MIN(B2:D2)
```

**常见错误：** 含 0 的区域 MIN 返回 0；要排除 0 用 `MINIFS`（365）或数组公式

---

## LARGE

**语法：** `LARGE(数组, k)` —— 返回第 k 大的值

**示例 1：** 第二高分
```
=LARGE(B2:B40, 2)
```

**示例 2：** 前三名平均分
```
=AVERAGE(LARGE(B2:B40, {1,2,3}))   → 365 动态数组直接求平均
```

**常见错误：**
- k 大于数据个数返回 `#NUM!`
- 有并列时：如两个 100 分，LARGE(…,1) 和 LARGE(…,2) 都是 100

---

## SMALL

**语法：** `SMALL(数组, k)` —— 返回第 k 小的值，与 LARGE 对称

**示例 1：** 去掉一个最低分后求平均（B2:B40）
```
=(SUM(B2:B40)-SMALL(B2:B40,1))/(COUNT(B2:B40)-1)
```

---

## RANK

**语法：** `RANK(数值, 引用区域, [排序方式])` —— 返回排名（新版建议用 RANK.EQ）

**参数说明：**
- 排序方式：0 或省略=降序（最大为第 1）；非 0=升序（最小为第 1）

**示例 1：** 成绩排名（B2 分数，B$2:B$40 全体）
```
=RANK(B2, B$2:B$40, 0)
```
> 注意区域要用 `$` 绝对引用，否则下拉时区域会漂移

**示例 2：** 并列处理：中国式排名（并列不占位）需用 COUNTIF 技巧
```
=SUMPRODUCT((B$2:B$40>B2)/COUNTIF(B$2:B$40, B$2:B$40&""))+1
```

**常见错误：**
- 忘记绝对引用是排名错误的第一原因
- 并列时 RANK 会跳号（如两个第 1，则无第 2），这是标准行为不是 bug

---

## MEDIAN

**语法：** `MEDIAN(数值1, [数值2], ...)` —— 返回中位数（排序后居中的值）

**示例 1：** 求工资中位数（比平均数更能反映典型水平，不受极端值影响）
```
=MEDIAN(C2:C100)
```

**常见错误：** 偶数个数据时取中间两数的平均，这是定义不是错误

---

## MODE

**语法：** `MODE(数值1, [数值2], ...)` —— 返回众数（出现次数最多的值，新版建议 MODE.SNGL）

**示例 1：** 找出最常见的分数
```
=MODE(B2:B40)
```

**常见错误：**
- 无重复值时返回 `#N/A`
- 多个并列众数只返回第一个；要全部用 MODE.MULT（365）

---

## STDEV

**语法：** `STDEV(数值1, [数值2], ...)` —— 样本标准差（新版建议 STDEV.S）

**示例 1：** 评估考试分数的离散程度
```
=STDEV(B2:B40)   → 值越大分数越参差不齐
```

**常见错误：**
- 样本 vs 总体：抽样数据用 STDEV.S（n-1），全体数据用 STDEVP/STDEV.P（n），用错结论偏差
- 数据少于 2 个返回 `#DIV/0!`

---

## VAR

**语法：** `VAR(数值1, [数值2], ...)` —— 样本方差（新版建议 VAR.S），等于标准差的平方

**示例 1：** 与 STDEV 配套分析波动性
```
=VAR(C2:C100)
```

**常见错误：** 同 STDEV，注意样本/总体的选择（VAR.S vs VAR.P）
