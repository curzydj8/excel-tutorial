# 数学函数大全

数学函数是 Excel 中最基础也最常用的一类函数，涵盖求和、求平均、四舍五入、随机数、条件求和等日常计算场景。本章共收录 19 个函数，每个函数均配有实用示例和避坑提醒。

---

## SUM

**语法：** `SUM(数值1, [数值2], ...)`

**参数说明：**
- 数值1（必需）：第一个要求和的参数，可以是数字、单元格引用或区域
- 数值2, ...（可选）：最多支持 255 个参数

**示例 1：** 计算 B2:B10 区域的销售总额
```
=SUM(B2:B10)
```

**示例 2：** 跨多个不连续区域求和（1 季度三个月销售额）
```
=SUM(B2:B10, D2:D10, F2:F10)
```

**常见错误：**
- 区域中混入文本会被自动忽略，不会报错，但求和结果可能与预期不符
- 数字以文本形式存储（如左上角有绿三角）时会被跳过，先用「分列」转为数值
- 公式返回 `#VALUE!` 通常是因为参数中引用了错误值

## SUMIF

**语法：** `SUMIF(条件区域, 条件, [求和区域])`

**参数说明：**
- 条件区域（必需）：用于判断条件的单元格区域
- 条件（必需）：筛选条件，如 `">100"`、`"北京"`、A1（引用单元格）
- 求和区域（可选）：实际求和的区域；省略时对条件区域本身求和

**示例 1：** 统计销售部所有人的销售额（A 列部门，B 列销售额）
```
=SUMIF(A2:A50, "销售部", B2:B50)
```

**示例 2：** 统计销售额大于 10000 的总额（条件写在单元格 D1 中更灵活）
```
=SUMIF(B2:B50, ">"&D1)
```
> 技巧：条件引用单元格时要用 `&` 连接，如 `">"&D1`，不能直接写 `">D1"`

**常见错误：**
- 条件中的文本必须加英文双引号，数字条件如 `">100"` 整个也要加引号
- 条件区域和求和区域行数不一致时，结果会错位，建议保持相同大小

---

## SUMIFS

**语法：** `SUMIFS(求和区域, 条件区域1, 条件1, [条件区域2, 条件2], ...)`

**参数说明：**
- 求和区域（必需）：注意与 SUMIF 不同，求和区域是**第一个**参数
- 条件区域1/条件1（必需）：第一组筛选条件，最多 127 组

**示例 1：** 统计销售部 3 月份的销售额（A 列部门，B 列月份，C 列销售额）
```
=SUMIFS(C2:C100, A2:A100, "销售部", B2:B100, "3月")
```

**示例 2：** 统计单价大于 50 且库存小于 20 的商品总价值（D 列单价，E 列库存，F 列总价值）
```
=SUMIFS(F2:F100, D2:D100, ">50", E2:E100, "<20")
```

**常见错误：**
- 与 SUMIF 参数顺序相反（SUMIFS 求和区域在前），混用时最容易写错
- 所有条件区域必须行列数一致，否则返回 `#VALUE!`
- 通配符可用：`"北*"` 匹配所有以"北"开头的文本

## AVERAGE

**语法：** `AVERAGE(数值1, [数值2], ...)`

**参数说明：** 与 SUM 类似，计算所有数值的算术平均值，自动忽略文本和空单元格

**示例 1：** 计算全班数学平均分（B2:B40 为分数）
```
=AVERAGE(B2:B40)
```

**示例 2：** 忽略缺考（空单元格）求平均——AVERAGE 本来就会跳过空单元格，无需额外处理
```
=AVERAGE(C2:C40)
```

**常见错误：**
- 值为 0 的单元格**会计入**平均（分母包含它），空单元格则不计入；想排除 0 要用 AVERAGEIF
- 区域全是文本时返回 `#DIV/0!`

---

## AVERAGEIF

**语法：** `AVERAGEIF(条件区域, 条件, [平均区域])`

**示例 1：** 计算及格学生的平均分（B2:B40 为分数）
```
=AVERAGEIF(B2:B40, ">=60")
```

**示例 2：** 计算技术部员工的平均工资（A 列部门，C 列工资）
```
=AVERAGEIF(A2:A100, "技术部", C2:C100)
```

**常见错误：**
- 没有满足条件的单元格时返回 `#DIV/0!`，建议外层套 IFERROR
- 条件写法规则与 SUMIF 完全一致

---

## COUNT

**语法：** `COUNT(数值1, [数值2], ...)`

**参数说明：** 只统计**数字**单元格的个数，文本、空单元格、逻辑值都不计

**示例 1：** 统计实际参加考试的人数（缺考记为空，B2:B40）
```
=COUNT(B2:B40)
```

**示例 2：** 统计有销售额记录的天数
```
=COUNT(C2:C32)
```

**常见错误：**
- 想统计非空单元格个数要用 COUNTA（见统计函数章），COUNT 会漏掉文本
- 日期会被计入（日期本质是数字），这是合理的

## ROUND

**语法：** `ROUND(数值, 小数位数)`

**参数说明：**
- 小数位数：正数表示保留几位小数，0 表示取整，负数表示向十位/百位取整

**示例 1：** 金额保留 2 位小数
```
=ROUND(123.4567, 2)   → 123.46
```

**示例 2：** 取整到百位（常用于预算估算）
```
=ROUND(12345, -2)     → 12300
```

**常见错误：**
- 误以为 ROUND(-2.5, 0) 的行为：Excel 中是 -3（远离零取整），不是 -2
- 只是改单元格格式显示小数位数，实际值并未改变；需要真正取整必须用 ROUND

---

## ROUNDUP

**语法：** `ROUNDUP(数值, 小数位数)` —— 永远**远离零**进位

**示例 1：** 运费按 0.5kg 为单位向上取（3.2kg 按 3.5kg 计费）
```
=ROUNDUP(3.2/0.5, 0)*0.5   → 3.5
```

**示例 2：** 计算需要几辆车（47 人，每车 8 人）
```
=ROUNDUP(47/8, 0)   → 6
```

**常见错误：**
- 与 ROUND 混淆：ROUNDUP(2.1, 0)=3，而 ROUND(2.1, 0)=2
- 负数时远离零：ROUNDUP(-2.1, 0)=-3

---

## ROUNDDOWN

**语法：** `ROUNDDOWN(数值, 小数位数)` —— 永远**向零**舍去

**示例 1：** 工龄只算整年（4.9 年按 4 年）
```
=ROUNDDOWN(4.9, 0)   → 4
```

**示例 2：** 折扣金额舍去分以下小数
```
=ROUNDDOWN(99.999, 2)   → 99.99
```

**常见错误：**
- 与 INT 区别：ROUNDDOWN(-2.9, 0)=-2（向零），INT(-2.9)=-3（向下）

---

## INT

**语法：** `INT(数值)` —— 向下取整到最接近的整数

**示例 1：** 计算完整工作周数（25 天）
```
=INT(25/7)   → 3
```

**常见错误：**
- 负数向下取整：INT(-2.1)=-3，不是 -2，这是新手最常踩的坑

---

## MOD

**语法：** `MOD(被除数, 除数)` —— 返回两数相除的余数

**示例 1：** 判断 A1 是否为偶数
```
=MOD(A1, 2)=0
```

**示例 2：** 隔行填充颜色的辅助列（返回 0/1 交替）
```
=MOD(ROW(), 2)
```

**常见错误：**
- 除数为 0 时返回 `#DIV/0!`
- 结果的符号与除数一致：MOD(-5, 2)=1（不是 -1），这点与很多编程语言不同

---

## ABS

**语法：** `ABS(数值)` —— 返回绝对值

**示例 1：** 计算实际与目标的偏差（不分正负）
```
=ABS(B2-C2)
```

**常见错误：** 几乎无坑，注意 ABS 不能处理复数字符串

---

## SQRT

**语法：** `SQRT(数值)` —— 返回正平方根

**示例 1：** 已知正方形面积求边长（A1 为面积）
```
=SQRT(A1)
```

**常见错误：**
- 负数返回 `#NUM!`，需要虚数结果请用 IMSQRT

---

## POWER

**语法：** `POWER(底数, 指数)`

**示例 1：** 计算 2 的 10 次方
```
=POWER(2, 10)   → 1024
```

**示例 2：** 开立方（等价于 `=A1^(1/3)`）
```
=POWER(A1, 1/3)
```

**常见错误：**
- 负数开偶次方根返回 `#NUM!`；注意 `^` 运算符优先级高于负号，`=-2^2` 结果是 4

---

## RAND

**语法：** `RAND()` —— 返回 0（含）到 1（不含）之间的随机小数，无参数

**示例 1：** 生成随机抽奖序号的辅助列（配合排序）
```
=RAND()
```

**示例 2：** 生成 60~100 的随机分数
```
=60+RAND()*40
```

**常见错误：**
- 每次工作表重算都会变化；需要固定值时复制后「选择性粘贴为数值」
- RAND 是易失性函数，大量使用会拖慢表格重算

---

## RANDBETWEEN

**语法：** `RANDBETWEEN(下限, 上限)` —— 返回指定区间的随机整数

**示例 1：** 随机生成 1~100 的整数
```
=RANDBETWEEN(1, 100)
```

**示例 2：** 随机抽取名单中的一行（A2:A51 共 50 人）
```
=INDEX(A2:A51, RANDBETWEEN(1, 50))
```

**常见错误：**
- 下限大于上限时返回 `#NUM!`
- 同 RAND，每次重算都会变，定稿前记得粘贴为值

---

## SUMPRODUCT

**语法：** `SUMPRODUCT(数组1, [数组2], ...)` —— 对应元素相乘后求和

**参数说明：** 各数组维度必须一致；可实现多条件计数求和，是 SUMIFS 出现前的"万能函数"

**示例 1：** 计算总销售额（B 列单价 × C 列数量）
```
=SUMPRODUCT(B2:B100, C2:C100)
```

**示例 2：** 多条件计数：统计销售部且销售额>10000 的人数
```
=SUMPRODUCT((A2:A100="销售部")*(C2:C100>10000))
```
> 原理：条件判断生成 TRUE/FALSE 数组，相乘时自动转为 1/0

**常见错误：**
- 区域中混入文本会导致 `#VALUE!`（不像 SUM 那样自动忽略）
- 数组维度不一致返回 `#VALUE!`
- 数据量大时计算较慢，能用 SUMIFS 的场景优先用 SUMIFS

## SUBTOTAL

**语法：** `SUBTOTAL(功能代码, 区域1, [区域2], ...)`

**参数说明：**
- 功能代码：1=AVERAGE，2=COUNT，3=COUNTA，4=MAX，5=MIN，6=PRODUCT，7=STDEV，8=STDEVP，9=SUM，10=VAR，11=VARP
- 用 101~111（如 109）代替 1~11，可同时忽略**手动隐藏行**
- 最大特点：自动忽略**筛选隐藏行**，且忽略区域内其他 SUBTOTAL，避免重复计算

**示例 1：** 筛选后仍能正确求和（普通 SUM 会把隐藏行也加进去）
```
=SUBTOTAL(9, B2:B100)
```

**示例 2：** 分级汇总时避免重复：小计行用 SUBTOTAL，总计行再用 SUBTOTAL(9, ...) 汇总小计行，结果正确
```
=SUBTOTAL(109, B2:B100)   → 忽略手动隐藏行求和
```

**常见错误：**
- 功能代码写错区间（如写成 19）返回 `#VALUE!`
- 1~9 会计入手动隐藏行，101~109 才忽略；筛选隐藏行两者都忽略

---

## AGGREGATE

**语法：** `AGGREGATE(功能代码, 选项, 数组, [参数k])`

**参数说明：**
- 功能代码 1~19：1=AVERAGE … 9=SUM，12=MEDIAN，14=LARGE，15=SMALL 等
- 选项 0~7：0=忽略嵌套 SUBTOTAL 和 AGGREGATE；1=忽略隐藏行；2=忽略错误值；3=忽略隐藏行+错误值；6=忽略错误值（常用）
- 参数 k：LARGE/SMALL 等需要第 k 个值时使用

**示例 1：** 求和时自动跳过错误值（区域中有 #N/A 也不报错）
```
=AGGREGATE(9, 6, B2:B100)
```

**示例 2：** 忽略错误值求第二大值
```
=AGGREGATE(14, 6, B2:B100, 2)
```

**常见错误：**
- 比 SUBTOTAL 强大但参数更复杂，功能代码与 SUBTOTAL 不完全对应，注意查表
- 引用整列（如 B:B）时性能较差，尽量限定具体区域
