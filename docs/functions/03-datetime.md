# 日期时间函数大全

Excel 中日期本质是序列号（1900-1-1 为 1），时间是小数（中午 12 点 = 0.5）。理解这一点，日期函数就通了。本章共收录 16 个函数。


## 学习目标

学完本篇，你将能够：
- 理解日期是序列值、时间是小数，并用加减法算日期差
- 用 DATE、EDATE、EOMONTH 构造与推算日期
- 用 NETWORKDAYS 与 WORKDAY 算工作日
---

## TODAY

**语法：** `TODAY()` —— 返回今天的日期（无时间部分），无参数

**示例 1：** 计算距今天的天数（A2 为到期日）
```
=A2-TODAY()   → -312（设 A2=2026-01-01，以 2026-11-09 为今天；负数表示已过去 312 天）
```

**示例 2：** 标记 7 天内到期的任务
```
=IF(A2-TODAY()<=7, "即将到期", "正常")   → "即将到期"（设 A2=2026-11-12，以 2026-11-09 为今天；还剩 3 天，≤7 天）
```

**常见错误：**
- 每天打开文件都会变；需要固定日期请按 `Ctrl+;` 输入静态日期
- 易失性函数，大量使用影响性能

---

## NOW

**语法：** `NOW()` —— 返回当前日期+时间，无参数

**示例 1：** 记录操作时间戳
```
=NOW()   → 2026-11-09 22:22（示例值，每次重算都会更新）
```

**示例 2：** 只取当前时间部分
```
=NOW()-TODAY()   → 0.93（示例值，约 22:22；以 2026-11-09 22:22 为当前时间，设单元格格式为"时间"显示 22:22；每次重算都会变）
```

**常见错误：**
- 同 TODAY，每次重算都会更新；固定时间戳用 `Ctrl+Shift+;`
- 显示为日期时间格式，如只想看时间需改单元格格式

---

## DATE

**语法：** `DATE(年, 月, 日)` —— 组合成合法日期，自动处理溢出

**示例 1：** 组合年月日三列为日期（A2 年、B2 月、C2 日）
```
=DATE(A2, B2, C2)   → 2026-10-03（设 A2=2026、B2=10、C2=3）
```

**示例 2：** 利用溢出进位：DATE 自动把 13 月转为次年 1 月
```
=DATE(2026, 13, 1)   → 2027-1-1
```

**常见错误：**
- 年份用 4 位数；两位数年份按 1930~2029 窗口解析，易混淆
- 文本型年月日需先 VALUE 转换，否则可能 `#VALUE!`

---

## TIME

**语法：** `TIME(时, 分, 秒)` —— 组合成时间（0~0.999… 的小数）

**示例 1：** 组合时分秒列（A2=9, B2=30, C2=0）
```
=TIME(A2, B2, C2)   → 9:30
```

**示例 2：** 计算加班时长（下班 21:30，标准 18:00）
```
=TIME(21,30,0)-TIME(18,0,0)   → 0.1458，格式设为 [h]:mm 显示 3:30
```

**常见错误：**
- 超过 24 小时的时长显示要用 `[h]:mm` 格式，否则只显示余数

---

## YEAR

**语法：** `YEAR(日期)` —— 提取年份（4 位数）

**示例 1：** 按年份统计（配合 SUMIFS）
```
=YEAR(A2)   → 2026（设 A2=2026-10-03）
```

**常见错误：** 参数为文本型日期时可能 `#VALUE!`，先用 DATEVALUE 转换

---

## MONTH

**语法：** `MONTH(日期)` —— 提取月份 1~12

**示例 1：** 判断是否为本月
```
=MONTH(A2)=MONTH(TODAY())   → TRUE（设 A2=2026-11-05，以 2026-11-09 为今天；同月，判断为真）
```

**常见错误：**
- 文本型日期（如 "2026-10-03" 写在单元格里但格式是文本）会返回 #VALUE!，先用 DATEVALUE 转换
- MONTH 只返回 1~12 的月份，不含年份：跨年按月汇总时要和 YEAR 组合用

---

## DAY

**语法：** `DAY(日期)` —— 提取日 1~31

**示例 1：** 提取每月 1 号的数据
```
=DAY(A2)=1   → TRUE（设 A2=2026-11-01，日为 1，判断为真）
```

**常见错误：**
- 文本型日期返回 #VALUE!，先用 DATEVALUE 转成真日期
- DAY 只返回 1~31 的日，不含年月：按日汇总跨月时会混在一起，要和 YEAR/MONTH 组合

---

## HOUR

**语法：** `HOUR(时间)` —— 提取小时 0~23

**示例 1：** 判断打卡是否迟到（9 点后算迟到，A2 为打卡时间）
```
=HOUR(A2)>=9   → TRUE（设 A2=9:30，小时为 9，判断为真）
```

**常见错误：**
- 参数是日期（无时间部分）时 HOUR 返回 0，不是报错——先确认单元格里真有时分秒
- 时长超过 24 小时时 HOUR 只返回余数部分（如 25:30 返回 1），总时长用 [h]:mm 格式或 HOUR+DAY 组合

---

## MINUTE

**语法：** `MINUTE(时间)` —— 提取分钟 0~59

**示例 1：** 组合显示"X 小时 Y 分"（A2 为时长小数）
```
=HOUR(A2)&"小时"&MINUTE(A2)&"分"   → "9小时30分"（设 A2=9:30）
```

**常见错误：**
- HOUR/MINUTE 配合时注意：时长超过 24 小时 HOUR 只返回余数部分

---

## DATEDIF

**语法：** `DATEDIF(开始日期, 结束日期, 单位)`

**参数说明：**
- 单位："Y" 整年数，"M" 整月数，"D" 天数，"MD" 忽略年月的日差，"YM" 忽略年的月差，"YD" 忽略年的天差

**示例 1：** 计算周岁年龄（A2 为出生日期）
```
=DATEDIF(A2, TODAY(), "Y")   → 36（设 A2=1990-06-15，以 2026-11-09 为今天；满 36 周岁）
```

**示例 2：** 显示"X 岁 Y 个月"（入职年限）
```
=DATEDIF(A2, TODAY(), "Y")&"岁"&DATEDIF(A2, TODAY(), "YM")&"个月"   → "36岁4个月"（设 A2=1990-06-15，以 2026-11-09 为今天；36 年零 4 个月）
```

**常见错误：**
- 开始日期晚于结束日期返回 `#NUM!`
- 这是"隐藏函数"，输入时无智能提示，但所有版本都可用
- ⚠️ 微软明确警告：单位 "MD" 可能返回负数、零或不准确的结果，不建议使用；如 =DATEDIF("1990-06-15","2026-11-09","MD") 返回 -6（应为 25 天左右）。需要"忽略年月的日差"时改用可靠写法：结束日期-EDATE(开始日期,DATEDIF(开始日期,结束日期,"M"))
- 单位必须英文大写双引号

---

## EDATE

**语法：** `EDATE(开始日期, 月数)` —— 返回 n 个月前/后的同一天

**示例 1：** 计算 6 个月后的还款日（A2 为放款日）
```
=EDATE(A2, 6)   → 2027-04-03（设 A2=2026-10-03，6 个月后）
```

**示例 2：** 3 个月前
```
=EDATE(A2, -3)   → 2026-07-03（设 A2=2026-10-03，3 个月前）
```

**常见错误：**
- 月末日期顺延：EDATE(2026-1-31, 1) 返回 2026-2-28（自动取月末）
- 结果显示为序列号时，改单元格格式为日期

---

## EOMONTH

**语法：** `EOMONTH(开始日期, 月数)` —— 返回 n 个月前/后的**月末**日期

**示例 1：** 本月最后一天
```
=EOMONTH(TODAY(), 0)   → 2026-11-30（以 2026-11-09 为今天；本月月末）
```

**示例 2：** 判断 A2 是否为月末
```
=A2=EOMONTH(A2, 0)   → TRUE（设 A2=2026-10-31，本身就是月末，判断为真）
```

**常见错误：** 与 EDATE 混淆：EDATE 保"同一天"，EOMONTH 取"月末"

---

## WEEKDAY

**语法：** `WEEKDAY(日期, [类型])`

**参数说明：**
- 类型：1=周日为 1~周六为 7（默认）；2=周一为 1~周日为 7（最常用）；3=周一为 0~周日为 6

**示例 1：** 判断是否为周末（类型 2）
```
=WEEKDAY(A2, 2)>5   → FALSE（设 A2=2026-11-09（星期一），类型 2 下星期一为 1，不大于 5）
```

**示例 2：** 显示中文星期
```
=CHOOSE(WEEKDAY(A2, 2), "一","二","三","四","五","六","日")   → "一"（设 A2=2026-11-09（星期一））
```

**常见错误：**
- 类型 1 和 2 的周日起点不同，跨表复用公式时务必统一

---

## NETWORKDAYS

**语法：** `NETWORKDAYS(开始日期, 结束日期, [节假日区域])` —— 计算两个日期间的工作日天数（自动排除周末）

**示例 1：** 计算项目工作日（A2 开始、B2 结束）
```
=NETWORKDAYS(A2, B2)   → 5（设 A2=2026-11-02（周一）、B2=2026-11-06（周五）；5 个工作日）
```

**示例 2：** 排除法定节假日（D2:D10 为节假日列表）
```
=NETWORKDAYS(A2, B2, D2:D10)   → 4（设 A2=2026-11-02、B2=2026-11-06，D2:D10 节假日含 2026-11-04（周三），其余为空；去掉 1 天）
```

**常见错误：**
- 默认周末是周六日；中东等周五六休息的地区用 NETWORKDAYS.INTL
- 节假日区域中的日期若为文本格式会被忽略

---

## WORKDAY

**语法：** `WORKDAY(开始日期, 天数, [节假日区域])` —— 推算 n 个工作日后的日期

**示例 1：** 10 个工作日后的交货日期（A2 为今天）
```
=WORKDAY(A2, 10)   → 2026-11-20（设 A2=2026-11-06（周五），往后推 10 个工作日）
```

**示例 2：** 排除节假日
```
=WORKDAY(A2, 10, D2:D10)   → 2026-11-23（设 A2=2026-11-06，D2:D10 节假日含 2026-11-09（周一），其余为空；顺延 1 天）
```

**常见错误：**
- 天数可为负数，表示往前推算
- 结果为序列号时记得改日期格式

---

## DATEVALUE

**语法：** `DATEVALUE(日期文本)` —— 把文本转为日期序列号

**示例 1：** 转换 "2026-10-03" 为可计算的日期
```
=DATEVALUE("2026-10-03")   → 46298（文本日期转序列号）
```

**示例 2：** 清洗系统导出的文本日期后求差
```
=DATEVALUE(A2)-DATEVALUE(B2)   → 30（设 A2="2026-10-03"、B2="2026-09-03"，相差 30 天）
```

**常见错误：**
- 文本格式无法识别时返回 `#VALUE!`（如 "10月3日" 无年份可能失败）
- 转换后需设为日期格式，否则显示为 46298 这样的序列号（=DATEVALUE("2026-10-03") 的实际值；旧文案序列号有误，已纠正）

3. 2026-11-09 是星期几？=WEEKDAY(DATE(2026,11,9)) 返回几（默认周日=1）？
