# Excel 快捷键大全

- **适用场景**：所有人——快捷键是 Excel 效率的分水岭，每天省 30 分钟
- **难度**：★☆☆☆☆（记忆型，建议打印贴显示器旁）
- **说明**：以下均为 Windows 版。Mac 版把 Ctrl 换成 ⌘，Alt 换成 Option。

> 记忆窍门：先记标 ★ 的 20 个高频，其他的用时再查。

---

## 一、导航（14 个）

| 快捷键 | 功能 |
|--------|------|
| ★ `Ctrl + 方向键` | 跳到当前数据区域边缘（连续按穿越整张表） |
| ★ `Ctrl + Home` | 回到 A1 |
| ★ `Ctrl + End` | 跳到已用区域右下角 |
| `PageUp / PageDown` | 上/下翻一屏 |
| `Alt + PageUp / PageDown` | 左/右翻一屏 |
| `Ctrl + PageUp / PageDown` | 上一个/下一个工作表 |
| `F5` 或 `Ctrl + G` | 定位（跳到指定单元格/区域） |
| `Ctrl + Backspace` | 滚动回当前活动单元格（看丢了时用） |
| `Tab / Shift+Tab` | 右/左移一格 |
| `Enter / Shift+Enter` | 下/上移一格 |
| `Home` | 回到本行 A 列 |
| `Ctrl + F6` | 在多个打开的工作簿间切换 |

## 二、选择（14 个）

| 快捷键 | 功能 |
|--------|------|
| ★ `Ctrl + A` | 全选（在数据区按一次选当前区域，按两次选全表） |
| ★ `Shift + 方向键` | 按格扩展选区 |
| ★ `Ctrl + Shift + 方向键` | 扩展到数据区域边缘（选整列数据神器） |
| ★ `Ctrl + 空格` | 选中整列 |
| ★ `Shift + 空格` | 选中整行 |
| `Ctrl + Shift + *` | 选中当前数据区域（`*` 是数字 8 上档键） |
| `Shift + Home` | 选到行首 |
| `Ctrl + Shift + Home` | 从当前位置选到 A1 |
| `Ctrl + Shift + End` | 从当前位置选到已用区域末尾 |
| `F8` | 扩展模式开关（再按方向键持续扩展） |
| `Shift + F8` | 添加到选区（选多个不连续区域） |
| `Ctrl + 点击` | 加选不连续单元格 |
| `Ctrl + /` | 选中数组公式的整个数组区域 |

## 三、编辑（16 个）

| 快捷键 | 功能 |
|--------|------|
| ★ `Ctrl + C / X / V` | 复制/剪切/粘贴 |
| ★ `Ctrl + Z / Y` | 撤销/重做 |
| ★ `F2` | 进入单元格编辑（光标定位到内容末尾） |
| ★ `Ctrl + Enter` | 多个选中格一次填入相同内容 |
| ★ `Ctrl + D` | 向下填充（把上一格复制下来） |
| ★ `Ctrl + R` | 向右填充 |
| `Ctrl + ;` | 输入当前日期 |
| `Ctrl + Shift + ;` | 输入当前时间 |
| `Ctrl + '` | 复制上一格的公式（`'` 是单引号） |
| `Alt + Enter` | 单元格内换行 |
| `Delete` | 清除内容（保留格式） |
| `Ctrl + -` | 删除行/列（弹出对话框） |
| `Ctrl + Shift + +` | 插入行/列 |
| `Ctrl + K` | 插入超链接 |
| `F4` | 重复上一次操作（神技：插一行后按 F4 连插） |
| `Esc` | 取消正在输入/拖动 |

## 四、格式（12 个）

| 快捷键 | 功能 |
|--------|------|
| ★ `Ctrl + B / I / U` | 加粗/斜体/下划线 |
| ★ `Ctrl + 1` | 打开设置单元格格式对话框 |
| `Alt + H, H` | 打开颜色选择（填充色） |
| `Ctrl + Shift + ~` | 常规数字格式 |
| `Ctrl + Shift + $` | 货币格式（两位小数） |
| `Ctrl + Shift + %` | 百分比格式 |
| `Ctrl + Shift + #` | 日期格式（日-月-年） |
| `Ctrl + Shift + @` | 时间格式 |
| `Ctrl + Shift + !` | 千分位数值格式（两位小数） |
| `Ctrl + 9 / 0` | 隐藏行/隐藏列 |
| `Ctrl + Shift + 9 / 0` | 取消隐藏行/列 |

> 格式三连 `Ctrl+Shift+$/%/#` 记住：美元、百分、日期，调格式不用碰鼠标。

## 五、公式（14 个）

| 快捷键 | 功能 |
|--------|------|
| ★ `=` | 开始输入公式 |
| ★ `F4` | 切换引用方式（A1 → $A$1 → A$1 → $A1 循环） |
| ★ `Ctrl + Shift + Enter` | 输入数组公式（旧版本） |
| ★ `Alt + =` | 自动求和（SUM） |
| `Shift + F3` | 插入函数对话框 |
| `Ctrl + Shift + A` | 输入函数名后，插入参数名和括号 |
| `F9` | 计算所有工作表 |
| `Shift + F9` | 只计算当前工作表 |
| `Ctrl + `` ` `` | 显示公式/显示结果 切换（` 是 Tab 上方那个键） |
| `Ctrl + [` | 追踪引用单元格（跳到公式引用的格） |
| `Ctrl + ]` | 追踪从属单元格（谁引用了我） |
| `Esc` 后 `F9` 技巧 | 在编辑栏选中公式片段按 F9，查看该片段的计算结果（调试公式神器） |
| `Alt + Enter` | 公式太长时在编辑栏内换行（仅显示效果） |
| `Tab` | 输入函数名前几个字母后按 Tab，自动补全 |

## 效率组合示例

1. **整理导出数据**：`Ctrl+End` 看范围 → `Ctrl+Shift+方向键` 选中 → `Ctrl+T` 转表格 → `Alt+N,V` 建透视表。
2. **快速填列**：选中区域 → 输入内容 → `Ctrl+Enter` 一次填完。
3. **查公式错误**：`Ctrl+`` 显示所有公式 → `Ctrl+[` 跳引用格 → 编辑栏选片段 `F9` 看中间结果。
4. **去公式留值**：复制 → `Alt,E,S,V` → 回车。

> 建议：每周刻意练 5 个，一个月后鼠标使用量减半。
