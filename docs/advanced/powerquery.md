# Power Query：数据的"清洗车间"

- **适用场景**：每月重复的报表清洗（导出的 CSV 格式混乱、多文件合并、多表关联）、跨文件汇总
- **难度**：★★★☆☆（中级，M 语言部分 ★★★★☆）
- **版本要求**：Excel 2016 及以上内置（「数据」选项卡）；2013 需单独安装插件

---

## 1. Power Query 是什么

它是 Excel 里的一个**数据加工流水线**：你把"获取→清洗→整理"的每一步操作点一遍，Power Query 会把步骤记下来。下个月拿到新的源文件，点一下"刷新"，所有步骤自动重跑一遍。

和公式的区别：
- 公式是"算出一个结果"，Power Query 是"产出一张干净的表"。
- 公式适合行内计算；Power Query 适合**结构性整理**：拆分列、转置、合并文件、逆透视——这些用公式写会很痛苦。

核心观念：**你点的每一步都会变成一行 M 代码**，记录在右侧「应用的步骤」里。可以回头修改、删除、调整顺序。

## 2. 获取数据

「数据」→「获取数据」，来源非常多：

| 来源 | 典型场景 |
|------|----------|
| 从文本/CSV | 系统导出的 csv/txt |
| 从工作簿 | 合并多个 Excel 文件 |
| 从文件夹 | 把文件夹里所有同结构文件纵向拼起来（合并工资表神器） |
| 从数据库 | SQL Server/Access |
| 从 Web | 抓网页表格 |

选中来源后点「转换数据」进入 Power Query 编辑器，开始清洗。

## 3. 常用清洗步骤

### 拆分列
一列里混着"省-市-区"？选中列 →「拆分列」→「按分隔符」→ 输入 `-`。一列变三列。也可以按固定宽度、按大小写转换处拆分。

### 替换值
选中列 → 右键 →「替换值」：把"男/女"换成"M/F"，把"N/A"换成空。支持整列批量。

### 填充
导出的报表经常只有第一行有"部门"名，下面是空的（合并单元格拆开后的样子）。选中列 →「转换」→「填充」→「向下」。空单元格自动填上上方的值，透视表分组的前提。

### 更改类型
每列顶上有个类型图标（ABC/123/日历）。点它把文本改成数字、日期。**类型不对会导致求和变计数、日期无法分组**，清洗时务必检查。

### 删除重复项 / 筛选
选中列 →「删除重复项」。列标题的下拉箭头可以筛选、排序，和 Excel 里一样。

### 提取/格式
「添加列」→「从文本提取」：取前 N 个字符、取分隔符之间的内容。身份证号取前 6 位判断地区，一步搞定。

## 4. 合并查询：比 VLOOKUP 更强的关联

场景：A 表是订单（有"客户编号"），B 表是客户档案（"客户编号"→"客户名称"），想给订单带上客户名称。

1. 在编辑器里选中订单查询 →「合并查询」。
2. 上表选"客户编号"，下表选"客户档案"的"客户编号"（点列表头选中，两边都要点）。
3. 联接种类选"左外部"（保留订单全部行，档案对不上的留空——对应 VLOOKUP 的精确匹配）。
4. 确定后多出一列，点列头的展开按钮，勾选"客户名称"。

比 VLOOKUP 强的点：
- **可按多列关联**：Ctrl+点选多个列头，一次按"省+市"两列匹配，VLOOKUP 要拼辅助列。
- **模糊匹配**：联接时勾选"模糊匹配"，自动处理"北京"vs"北京市"这种差异，还能设相似度阈值。
- **左反/右反联接**：直接找出"有订单但无档案"的异常数据，做对账极方便。

## 5. 追加查询：纵向堆叠

场景：12 个月的销售表结构相同，要拼成一张全年表。

「追加查询」→ 选"三个或更多表" → 把 12 个表都加进来。列名相同的自动对齐，某表多出的列会以空值补齐。

**从文件夹追加**（更常用）：「获取数据」→「从文件夹」→ 选存放 12 个文件的文件夹 →「合并和转换」。以后每月往文件夹里丢新文件，刷新一次全进来——月报自动化。

## 6. 透视列与逆透视列

### 逆透视（Unpivot）：把交叉表"拆长"
源数据是"姓名×12个月"的矩阵（1 月、2 月…各一列），透视表吃不了这种格式。
选中 12 个月份列 → 右键 →「逆透视列」。变成三列：姓名、月份、销售额。**这是 Power Query 最经典的用途之一。**

### 透视列（Pivot）：反向操作
把"月份、销售额"两列转回交叉表：选中"月份"列 →「透视列」→ 值列选"销售额"、聚合选"求和"。

## 7. M 语言入门

你点的每一步，Power Query 都翻译成 M 语言，显示在顶部的公式栏。看懂它，就能做界面点不出来的事。

```m
let
    源 = Csv.Document(File.Contents("C:\data\销售.csv"), [Delimiter=",", Encoding=65001]),
    提升标题 = Table.PromoteHeaders(源),
    改类型 = Table.TransformColumnTypes(提升标题, {{"日期", type date}, {"金额", type number}}),
    筛选 = Table.SelectRows(改类型, each [金额] > 0)
in
    筛选
```

读法：
- `let...in`：定义一串中间变量，最后 `in` 后面的是输出。
- 每个步骤名（如 `提升标题`）都是一个变量，下一步引用上一步。
- `each [金额] > 0`：对每一行判断，`[金额]` 表示当前行的"金额"字段——相当于 M 里的 lambda。

常用手工写法：
```m
// 新增条件列（界面：添加列→条件列 点不出的复杂逻辑自己写）
Table.AddColumn(上一步, "等级", each if [金额] >= 10000 then "大" else "小")

// 按分隔符取第 2 段
Table.AddColumn(上一步, "城市", each Text.Split([地址], "-"){1})
```

`{1}` 是取列表第 2 个元素（从 0 开始数）。M 的列表、记录、表三种结构是核心，掌握 `each` 和 `[字段名]` 就能写 80% 的自定义步骤。

## 8. 实战流程示例：月度销售报表自动化

1. 每月系统导出 `销售2026-10.csv`，丢进 `D:\月报\` 文件夹。
2. 「从文件夹」获取，合并，得到原始表。
3. 清洗：提升标题 → 改类型（日期/数字）→ 填充部门 → 拆分"省-市" → 删除空行。
4. 合并查询客户档案带出客户名称。
5. 逆透视 12 个月份列（如果是交叉表）。
6. 「关闭并上载」→ 生成干净的表，上面做透视表出报表。
7. 下个月：新 CSV 丢进文件夹，右键刷新——全自动。

## 9. 注意事项

1. **步骤顺序敏感**：删列之后再引用该列的步骤会报错。改步骤前先看后面的步骤是否依赖它。
2. **文件路径**：M 代码里写死了 `C:\data\...`，文件挪位置要改源步骤。发布给别人用时注意。
3. **刷新要手动**：源文件变了，Excel 不会自动重算，必须右键「刷新」。
4. **先备份**：清洗是破坏性的（在查询里），原始文件不受影响——这是优点，但也意味着别把查询结果当唯一存档。
