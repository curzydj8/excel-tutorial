# 数组公式与动态数组

- **适用场景**：多条件求和计数、一次公式返回多个结果、去重/筛选/排序等"一公式多结果"需求
- **难度**：★★★★☆（中高级）
- **版本要求**：传统数组公式全版本可用；动态数组函数需 Microsoft 365 / Excel 2021

---

## 1. 先理解"数组"是什么

数组就是"一串值"。`{1,2,3}` 是横向数组，`{1;2;3}` 是纵向数组（分号换行）。Excel 公式本来就是按数组思维设计的：

```excel
=A1:A3 * 2
```

这行公式的含义是"把 A1、A2、A3 每个都乘以 2"，得到 `{A1*2, A2*2, A3*2}`。普通公式只显示第一个结果，数组公式则能把全部结果"摊开"显示。

## 2. 传统数组公式（Ctrl+Shift+Enter）

在旧版本 Excel 里，想让公式返回多个结果：

1. 先选中**多个**单元格（结果要占几格就选几格）。
2. 输入公式，如 `=A1:A3*2`。
3. 按 **Ctrl+Shift+Enter**（不是只按 Enter）。

公式两端会自动加上花括号 `{=A1:A3*2}`，表示这是数组公式。**花括号是 Excel 自己加的，手工输入无效。**

经典用途——多条件计数（COUNTIFS 出现之前的写法，现在仍有人用）：

```excel
{=SUM((A2:A100="销售部")*(B2:B100>5000))}
```

原理：`(A2:A100="销售部")` 得到一串 TRUE/FALSE，`(B2:B100>5000)` 得到另一串，两串相乘（TRUE=1、FALSE=0），只有两个条件都成立的位置是 1，SUM 加总即为同时满足的人数。

传统数组公式的麻烦：区域大小固定，源数据增删行要重选区域重按三键；别人接手容易误按 Enter 破坏公式。

## 3. 动态数组：新时代的写法

Microsoft 365 引入动态数组后，**只按 Enter**，结果自动"溢出"到相邻单元格。不再需要三键，也不再需要预选区域。

### FILTER：按条件筛选

```excel
=FILTER(A2:C100, B2:B100="销售部")
```

返回 B 列等于"销售部"的所有行（A:C 三列）。做"部门人员清单"一公式搞定，源数据增减行自动更新。

加"无结果"提示：

```excel
=FILTER(A2:C100, B2:B100="销售部", "该部门暂无人员")
```

### SORT：排序

```excel
=SORT(A2:C100, 3, -1)
```

按第 3 列降序排列。第三个参数 1=升序、-1=降序。

### UNIQUE：去重

```excel
=UNIQUE(B2:B100)
```

提取 B 列不重复值。做"部门列表"下拉源时极其好用，源数据新增部门，列表自动变长。

### SEQUENCE：生成序号

```excel
=SEQUENCE(10)
```

生成 1 到 10 的纵向序号。`=SEQUENCE(1,12)` 生成 1 到 12 的横向月份序号。配合其他函数做日历、编号。

### RANDARRAY：随机数组

```excel
=RANDARRAY(5, 3)
```

生成 5 行 3 列的 0~1 随机数。`=INT(RANDARRAY(10)*100)+1` 生成 10 个 1~100 的随机整数——抽奖、随机分组用。

### 组合技

```excel
=SORT(UNIQUE(B2:B100))
```

去重后再排序，一行公式得到干净有序的部门列表。

```excel
=FILTER(SORT(A2:C100,3,-1), C2:C100>10000)
```

先按金额降序，再筛出大于 10000 的——"销售额 Top 清单"一步到位。

## 4. #溢出! 错误处理

当动态数组的结果没地方"摊开"时，报 `#溢出!`。常见原因和解法：

| 原因 | 解法 |
|------|------|
| 下方单元格已有数据挡住 | 清空目标区域，或把公式移到空白处 |
| 合并单元格挡路 | 取消合并 |
| 引用了整列（如 A:A）导致无限循环 | 改用有限区域 A2:A1000 |
| 想引用溢出区域 | 用 `#` 号：`=SUM(A2#)` 表示" A2 开始的整个溢出区域" |

`#` 引用是动态数组时代的重要符号：公式结果变长变短，`A2#` 自动跟着变，SUM 永远求和的是最新结果。

## 5. 实战案例

### 案例 1：多条件求和（替代 SUMIFS 的数组思路）
统计"销售部"且"金额>5000"的总额：
```excel
=SUM((B2:B100="销售部")*(C2:C100>5000)*C2:C100)
```
普通 Enter 即可（365 会自动按数组算）。

### 案例 2：动态部门筛选器
```excel
=FILTER(员工表!A2:D500, 员工表!B2:B500=$F$1, "无匹配")
```
F1 做下拉选部门，右侧自动列出该部门所有人——简易查询系统。

### 案例 3：自动去重+计数
```excel
=ROWS(UNIQUE(A2:A1000))
```
A 列有多少个不重复的客户，一公式搞定。

### 案例 4：随机抽 5 人
```excel
=INDEX(A2:A100, SORTBY(SEQUENCE(ROWS(A2:A100)), RANDARRAY(ROWS(A2:A100))))
```
取前 5 行即随机 5 人。原理：给每行配一个随机数，按随机数排序后取前 5。

### 案例 5： cross 表转一维（配合 TOCOL）
```excel
=TOCOL(B2:M13)
```
把 12 个月的矩阵按列拼成一列，方便做透视表。TOCOL 是 365 的"转列"函数。

## 6. 新旧对照速查

| 需求 | 传统写法 | 动态数组写法 |
|------|----------|--------------|
| 多条件求和 | `{=SUM((条件1)*(条件2)*求和列)}` | `=SUM((条件1)*(条件2)*求和列)`（直接 Enter） |
| 提取不重复值 | 数组公式+INDEX+MATCH 嵌套 | `=UNIQUE(区域)` |
| 按条件列清单 | 高级筛选（手动） | `=FILTER(区域,条件)` |
| 排序 | 手动排序/复制 | `=SORT(区域,列,方向)` |
| 生成序号 | 下拉填充 | `=SEQUENCE(n)` |
