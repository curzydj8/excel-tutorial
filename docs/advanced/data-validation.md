# 数据验证与保护：从源头保证数据质量

- **适用场景**：多人协作录入、表单模板、下拉选部门/产品、防止误删公式
- **难度**：★★☆☆☆（初级，二级联动 ★★★☆☆）
- **版本要求**：全版本可用

---

## 1. 数据验证是什么

「数据」→「数据验证」。它在**输入的那一刻**拦截不合法的值，而不是事后检查。

三个可配置项：
1. **设置**：允许输入什么（整数/小数/日期/序列/文本长度…）。
2. **输入信息**：选中单元格时弹出的提示（"请输入 1-100 的整数"）——主动引导。
3. **出错警告**：输错时的弹窗，样式可选"停止"（硬拦截）/"警告"（可继续）/"信息"（仅提醒）。

## 2. 下拉列表（最常用）

### 固定选项
选中单元格 → 数据验证 → 允许「序列」→ 来源填 `男,女`（中文逗号不行，必须用**英文逗号**分隔）。单元格右侧出现下拉箭头。

### 引用区域
来源填 `=$F$2:$F$10`（部门清单）。清单变了下拉自动变。建议把清单放在单独的"基础数据"表，隐藏起来。

### 动态二级联动：选"省"后"市"跟着变
这是数据验证的经典难题，标准解法是 **INDIRECT + 命名区域**：

1. 准备对照表：A 列是省名（广东、江苏…），B 列开始每列是一个省的城市，第一行是省名。
2. 给每个省的城市区域**定义名称**：选中广东的城市 → 名称框输入 `广东` → 回车。注意名称不能含空格，省名有空格先替换。
3. A2 做一级下拉：来源 `=广东,江苏`（或引用省清单）。
4. B2 做二级下拉：来源填公式 `=INDIRECT($A$2)`。INDIRECT 把 A2 的文本"广东"转成对"广东"这个命名区域的引用。

原理：二级下拉的来源是一个**随一级变化的引用**，INDIRECT 是实现"文本转引用"的桥梁。

> 365 用户有更简单的写法：二级来源用 `=FILTER(城市表, 省列=$A$2)`，动态数组自动溢出，无需命名区域。

## 3. 输入限制

| 限制类型 | 设置示例 | 场景 |
|----------|----------|------|
| 整数 | 介于 1 到 100 | 年龄、数量 |
| 小数 | 大于 0 | 单价、折扣率 |
| 日期 | 介于 2026-01-01 到 2026-12-31 | 本年度日期 |
| 文本长度 | 等于 18 | 身份证号 |
| 自定义公式 | `=ISNUMBER(A1)` 等 | 任意逻辑 |

自定义公式的心法和条件格式一样：**相对左上角写**。选中 B2:B100 后公式写 `=LEN(B2)=11`，表示"本单元格长度必须 11"。

## 4. 圈释无效数据

数据验证只拦**新输入**，历史脏数据怎么办？「数据」→「数据验证」→「圈释无效数据」。所有违反规则的旧数据会被红圈圈出来，改完后「清除无效数据标识」去掉圈。

用途：接手别人的表，先圈一遍，脏数据一目了然。

## 5. 工作表保护：锁公式、开放录入区

场景：模板发给 20 个人填，只允许填黄色区域，公式列不许碰。

1. **先解锁录入区**：选中允许填写的单元格 → 右键「设置单元格格式」→「保护」→ **取消勾选"锁定"**。默认所有单元格都是"锁定"状态，但不保护时锁无效。
2. 「审阅」→「保护工作表」→ 设密码 → 勾选允许的操作（一般保留"选定未锁定的单元格"）。
3. 效果： locked 的公式格点不进去，未锁定的可填。有人想改公式？弹密码框。

取消：审阅 → 撤销工作表保护 → 输密码。

## 6. 允许编辑区域：多人分工

保护工作表是一刀切，"允许编辑区域"可以**按区域设不同密码**：

「审阅」→「允许编辑区域」→「新建」：
- 区域 A1:B10，密码 111 → 销售部用密码 111 可改
- 区域 C1:D10，密码 222 → 财务部用密码 222 可改

每人只能改自己的区，保护工作表后依然有效。适合部门分工录入同一张表。

## 7. 工作簿保护

- **保护工作簿结构**：「审阅」→「保护工作簿」→ 输密码。防止别人增删/移动/隐藏工作表。发模板时必做。
- **保护工作簿窗口**（旧版本）：防止窗口被移动缩放，现在意义不大。

## 8. 实战：设计一张防呆录入表

1. 部门列：一级下拉（引用基础数据表）。
2. 姓名列：二级联动（INDIRECT）。
3. 金额列：数据验证小数 >0，出错警告样式"停止"。
4. 日期列：介于本年度，输入信息提示"请选今年内的日期"。
5. 合计列：公式，整列锁定。
6. 保护工作表（密码），只开放前 4 列。
7. 发出去之前，「圈释无效数据」自查一遍。

这样收回来的表：无空值、无错别字（下拉保证）、无非法数字，汇总时零清洗。

## 9. 注意事项

1. **验证可被绕过**：复制粘贴能跳过数据验证！重要模板配合工作表保护，或事后用「圈释无效数据」检查。
2. **密码强度**：Excel 工作表保护密码防君子不防小人，真有机密用文件级加密（文件→信息→保护工作簿→用密码进行加密）。
3. **先验证后保护**：顺序别反——先设好所有验证和锁定状态，最后一步才是保护工作表。
4. **下拉箭头不打印**：放心，下拉箭头只是屏幕元素，打印/导出 PDF 不会出现。
