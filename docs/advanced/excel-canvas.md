# Excel Canvas（Copilot 画布）

- **适用场景**：月报/周报做腻了手动拼图表的人——让 Copilot 把整本工作簿变成一张"活的"可视化看板
- **难度**：★★☆☆☆（初级，会跟 Copilot 说话就行）
- **版本要求**：Microsoft 365（Excel for Windows 最新 Current Channel 渠道 / Excel for the web），且账号开通了 Copilot in Excel
- **状态**：截至 2026-10-13，微软正在分批推送（预计 10 月底完成）。Insider 渠道用户已可看到 Canvas；如果你打开 Copilot 还没看到，不是你操作错了，是推送还没轮到你的账号。

---

## 1. 这是什么

Excel Canvas 是微软在 Microsoft 365 路线图（编号 **569424**，2026-09-01 公布）上推出的一项 Copilot 能力：

> Copilot 根据工作簿里的数据，自动生成一个"画布"——里面是关键图表、核心指标和洞察文字，**排版好、能交互**。

和以前"让 Copilot 做个图"最大的区别：

| 旧方式 | Excel Canvas |
|--------|--------------|
| 问一次，给一张静态图 | 生成一个**持续存在**的看板视图 |
| 数据一改，图立刻过时 | 画布**连着数据源**，改单元格→图表自动更新 |
| 想改样式得重新问、重新生成 | 直接在对话里说"把销售额改成柱状图"，画布**就地调整** |

一句话：以前 Copilot 给你的是**快照**，Canvas 给你的是**活的报表**。

## 3. 使用前置条件（缺一不可）

1. **账号有 Copilot in Excel 权限**——这是硬门槛。个人版/家庭版用户先别急，微软目前只明确了商业侧的推送，消费级订阅是否在范围内还没说清楚。
2. **Excel 是最新版**：Windows 端用 Current Channel 渠道并更新到最新；或者直接用网页版 Excel（web）。
3. **工作簿里有规整的数据表**：第一行是标题行、无合并单元格——和数据透视表要求的数据规范一模一样（见 [数据透视表 §2](pivottable.md#2-创建步骤)）。

## 4. 基本操作

推送到位后，流程是这样的：

1. 打开含有数据的工作簿。
2. 打开 Copilot 窗格。
3. 用自然语言说：**"根据这张表的数据创建一个画布（canvas）"**（英文界面可用 "Create a canvas from this data"）。
4. Copilot 自动生成：关键图表 + 核心指标卡 + 一段文字洞察。
5. **对照源数据抽查**一遍图表和数字，确认无误再分享——AI 生成的数字永远先验后信。
6. 想调整不用重做，直接在对话里继续提要求（见下一节）。

## 5. 对话式调整：常用说法

画布生成后，它就是你的"报表设计师"，你只管动嘴：

- "把月度销售额改成柱状图，按产品分颜色"
- "加上环比增长率的指标卡"
- "只保留华东区的数据"
- "这个饼图太挤了，换成条形图"
- "给我一段 50 字以内的总结，放在最上面"

技巧：**一次只改一件事**。Copilot 对"改 A 又改 B 还要加 C"的长指令容易顾此失彼，拆成三句效果更好。

## 6. 它和透视表 / Power Query 是什么关系

三者不是替代关系，是分工：

| 工具 | 擅长 | 定位 |
|------|------|------|
| 数据透视表 | 分组汇总、交叉分析 | **算数**：把明细算成结论 |
| Power Query | 多文件清洗、合并、逆透视 | **备料**：把脏数据洗成规范表 |
| Excel Canvas | 把结论变成好看的、自动更新的看板 | **呈现**：把算好的东西讲清楚 |

推荐工作流：Power Query 洗数据 → 透视表做汇总 → Canvas 一键生成月报看板。Canvas 吃的就是你前面两步做好的规范表。

## 7. 避坑

1. **没推送到就别折腾**：没有任何开关可以"提前开启"，更新到最新版、等推送是唯一路径。
2. **订阅范围不明**：微软没说清哪些订阅能用。如果你是个人版用户，先按"暂无"预期，别为此买 Copilot 授权。
3. **AI 的数字先验后信**：分享给老板之前，对着源数据抽查关键数字。Canvas 排版再漂亮，数字错了就是事故。
4. **别拿它做一次性分析**：只看一次的数据，直接问 Copilot 要结论更快；Canvas 的价值在于"**每月都要看、数据每月都变**"的报表。
5. **源数据规范是前提**：合并单元格、标题行缺失、"合计"行混在明细里——这些在透视表里会出的问题，在 Canvas 里一样会出。先按 [数据透视表 §2](pivottable.md#2-创建步骤) 把表整理好。
6. **别跟已下线的 `=COPILOT()` 搞混**：那个写在单元格里的 Copilot 函数已于 2026-09-14 停止服务（微软决定不再推向 GA）；Canvas 是 Copilot 窗格里的画布能力，两者不是一回事。

## 8. 同期发布的相关新功能（教程站待写选题）

2026-10-13 微软在同一批公告里还发布了四个相关功能（据 Neowin 转述，原文见页脚链接），个个都值得单独成篇教程：

1. **Skill Builder**（2026 年 10 月 GA）：把重复工作流「说」成可复用技能——用对话描述流程、给指令、贴历史提示词或已完成示例，Copilot 把它转成技能，以后 @ 一下就能复用。
2. **Skill Recorder**（2026 年 10 月底进 Insider）：说不清流程就直接演示——在 Excel 里把操作做一遍，Copilot 录下来转成可复用技能。
3. **Get Data**（10 月中旬 GA，先上 Excel for the web）：用自然语言描述「要什么数据、从哪来、长什么样」，替代过去手搭 Power Query 查询的方式。
4. **Clean Data**（10 月开始推送）：自动指出常见数据质量问题——重复记录、格式不一致、类型错误（比如同一列里混着 "USA"、"US"、"United States"），并给出修正建议。

注意：这四个的实机验证同样适用「等推送到位」原则——写教程前先确认自己 Excel 里能看到，草稿阶段不发布。
