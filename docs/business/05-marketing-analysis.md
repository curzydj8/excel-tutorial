## 2. 基础概念

### 2.1 营销漏斗：四级转化

营销漏斗是把“从看到广告到最终成交”的过程画成逐级收窄的漏斗。本篇示例季度漏斗共四级：

| 阶段 | 人数 | 本级转化率 | 流失人数 |
|---|---|---|---|
| 曝光 | 50000 | — | — |
| 点击 | 8000 | 8000 / 50000 = 16.00% | 42000 |
| 咨询 | 2400 | 2400 / 8000 = 30.00% | 5600 |
| 成交 | 480 | 480 / 2400 = 20.00% | 1920 |

各级人数必须递减：50000 > 8000 > 2400 > 480。哪一级人数比上一级大，数据一定录错了，先查数据源，不要急着画图。

总转化率是成交人数除以曝光人数：480 / 50000 = 0.96%。它等于三级转化率逐级相乘：16.00% × 30.00% × 20.00% = 0.96%。这个等式是漏斗表的自检算式：乘出来不等于总转化率，说明某一级的转化率算错了。

### 2.2 漏斗图：2019 新增的图表

漏斗图是 Excel 2019 新增的图表类型，专为逐级减少的数据设计：居中对称、没有坐标轴，每段的宽度对应人数。做法是选中阶段与人数两列，插入 → 漏斗图。2016 及更早版本没有内置漏斗图，用居中条形图模拟（见 C07 图表大全“新图表类型”篇的漏斗图一节）。

现成的图表-漏斗图模板.xlsx（templates/图表-漏斗图模板.xlsx）可直接套用：把本篇四级人数填进去，图自动生成。不要把漏斗图与条形图混用：漏斗图只适合转化流程，条形图适合一般比较。

### 2.3 渠道效果对比：ROI 是第一指标

渠道是指花钱获客的地方。本篇示例季度有 3 个渠道：

| 渠道 | 投入（元） | 线索（条） | 成交（单） | 收入（元） |
|---|---|---|---|---|
| 搜索引擎广告 | 20000 | 900 | 180 | 90000 |
| 短视频推广 | 15000 | 900 | 150 | 60000 |
| 内容/社群运营 | 8000 | 600 | 150 | 54000 |
| 合计 | 43000 | 2400 | 480 | 204000 |

渠道表的线索合计 2400 条等于漏斗的咨询 2400 人，成交合计 480 单等于漏斗的成交 480 人，两张表互相印证。线索是指留下联系方式的潜在客户，咨询是漏斗里的同一批人换了个名字：渠道表按来源分，漏斗表按阶段分。

ROI（投资回报率）的公式是：ROI = (收入 - 成本) / 成本。收入不是利润：收入 90000、投入 20000 的渠道，ROI 是 (90000 - 20000) / 20000 = 350.00%，不是 90000 / 20000 = 450%。把收入直接除以成本会把本金也算成回报，是常见错误。

### 2.4 活动复盘表：达成率与 ROI 一起看

活动复盘表是按单场活动算效果，与渠道表是两种切分口径：渠道表按“钱花在哪”分，活动复盘表按“活动是哪场”分。本篇示例季度复盘三场活动：

| 活动 | 目标线索 | 实际线索 | 线索达成率 | 目标成交 | 实际成交 | 成交达成率 | 投入（元） | 收入（元） | ROI |
|---|---|---|---|---|---|---|---|---|---|
| 双十一预热直播 | 1000 | 1150 | 115.0% | 150 | 168 | 112.0% | 12000 | 67200 | 460.00% |
| 短视频挑战赛 | 800 | 720 | 90.0% | 120 | 96 | 80.0% | 9000 | 38400 | 326.67% |
| 老客户转介绍 | 500 | 640 | 128.0% | 100 | 132 | 132.0% | 5000 | 58080 | 1061.60% |
| 三场合计 | 2300 | 2510 | 109.13% | 370 | 396 | 107.03% | 26000 | 163680 | 529.54% |

达成率是实际除以目标：1150 / 1000 = 115.0%，超过 100% 就是超额完成。复盘要达成率与 ROI 一起看：只看达成率会漏掉成本，只看 ROI 会漏掉目标。

### 2.5 三张表的口径差异：为什么不能直接相加

三张表数字各有归属，不能直接相加，原因有三条：

第一，活动复盘表的线索合计 2510 条大于渠道表的线索合计 2400 条，是因为活动口径含重复触达：同一个人参加了直播又参加了挑战赛，在活动表里计两次，在渠道表里按首次来源只计一次。复盘表看单场活动效果，不与渠道表直接相加。

第二，活动复盘表的成交合计 396 单小于渠道表的成交合计 480 单，是因为复盘表只覆盖三场重点活动，不是全部营销投入；其余 84 单来自日常投放，没有单独立项复盘。

第三，漏斗表是全量口径：曝光 50000 人是全部渠道的曝光之和，成交 480 单是全部渠道的成交之和。渠道表是漏斗表的分来源展开，两张表的合计数必须相等（线索 2400、成交 480），不等就是数据错了。

## 3. 操作步骤

以下步骤按配套示例文件“示例-市场营销分析.xlsx”的三张表操作：漏斗数据、渠道对比、活动复盘。

1. 新建工作簿，把第一张表命名为“漏斗数据”，建三列：阶段、人数、转化率。填入四级人数：曝光 50000、点击 8000、咨询 2400、成交 480。人数列设为数值格式，不要用文本。（待补图）
2. 在转化率列写公式：点击行的公式是 `=B3/B2`，结果为 16.00%；咨询行 `=B4/B3`，结果为 30.00%；成交行 `=B5/B4`，结果为 20.00%。公式里的分子是本级人数、分母是上一级人数，不要写反。（待补图）
3. 在表下方加一行“总转化率”，公式是 `=B5/B2`，结果为 0.96%。再加一行自检算式 `=C3*C4*C5`，结果同样为 0.96%。两个数一致，漏斗表自检通过；不一致时逐级检查转化率公式。（待补图）
4. 加一列“流失人数”，公式是上一级人数减本级人数：点击行 `=B2-B3`，结果为 42000；咨询行 `=B3-B4`，结果为 5600；成交行 `=B4-B5`，结果为 1920。流失人数最大的环节是曝光到点击，绝对数 42000 人。（待补图）
5. 选中阶段与人数两列，插入漏斗图（Excel 2019 / 2021 / 365）；2016 及更早版本按 C07“新图表类型”篇的做法用居中条形图模拟。也可以直接打开图表-漏斗图模板.xlsx（templates/图表-漏斗图模板.xlsx），把四级人数填进去对照。（待补图）
6. 新建第二张表“渠道对比”，建六列：渠道、投入、线索、成交、收入、ROI。填入 3 个渠道的投入、线索、成交、收入（见 2.3 节的表）。（待补图）
7. 在 ROI 列写公式：搜索引擎行 `=(E2-B2)/B2`，结果为 350.00%；短视频行结果为 300.00%；社群行结果为 575.00%。再加三列辅助指标：线索成本 `=投入/线索`、获客成本 `=投入/成交`、客单价 `=收入/成交`，结果见 5.4 节。（待补图）
8. 在渠道对比表下方加一行“合计”，投入、线索、成交、收入四列用 SUM 求和：43000、2400、480、204000。合计 ROI 的公式是 `=(204000-43000)/43000`，结果为 374.42%，不要用三个渠道 ROI 的简单平均（408.33%），简单平均不区分投入大小，是错的。（待补图）
9. 核对渠道表与漏斗表的勾稽关系：渠道线索合计 2400 必须等于漏斗咨询 2400，渠道成交合计 480 必须等于漏斗成交 480。用公式 `=渠道合计单元格-漏斗对应单元格` 算差异，结果为 0 才算对上。（待补图）
10. 新建第三张表“活动复盘”，建十列：活动、目标线索、实际线索、线索达成率、目标成交、实际成交、成交达成率、投入、收入、ROI。填入三场活动的数据（见 2.4 节的表）。（待补图）
11. 达成率列写公式：线索达成率 `=实际线索/目标线索`，双十一预热直播为 1150 / 1000 = 115.0%；成交达成率 `=实际成交/目标成交`，老客户转介绍为 132 / 100 = 132.0%。ROI 列公式与第 7 步相同。（待补图）
12. 在活动复盘表下方加一行“合计”：目标线索 2300、实际线索 2510、达成率 109.13%；目标成交 370、实际成交 396、达成率 107.03%；投入 26000、收入 163680、ROI 529.54%。合计行的达成率用合计实际除以合计目标算，不要用三场达成率的平均值。（待补图）

## 5. 公式和代码

### 5.1 各级转化率

```excel
=8000/50000 → 16.00%
=2400/8000 → 30.00%
=480/2400 → 20.00%
```

三级转化率分别是点击率、咨询率、成交率。分子是本级人数，分母是上一级人数。

### 5.2 总转化率与逐级相乘自检

```excel
=480/50000 → 0.96%
=16%*30%*20% → 0.96%
```

两个算式结果一致，漏斗表自检通过。注意第二个算式里写的是转化率本身相乘（0.16 × 0.30 × 0.20 = 0.0096），不是人数相乘。

### 5.3 ROI

```excel
=(90000-20000)/20000 → 350.00%
=(60000-15000)/15000 → 300.00%
=(54000-8000)/8000 → 575.00%
=(204000-43000)/43000 → 374.42%
```

前三行是三个渠道的 ROI，第四行是合计 ROI。合计 ROI 用合计收入与合计投入算，不要用 350.00%、300.00%、575.00% 的简单平均（408.33%）。

### 5.4 线索成本、获客成本与客单价

```excel
=20000/900 → 22.22
=15000/900 → 16.67
=8000/600 → 13.33
=20000/180 → 111.11
=15000/150 → 100.00
=8000/150 → 53.33
=90000/180 → 500
=60000/150 → 400
=54000/150 → 360
```

前三行是三个渠道的线索成本（元/条），中间三行是获客成本（元/单），后三行是客单价（元）。合计口径：线索成本 43000 / 2400 = 17.92 元/条，获客成本 43000 / 480 = 89.58 元/单，平均客单价 204000 / 480 = 425.00 元。三个渠道客单价不同（500、400、360 元），是因为各渠道带来的客户买的产品组合不同，不是算错了。

### 5.5 流失人数与流失率

```excel
=50000-8000 → 42000
=8000-2400 → 5600
=2400-480 → 1920
=42000/50000 → 84.00%
=5600/8000 → 70.00%
=1920/2400 → 80.00%
```

前三行是各级流失人数，后三行是各级流失率。曝光到点击的流失率 84.00% 是三级里最高的，优化优先级排第一。

### 5.6 达成率

```excel
=1150/1000 → 115.0%
=720/800 → 90.0%
=640/500 → 128.0%
=168/150 → 112.0%
=96/120 → 80.0%
=132/100 → 132.0%
```

前三行是三场活动的线索达成率，后三行是成交达成率。达成率超过 100% 是超额完成，低于 100% 是未达标。

### 5.7 活动复盘合计

```excel
=2510/2300 → 109.13%
=396/370 → 107.03%
=(163680-26000)/26000 → 529.54%
```

三场活动合计：线索达成率 109.13%，成交达成率 107.03%，合计 ROI 529.54%。合计达成率用合计实际除以合计目标算，不要用三场达成率的平均值（(115.0% + 90.0% + 128.0%) / 3 = 111.00%，是错的）。

### 5.8 漏斗图数据准备：占比列

```excel
=8000/50000 → 16.00%
=2400/50000 → 4.80%
=480/50000 → 0.96%
```

如果要在漏斗图旁边加一列“占曝光比例”，点击占 16.00%，咨询占 4.80%，成交占 0.96%。这列的分母都是曝光 50000，不是上一级人数，不要与 5.1 节的各级转化率混淆。

## 6. 实际工作场景

### 场景一：季度复盘会上的渠道预算再分配

市场部经理每季度开一次复盘会，决定下季度 43000 元预算怎么分。以前凭感觉分：哪个渠道声音大就多分点，结果 ROI 越来越低。

做法：经理按本篇建了漏斗与渠道两张表。本季度数据是：社群 ROI 575.00% 最高、获客成本 53.33 元最低；搜索收入最高（90000 元）但 ROI 只有 350.00%；短视频 ROI 最低（300.00%）。

结果：下季度预算调整为社群 15000 元、搜索 18000 元、短视频 10000 元，社群追加 7000 元、短视频削减 5000 元。假设各渠道 ROI 不变，预期收入为 15000 × (1 + 575.00%) + 18000 × (1 + 350.00%) + 10000 × (1 + 300.00%) = 101250 + 81000 + 40000 = 222250 元，比本季度 204000 元多 18250 元。这个预期数的前提是 ROI 不变，写进会议纪要时要注明是测算不是承诺。

### 场景二：双十一预热直播的复盘与再办决策

双十一预热直播结束后，市场专员要在一页纸里回答“这场直播值不值、下一场办不办”。

做法：专员按本篇建活动复盘表。直播数据是：目标线索 1000、实际 1150，达成率 115.0%；目标成交 150、实际 168，达成率 112.0%；投入 12000 元、收入 67200 元，ROI 460.00%。再对照漏斗：直播带来的 1150 条线索里有 168 单成交，线索成交率为 168 / 1150 = 14.61%，低于全渠道平均 20.00%。

结果：结论是“值得再办，但要改跟进方式”。直播的量超额了，质拖了后腿：线索成交率 14.61% 比平均低 5.39 个百分点。下一场直播保留投放打法，成交跟进从“统一群发”改成“按咨询问题分三组跟进”，目标是把线索成交率提到 18% 以上。复盘表同时给了“办不办”的结论与“怎么改”的方向，这才是复盘表该有的样子。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 漏斗某一级人数比上一级大 | 数据录错，或两级口径不一致 | 先核对数据源；各级人数必须递减，不递减不要画图 |
| 总转化率与逐级相乘对不上 | 某一级转化率的分子分母写反 | 各级转化率 = 本级人数 / 上一级人数；用 5.2 节两个算式互相核对 |
| ROI 算成 450% 而不是 350% | 把收入直接除以成本，忘了减本金 | ROI = (收入 - 成本) / 成本；收入 90000、成本 20000 时为 350.00% |
| 合计 ROI 用三个渠道 ROI 的平均值 | 简单平均不区分投入大小 | 合计 ROI 用合计收入与合计投入算，本例为 374.42%，不是 408.33% |
| 活动合计与渠道合计对不上就改数 | 两张表口径不同，活动表含重复触达、只覆盖重点活动 | 按 2.5 节写清口径差异，不要为了对齐而改原始数据 |
| 漏斗图在 Excel 2016 里找不到 | 漏斗图是 2019 新增，2016 没有 | 2016 用居中条形图模拟，或直接用图表-漏斗图模板.xlsx 对照做法 |
| 只看收入排渠道优先级 | 收入高可能是投入高，不代表效率高 | 排优先级看 ROI 与获客成本：本例社群 ROI 575.00% 第一，搜索收入最高但 ROI 只有 350.00% |
| 达成率合计用三场平均值 | 合计达成率是合计实际除以合计目标 | 线索合计达成率为 2510 / 2300 = 109.13%，不是三场平均 111.00% |
| 线索成本与获客成本混用 | 线索成本是每条线索的钱，获客成本是每单成交的钱 | 线索成本 = 投入 / 线索，获客成本 = 投入 / 成交；本例合计分别为 17.92 与 89.58 元 |

## 9. 练习题

1. 某季度漏斗为曝光 40000、点击 6000、咨询 1800、成交 360。算出三级转化率与总转化率，并验证逐级相乘是否等于总转化率。
2. 某渠道投入 12000 元、收入 48000 元，ROI 是多少？写出算式。另一个渠道投入 6000 元、收入 30000 元，ROI 是多少？哪个渠道效率更高？
3. 内容/社群运营的 ROI 是 575.00%，搜索引擎广告是 350.00%。如果只看收入，搜索引擎广告 90000 元高于社群 54000 元，为什么追加投入的优先级仍是社群第一？
4. 如果咨询到成交的转化率从 20.00% 提高到 25.00%，咨询人数仍为 2400 人，成交会变成多少单？比原来多多少单？
5. 短视频挑战赛的目标成交是 120 单、实际 96 单，成交达成率是多少？还差几单达标？
6. 漏斗三级的流失率分别是 84.00%、70.00%、80.00%，绝对流失人数分别是 42000、5600、1920 人。优化优先级应该先看绝对数还是先看相对数？本例的结论是什么？

## 10. 参考答案

<details>
<summary>点击查看答案</summary>

1. 点击率 6000 / 40000 = 15.00%，咨询率 1800 / 6000 = 30.00%，成交率 360 / 1800 = 20.00%，总转化率 360 / 40000 = 0.90%。逐级相乘 15.00% × 30.00% × 20.00% = 0.90%，与总转化率一致。
2. 第一个渠道 ROI 为 (48000 - 12000) / 12000 = 300.00%。第二个渠道 ROI 为 (30000 - 6000) / 6000 = 400.00%。第二个渠道效率更高，虽然收入更低，但单位投入产出更高。
3. 因为排优先级看的是效率不是规模。社群 ROI 575.00% 高于搜索 350.00%，获客成本 53.33 元低于搜索 111.11 元，同样 1 万元投给社群预期回报更高。搜索收入高是因为投入 20000 元是社群 8000 元的 2.5 倍，不是效率高。
4. 成交变为 2400 × 25.00% = 600 单，比原来 480 单多 120 单。也可以按总转化率算：16.00% × 30.00% × 25.00% = 1.20%，50000 × 1.20% = 600 单，结果一致。
5. 成交达成率为 96 / 120 = 80.0%，还差 120 - 96 = 24 单达标。
6. 两个都要看，本例结论一致：曝光到点击的流失绝对数最大（42000 人），流失率也最高（84.00%），优化优先级排第一。如果绝对数与相对数指向不同环节，要优先看绝对数大的环节，因为那里改进的收益人数最多。
