## 2. 基础概念

### 2.1 花名册是人事数据的源头

花名册是一张表管全部员工：工号、姓名、部门、岗位、入职日期、基本工资、绩效奖金、出勤天数。所有下游表格（考勤汇总、工资条）都从花名册查数据，不许各表各填一份——两份名单一定会对不上。

三列格式红线：工号如果含字母（如 E001）用文本格式，纯数字工号也要用文本格式（否则前面的 0 会被吃掉）；入职日期必须是日期格式，才能用 DATEDIF 算工龄；基本工资必须是数值格式，文本格式的数字 SUM 求和会漏掉。

### 2.2 考勤统计的口径

本篇月应出勤 22 天。10 人小案例出勤总天数 212 天，应出勤 220 天，缺勤 8 天，出勤率 = 212 / 220 = 96.36%。全勤 5 人，每人全勤奖 300 元，合计 1500 元。

考勤样本文件是另一套口径：550 条记录里正常 448 人次、迟到 86 人次、请假 16 人次，迟到率 = 86 / 550 = 15.64%。注意"人次"与"人数"的区别：同一个人一个月迟到 8 次，算 8 人次、1 人。样本里迟到最多的是高翔 8 次、李明 7 次。

### 2.3 工资条的计算链

实发工资 = 基本工资 + 绩效奖金 - 社保个人部分 - 个税。本篇口径：社保个人部分 = 基本工资 x 11%，个税按给定值直接取用（不展开算税过程，个税计算另见财务函数篇）。10 人合计：基本工资 87800 元、绩效奖金 20600 元、社保 9658 元、个税 4070 元、实发工资 94672 元，人均实发 9467.20 元。

### 2.4 VLOOKUP 与 XLOOKUP

- **VLOOKUP**：按首列查，返回指定列。老版本通用，但只能从左往右查，插入列会错位。
- **XLOOKUP**：按任意列查，默认精确匹配，可从右往左查，找不到可指定默认值。需要 Excel 2021 或 Microsoft 365。

本篇工资条用 VLOOKUP 写（兼容 2016），同时给出 XLOOKUP 的等价写法，两个结果必须一致。

### 2.5 人员结构分析：先看人，再算钱

算工资之前先看结构，10 人小案例的结构是：

- **部门分布**：销售部 4 人（40%）、技术部 4 人（40%）、行政部 2 人（20%）。
- **平均基本工资**：销售部 7675 元、技术部 11325 元、行政部 5900 元。技术部平均基本工资最高，比行政部高出 5425 元。
- **实发工资分布**：技术部合计 48447 元，占实发总额的 51.17%；销售部 33743 元，占 35.64%；行政部 12482 元，占 13.18%。

结构分析的意义：技术部人均成本最高，管工资总额先看技术部；销售部 4 个人的绩效奖金合计 7500 元，占绩效总额的 36.41%，绩效占比高说明销售岗的浮动部分大，考核口径一变，实发波动也大。

## 3. 操作步骤

本节以配套模板文件 `示例-人力资源管理.xlsx` 为操作对象，花名册在第 3 行到第 12 行，考勤汇总与工资条用公式引用花名册。

1. 建花名册：新建"花名册"工作表，列是工号、姓名、部门、岗位、入职日期、基本工资、绩效奖金、出勤天数、个税。填入 10 名员工，工号 E001 至 E010，入职日期设成日期格式，基本工资、绩效奖金、个税设成数值格式。底部合计行：基本工资 `=SUM(F3:F12)` → 87800，绩效奖金 `=SUM(G3:G12)` → 20600（待补图）。
2. 做考勤汇总：新建"考勤汇总"工作表，姓名列用 `=花名册!B3` 引用，部门列用 `=花名册!C3` 引用，应出勤填 22，实际出勤用 `=花名册!H3` 引用，缺勤用 `=C3-D3`，出勤率用 `=D3/C3`，全勤奖用 `=IF(D3=C3,300,0)`。合计行检查出勤总天数 212、出勤率 96.36%、全勤奖总额 1500（待补图）。
3. 加部门汇总：在考勤汇总表下方做部门汇总区，人数用 `=COUNTIF(花名册!$C$3:$C$12,A17)`，出勤合计用 `=SUMIF(花名册!$C$3:$C$12,A17,花名册!$H$3:$H$12)`，平均出勤用 `=C17/B17`，实发合计用 `=SUMIF(工资条!$B$3:$B$12,A17,工资条!$G$3:$G$12)`。销售部 4 人、技术部 4 人、行政部 2 人（待补图）。
4. 做工资条：新建"工资条"工作表，姓名列用 `=花名册!B3` 引用，部门、基本工资、绩效奖金、个税四列用 VLOOKUP 查花名册，例如基本工资 `=VLOOKUP(A3,花名册!$B$3:$I$12,5,FALSE)` → 8000（张伟）。社保列用 `=ROUND(C3*11%,0)` → 880，实发列用 `=C3+D3-E3-F3` → 8820。合计行检查实发合计 94672（待补图）。
5. 核对勾稽：工资条合计行验算 `基本合计 + 绩效合计 - 社保合计 - 个税合计 = 实发合计`，即 87800 + 20600 - 9658 - 4070 = 94672；考勤汇总部门实发合计（销售部 33743 + 技术部 48447 + 行政部 12482）也要等于 94672。任何一处不等，先查 VLOOKUP 的列序号（待补图）。
6. 练大文件统计：打开 `数据-人事考勤样本.xlsx`，在"部门汇总"表看现成的 COUNTIFS 与 AVERAGEIF 公式：迟到人次 `=COUNTIFS(考勤记录!C:C,A2,考勤记录!I:I,"迟到")`，平均迟到分钟 `=ROUND(AVERAGEIF(考勤记录!C:C,A2,考勤记录!G:G),1)`，请假人次 `=COUNTIFS(考勤记录!C:C,A2,考勤记录!I:I,"请假")`。再用数据透视表按"出勤状态"统计各部门人数，与公式结果比对（待补图）。
7. 发工资条：工资条表每人一行就是工资条；要按人拆成单独的工资条页，用"工资条打印"做法——复制表头行，每两行插一个表头（或用邮件合并），打印前按部门排序，裁剪后发放。注意工资条含个人收入，不要群发、不要贴在公共区域（待补图）。

## 5. 公式和代码

### 5.1 考勤统计（COUNTIFS 与 AVERAGEIF）

```excel
= COUNTIFS(考勤记录!C:C,A2,考勤记录!I:I,"迟到")              → 迟到人次（按部门，A2 是部门名）
= COUNTIFS(考勤记录!C:C,A2,考勤记录!I:I,"请假")              → 请假人次（按部门）
= ROUND(AVERAGEIF(考勤记录!C:C,A2,考勤记录!G:G),1)          → 平均迟到分钟（按部门，保留 1 位小数）
= COUNTIFS(考勤记录!B:B,"李明",考勤记录!I:I,"迟到")          → 7（李明迟到 7 次）
= COUNTIFS(考勤记录!B:B,"高翔",考勤记录!I:I,"迟到")          → 8（高翔迟到 8 次，全文件最多）
= 86/550                                                     → 15.64%（全文件迟到率）
= IF(E2="","",IF(E2>"09:00",(E2-"09:00")*1440,0))           → 17（09:17 打卡，迟到 17 分钟）
```

要点：迟到分钟公式把时间差乘 1440（一天的分钟数），因为 Excel 里 1 代表一天；打卡为空时先判空，否则空单元格会被当成 0 点算出负数。

### 5.2 考勤汇总（10 人小案例）

```excel
= 花名册!H3                 → 22（张伟实际出勤，引用花名册）
= C3-D3                    → 0（张伟缺勤：应出勤 22 - 实际出勤 22）
= D3/C3                    → 100.00%（张伟出勤率）
= IF(D3=C3,300,0)          → 300（张伟全勤奖：满勤发 300，否则 0）
= SUM(D3:D12)              → 212（出勤总天数）
= D13/C13                  → 96.36%（全公司出勤率：212 / 220）
= COUNTIF(花名册!$C$3:$C$12,"销售部")                        → 4（销售部人数）
= SUMIF(花名册!$C$3:$C$12,"销售部",花名册!$H$3:$H$12)      → 84（销售部出勤合计）
= AVERAGEIF(花名册!$C$3:$C$12,"技术部",花名册!$H$3:$H$12)  → 21.25（技术部平均出勤）
```

### 5.3 工资条（VLOOKUP 与 XLOOKUP）

```excel
= VLOOKUP(A3,花名册!$B$3:$I$12,5,FALSE)   → 8000（张伟基本工资：第 5 列）
= VLOOKUP(A3,花名册!$B$3:$I$12,6,FALSE)   → 2000（张伟绩效奖金：第 6 列）
= VLOOKUP(A3,花名册!$B$3:$I$12,2,FALSE)   → 销售部（张伟部门：第 2 列）
= XLOOKUP(A3,花名册!$B$3:$B$12,花名册!$F$3:$F$12)   → 8000（张伟基本工资，XLOOKUP 写法）
= ROUND(C3*11%,0)                         → 880（张伟社保：基本工资 x 11%）
= C3+D3-E3-F3                             → 8820（张伟实发：基本 + 绩效 - 社保 - 个税）
= SUM(G3:G12)                             → 94672（实发工资合计）
= G13/COUNTA(A3:A12)                      → 9467.20（人均实发）
= DATEDIF(E3,TODAY(),"Y")                 → 工龄（年，E3 是入职日期；随今天日期变化）
```

要点：VLOOKUP 的第 3 个参数是"第几列"，从查找列（姓名列）开始数：姓名是第 1 列，部门第 2 列，岗位第 3 列，入职日期第 4 列，基本工资第 5 列，绩效奖金第 6 列，出勤天数第 7 列，个税第 8 列。数错一列，查出来的就是隔壁列的数。

### 5.4 工龄与生日提醒

```excel
= DATEDIF(E3,TODAY(),"Y")&"年"&DATEDIF(E3,TODAY(),"YM")&"个月" → 工龄（年 + 月，如张伟 2022-03-01 入职）
= EDATE(E3,12)                             → 入职满 1 年的日期（转正、调薪参考）
= IF(MONTH(TODAY())=MONTH(入职日期列),"本月入职周年","") → 入职周年提醒（配合条件格式标出）
```

### 5.5 部门对比公式

```excel
= COUNTIF(花名册!$C$3:$C$12,"销售部")/COUNTA(花名册!$C$3:$C$12) → 40.00%（销售部人数占比：4 / 10）
= AVERAGEIF(花名册!$C$3:$C$12,"技术部",花名册!$F$3:$F$12) → 11325（技术部平均基本工资）
= AVERAGEIF(花名册!$C$3:$C$12,"行政部",花名册!$F$3:$F$12) → 5900（行政部平均基本工资）
= SUMIF(工资条!$B$3:$B$12,"技术部",工资条!$G$3:$G$12)/工资条!$G$13 → 51.17%（技术部实发占比：48447 / 94672）
= SUMIF(花名册!$C$3:$C$12,"销售部",花名册!$G$3:$G$12)/花名册!$G$13 → 36.41%（销售部绩效占比：7500 / 20600）
```

要点：AVERAGEIF 的三个参数是条件区域、条件、求平均的区域，顺序不要和 SUMIF 搞混；占比公式的分母要锁行（`$G$13`），下拉填充时分母不动。

## 6. 实际工作场景

### 6.1 场景一：月底发工资，10 人工资条半小时出完

场景：你是人事专员，每月 25 日发工资。以前的做法是每个月把上月工资表复制一份，逐个改基本工资和绩效，社保按计算器一个一个敲，10 个人要花一下午，还总有人算错来问。

做法：花名册只维护基本工资、绩效奖金、出勤天数、个税四列会变的数据；工资条表全部用公式——部门、基本工资、绩效、个税用 VLOOKUP 查花名册，社保用 `=ROUND(基本工资*11%,0)`，实发用 `=基本+绩效-社保-个税`。每月只改花名册的四列，工资条自动重算；合计行当场验算 87800 + 20600 - 9658 - 4070 = 94672，数字对不上就不发。

结果：本月 10 人实发合计 94672 元，人均 9467.20 元；王强实发 12880 元最高，孙丽 6062 元最低；分部门销售部 33743 元、技术部 48447 元、行政部 12482 元，三部门合计与工资条合计一致。发之前把工资条按部门排序打印裁剪，每人只拿到自己的一张。

### 6.2 场景二：季度考勤复盘，迟到率 15.64% 怎么来的

场景：季度会上老板问"迟到到底多严重"。人事手里是 550 条打卡记录，口头说"迟到挺多的"没有说服力。

做法：打开考勤样本文件，先报总数：550 条记录，正常 448 人次、迟到 86 人次、请假 16 人次，迟到率 86 / 550 = 15.64%。再用 COUNTIFS 按人统计：高翔 8 次、李明 7 次、王芳和周敏各 6 次，4 个人占了 27 人次（86 人次里的 31.40%）；最后用部门汇总表看迟到分布，定位到人、定位到部门。

结果：结论不是"大家迟到多"，而是"迟到集中在 4 个人身上，占迟到人次的 31.40%"——处理方式从全员通报变成个别谈话。验算：27 / 86 = 31.40%，4 人人次 8 + 7 + 6 + 6 = 27，与总数口径一致。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| VLOOKUP 返回 #N/A | 姓名里多了一个空格，或花名册与工资条的姓名不一致 | 用 TRIM 清掉空格再查；或把 VLOOKUP 包一层 `=IFNA(VLOOKUP(...),"查无此人")` |
| VLOOKUP 查出隔壁列的数 | 列序号数错：从查找列开始数，基本工资是第 5 列不是第 4 列 | 列序号对照表头逐个数；改用 XLOOKUP 直接指定返回列，不用数列号 |
| 工资条合计少了 2000 元 | 花名册里某人的基本工资是文本格式，SUM 求和漏掉了 | 基本工资列全选 → 分列 → 完成，转回数值；或用 `=SUMPRODUCT(--区域)` 验算 |
| 迟到分钟算出负数或 1400 多 | 打卡为空的单元格被当成 0 点参与计算 | 公式先判空：`=IF(上班打卡="","",IF(上班打卡>"09:00",(上班打卡-"09:00")*1440,0))` |
| 出勤率算成 1063% | 应出勤与实际出勤的列写反，公式用了 `=C3/D3` | 出勤率 = 实际出勤 / 应出勤，即 `=D3/C3`；合计行是 `=D13/C13` → 96.36% |
| 全勤奖人人都有 | 公式写成 `=IF(D3>=22,300,0)`，而应出勤本身就是 22 天 | 全勤条件是实际出勤等于应出勤，写 `=IF(D3=C3,300,0)`，不要写死 22 |
| 部门汇总人数对不上 | COUNTIF 的区域只写了花名册的部分行，或部门名称多了空格 | 区域锁成 `$C$3:$C$12`，部门名用数据验证做下拉列表，不许手打 |
| 工龄算出 #VALUE! | 入职日期是文本格式，DATEDIF 认不出来 | 入职日期列改成日期格式；已是文本的用 DATEVALUE 或分列转换后再算 |

## 9. 练习题

1. 工资条：张伟基本工资 8000 元、绩效奖金 2000 元、社保 880 元、个税 300 元，写出实发公式并算出结果；再写出社保公式并说明 11% 是怎么来的。
2. 考勤汇总：刘洋实际出勤 20 天、应出勤 22 天，写出缺勤与出勤率公式；杨帆实际出勤 19 天，全勤奖是多少？为什么？
3. 部门汇总：用 COUNTIF 写出技术部人数公式，用 SUMIF 写出技术部实发合计公式，并算出结果。
4. 考勤样本：550 条记录里迟到 86 人次，写出迟到率公式；高翔迟到 8 次、李明 7 次、王芳 6 次、周敏 6 次，4 人合计占迟到人次的百分之几？
5. VLOOKUP：用 VLOOKUP 从花名册查吴霞的基本工资，写出完整公式与列序号的数法；再用 XLOOKUP 写出等价公式。
6. 勾稽：基本工资合计 87800 元、绩效奖金合计 20600 元、社保合计 9658 元、个税合计 4070 元，写出实发合计的验算公式并算出结果；分部门实发（销售部 33743、技术部 48447、行政部 12482）相加是否等于这个数？

## 10. 参考答案

<summary>点击查看答案</summary>

1. 实发公式 `=8000+2000-880-300` → 8820；社保公式 `=ROUND(8000*11%,0)` → 880。解析：社保个人部分 = 基本工资 x 11%，8000 x 11% = 880；实发 = 基本 + 绩效 - 社保 - 个税，四项缺一不可。
2. 缺勤公式 `=22-20` → 2 天；出勤率公式 `=20/22` → 90.91%。杨帆全勤奖 `=IF(19=22,300,0)` → 0。解析：全勤奖只发给实际出勤等于应出勤的人，杨帆缺勤 3 天，不发。
3. 人数公式 `=COUNTIF(花名册!$C$3:$C$12,"技术部")` → 4；实发合计公式 `=SUMIF(工资条!$B$3:$B$12,"技术部",工资条!$G$3:$G$12)` → 48447。解析：COUNTIF 数人数，SUMIF 按部门汇总实发；技术部 4 人实发 12880 + 11640 + 12315 + 11612 = 48447。
4. 迟到率公式 `=86/550` → 15.64%；4 人合计 8 + 7 + 6 + 6 = 27 人次，占比 `=27/86` → 31.40%。解析：迟到率的分母是总记录数 550 人次，不是人数 25 人；4 个人占了近三分之一的迟到人次，说明迟到集中在少数人身上。
5. VLOOKUP 公式 `=VLOOKUP("吴霞",花名册!$B$3:$I$12,5,FALSE)` → 10800。列序号数法：姓名第 1 列、部门第 2 列、岗位第 3 列、入职日期第 4 列、基本工资第 5 列。XLOOKUP 等价公式 `=XLOOKUP("吴霞",花名册!$B$3:$B$12,花名册!$F$3:$F$12)` → 10800。解析：XLOOKUP 不用数列号，直接指定返回列；两个公式结果都是 10800，不一致就说明其中一个写错了。
6. 验算公式 `=87800+20600-9658-4070` → 94672。分部门相加：33743 + 48447 + 12482 = 94672，等于实发合计。解析：两条路算出同一个数才算对上；分部门合计与工资条合计是同一批数据的两种切法，结果必须相等。
