## 2. 基础概念

### 2.1 三张表各回答什么问题

- **利润表**：这一年赚了多少钱。回答"经营成果"，按收入、成本、费用、利润的顺序展开。
- **资产负债表**：年底手里有什么、欠别人什么。回答"财务状况"，恒等式是资产 = 负债 + 所有者权益。
- **现金流量表**：钱是怎么进出、最后剩多少现金。回答"现金流动"，分经营、投资、筹资三类活动。

三张表不是各算各的：净利润连利润表和资产负债表，期末现金连现金流量表和资产负债表。任何一处断链，报表就是错的。

### 2.2 利润表的递进关系

营业收入 1200000 元，减营业成本 720000 元得毛利 480000 元；毛利减销售费用 120000 元、管理费用 150000 元、财务费用 30000 元得营业利润 180000 元；本例无营业外收支，利润总额就是营业利润 180000 元；减所得税费用 45000 元（180000 x 25%），得净利润 135000 元。

毛利率 = 毛利 / 营业收入 = 40.00%，净利率 = 净利润 / 营业收入 = 11.25%。毛利率看产品本身赚不赚钱，净利率看扣掉全部费用和税之后还剩多少。

### 2.3 资产负债表的恒等式

资产总计 770000 元 = 负债合计 385000 元 + 所有者权益合计 385000 元。资产负债率 = 负债合计 / 资产总计 = 50.00%，流动比率 = 流动资产 / 流动负债 = 450000 / 185000 = 2.43。

做表时先分别算两边，最后用一行平衡检查公式 `=资产总计 - （负债合计 + 所有者权益合计）`，结果必须是 0。不为 0 就不要往下做，先找差额。

### 2.4 现金流量表的三类活动

- **经营活动**：日常买卖产生的现金。本例净流入 70000 元。
- **投资活动**：买固定资产等长期资产产生的现金。本例购建固定资产支付 400000 元，净流出 400000 元。
- **筹资活动**：股东投钱、借钱、还钱、分红产生的现金。本例吸收投资 300000 元、取得借款 200000 元、分配股利 50000 元，净流入 450000 元。

三类相加：70000 - 400000 + 450000 = 120000 元，期初现金 0 元，期末现金 120000 元。

### 2.5 权责发生制与收付实现制

利润表按权责发生制：收入 1200000 元里有 150000 元还没收到钱（应收账款），成本 720000 元里有 120000 元还没付钱（应付账款）。现金流量表按收付实现制：只算实际收付的现金。所以净利润 135000 元不等于经营现金流 70000 元，差额要靠间接法逐项调节，这正是第 4.4 节的内容。

### 2.6 财务比率速读：四个数看懂一家公司

| 比率 | 公式 | 本例数值 | 读法 |
|---|---|---|---|
| 毛利率 | 毛利 / 营业收入 | 40.00% | 产品本身赚不赚钱 |
| 净利率 | 净利润 / 营业收入 | 11.25% | 扣掉全部费用和税后还剩多少 |
| 资产负债率 | 负债合计 / 资产总计 | 50.00% | 一半资产靠借钱撑着，杠杆适中 |
| 流动比率 | 流动资产 / 流动负债 | 2.43 | 短期还债能力充足（大于 2 一般认为安全） |
| 权益乘数 | 资产总计 / 所有者权益合计 | 2.00 | 1 元自有资金撑起 2 元资产 |
| 总资产周转率 | 营业收入 / 资产总计 | 1.56 | 1 元资产一年创造 1.56 元收入 |

比率要成组看：毛利率 40.00% 不低，净利率只有 11.25%，差额是三项费用 300000 元与所得税 45000 元吃掉的；资产负债率 50.00% 配流动比率 2.43，说明负债虽有一半，但短期偿债没有压力。

## 3. 操作步骤

本节以配套模板文件 `示例-财务报表.xlsx` 为操作对象，三张表各一张工作表，合计项与勾稽项全部是公式。

1. 做利润表：新建"利润表"工作表，按收入、成本、毛利、三项费用、营业利润、利润总额、所得税、净利润的顺序列项目。毛利用公式 `=B3-B4`（收入 - 成本）→ 480000；营业利润用 `=B5-B6-B7-B8` → 180000；所得税用 `=ROUND(B10*25%,0)` → 45000；净利润用 `=B10-B11` → 135000。末尾加毛利率 `=B5/B3` → 40.00% 与净利率 `=B12/B3` → 11.25%（待补图）。
2. 做资产负债表：新建"资产负债表"工作表，左边列资产，右边（或下方）列负债与所有者权益。流动资产合计用 `=SUM(B3:B5)` → 450000；固定资产净值用 `=B7-B8`（原值 - 累计折旧）→ 320000；资产总计用 `=B6+B9` → 770000；流动负债合计用 `=SUM(B11:B13)` → 185000；负债合计用 `=B14+B15` → 385000（待补图）。
3. 接未分配利润：资产负债表权益部分写四行：未分配利润期初 0、加本年净利润（引用利润表，`='利润表'!B12` → 135000）、减分配股利 50000、未分配利润期末 `=B18+B19-B20` → 85000。所有者权益合计 `=B17+B21` → 385000（待补图）。
4. 验算平衡：资产负债表底部加平衡检查行，公式 `=B10-B23`（资产总计 - 负债和所有者权益总计），结果必须是 0。不为 0 时，先核对未分配利润有没有引用利润表，再逐项核对合计公式的求和范围（待补图）。
5. 做现金流量表（直接法）：新建"现金流量表"工作表，按经营、投资、筹资三类列项目。经营净额用 `=SUM(B3:B7)` → 70000；投资净额是购建固定资产支付 -400000；筹资净额用 `=SUM(B11:B13)` → 450000（吸收投资 300000 + 取得借款 200000 - 分配股利 50000）；现金净增加额用 `=B8+B10+B14` → 120000；期末现金用 `=B15+B16`（净增加额 + 期初 0）→ 120000（待补图）。
6. 验算勾稽：现金流量表底部加勾稽检查行，公式 `=B17-'资产负债表'!B3`（期末现金 - 货币资金），结果必须是 0。不为 0 时，先核对筹资活动有没有漏掉吸收投资 300000 元（实收资本），再核对投资活动是不是购建固定资产 400000 元（待补图）。
7. 做间接法调节表（可选但推荐）：在现金流量表下方或另起一区，从净利润 135000 元出发，加折旧 80000 元，减应收账款增加 150000 元，减存货增加 180000 元，加应付账款增加 120000 元，加应付职工薪酬增加 50000 元，加应交税费增加 15000 元，合计 70000 元，与直接法经营净额比对（待补图）。
8. 排版与打印：三张表统一标题行、金额列千分位格式、合计行加粗；页面设置横向、 fit to page，打印前用打印预览检查合计行没有被分页切断（待补图）。

## 5. 公式和代码

### 5.1 利润表

```excel
= B3-B4                  → 480000（毛利：营业收入 - 营业成本）
= B5-B6-B7-B8            → 180000（营业利润：毛利 - 销售费用 - 管理费用 - 财务费用）
= ROUND(B10*25%,0)       → 45000（所得税费用：利润总额 x 25%）
= B10-B11                → 135000（净利润：利润总额 - 所得税费用）
= B5/B3                  → 40.00%（毛利率）
= B12/B3                 → 11.25%（净利率）
```

### 5.2 资产负债表

```excel
= SUM(B3:B5)             → 450000（流动资产合计：货币资金 + 应收账款 + 存货）
= B7-B8                  → 320000（固定资产净值：原值 - 累计折旧）
= B6+B9                  → 770000（资产总计）
= SUM(B11:B13)           → 185000（流动负债合计）
= B14+B15                → 385000（负债合计：流动负债 + 长期借款）
= '利润表'!B12           → 135000（本年净利润，跨表引用利润表）
= B18+B19-B20            → 85000（未分配利润期末：期初 0 + 本年净利润 - 分配股利）
= B17+B21                → 385000（所有者权益合计：实收资本 + 未分配利润期末）
= B10-B23                → 0（平衡检查：资产总计 - 负债和所有者权益总计）
```

### 5.3 现金流量表

```excel
= SUM(B3:B7)             → 70000（经营活动现金流量净额）
= B9                     → -400000（投资活动现金流量净额：购建固定资产支付）
= SUM(B11:B13)           → 450000（筹资活动现金流量净额：300000 + 200000 - 50000）
= B8+B10+B14             → 120000（现金净增加额：经营 + 投资 + 筹资）
= B15+B16                → 120000（期末现金：净增加额 + 期初 0）
= B17-'资产负债表'!B3    → 0（勾稽检查：期末现金 - 货币资金）
```

### 5.4 现金流各项目的推导公式

```excel
= 1200000-150000         → 1050000（销售收到现金：营业收入 - 应收账款增加）
= 720000+180000-120000   → 780000（购买支付现金：营业成本 + 存货增加 - 应付账款增加）
= 110000-50000           → 60000（支付职工现金：计提薪酬 110000 - 应付职工薪酬增加 50000）
= 45000-15000            → 30000（支付税费：所得税计提 45000 - 应交税费增加 15000）
```

### 5.5 财务函数应用

以下四个函数的数值与阶段 2 审计一致（07-financial.md 已逐一重算复核），参数与结果逐一对应，符号错误是最常见的坑。

```excel
= PMT(4.5%/12, 20*12, 500000)        → -3,163.25（贷款 50 万、年利率 4.5%、20 年，月供；负号表示支出）
= ABS(PMT(4.5%/12, 240, 500000))     → 3,163.25（月供显示为正数）
= FV(6%/12, 10*12, -2000)            → 327,758.69（每月定投 2000、年化 6%、10 年后终值）
= FV(6%/12, 120, -2000, -100000)     → 509,698.37（现有 10 万本金、每月再投 2000、10 年后）
= IRR(A2:A6)                          → 约 7.71%（现金流 -100 万、30 万、30 万、30 万、30 万）
= NPER(4.5%/12, -5000, 500000)/12    → 约 10.5 年（每月还 5000、年利率 4.5%、50 万贷款几年还清）
= SLN(100000,10000,5)                → 18000（设备原值 100000、残值 10000、年限 5 年，年折旧额）
```

要点：PMT、FV、NPER 的利率与期数必须同口径——年利率除以 12，期数就用月数；IRR 的现金流必须至少一正一负，否则返回 `#NUM!`；FV 里定投写 -2000（支出），结果为正才是对的，符号反了结果就反号。

### 5.6 折旧函数对照：SLN 与 DB

```excel
= SLN(100000,10000,5)      → 18000（直线法：(原值 - 残值) / 年限，每年一样）
= DB(100000,10000,5,1)     → 36,904.27（余额递减法：第 1 年折旧，前期多、后期少）
= DB(100000,10000,5,2)     → 23,285.02（余额递减法：第 2 年折旧，逐年递减）
```

要点：SLN 每年折旧额相同，算法简单，是小公司最常用的折旧方法；DB 前期折旧多、后期少，第 1 年 36904.27 元是 SLN 的两倍多。两种方法 5 年折旧总额都是 90000 元（原值 100000 - 残值 10000），差别只在分摊节奏。本篇利润表管理费用里的折旧 80000 元用的是直线法口径：固定资产原值 400000 元按 5 年计提，每年 80000 元。

## 6. 实际工作场景

### 6.1 场景一：年底结账，老板要三张表

场景：小公司第一年结束，老板要三张表去见投资人。你手头只有一年的收支流水和几张余额：收入 1200000 元、成本 720000 元、三项费用合计 300000 元；年底货币资金 120000 元、应收 150000 元、存货 180000 元、固定资产原值 400000 元、累计折旧 80000 元；应付 120000 元、应付职工薪酬 50000 元、应交税费 15000 元、长期借款 200000 元；股东投了 300000 元，分了 50000 元股利。

做法：按第 3 节顺序做利润表（净利润 135000 元）、资产负债表（未分配利润期末 85000 元）、现金流量表（期末现金 120000 元）。每做完一张就验算一次：利润表验算毛利率 40.00%、净利率 11.25%；资产负债表验算平衡检查为 0；现金流量表验算勾稽检查为 0。

结果：三张表全部勾稽上——净利润进了未分配利润，期末现金等于货币资金，投资人问"利润 135000 元为什么账上只有 120000 元现金"，直接翻到间接法调节表：应收和存货占了 330000 元，折旧加回 80000 元，应付加回 185000 元，账算得清清楚楚。

### 6.2 场景二：贷款决策，用 PMT 算月供压力

场景：公司想再贷 50 万元买设备，年利率 4.5%，分 20 年还。老板问每月要还多少、还几年还得清、值不值得贷。

做法：月供用 `=PMT(4.5%/12, 20*12, 500000)` → -3,163.25 元，每月固定支出 3163.25 元；如果每月只能还 5000 元，用 `=NPER(4.5%/12, -5000, 500000)/12` → 约 10.5 年还清；再拿经营现金流 70000 元比一比——每年月供 37959 元，占经营现金流的一半以上，还款压力不小；同时用 IRR 评估设备投资回报，现金流 -100 万、每年回 30 万连回 4 年，IRR 约 7.71%，高于贷款利率 4.5%，项目本身划算，但现金流压力要另外安排。

结果：结论写进报表附注——"项目 IRR 约 7.71%，高于贷款利率，但月供占经营现金流过半，建议缩短贷款年限或分期购入设备"。数字和结论分开，数字是算出来的，结论是判断，报表上只写数字，判断写进附注。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 资产负债表不平，差 135000 | 未分配利润期末只写了期初 0，漏了本年净利润 | 未分配利润期末公式改成 `=期初 + '利润表'!净利润 - 分配股利`，本例应为 85000 |
| 平衡检查差 50000 | 分配股利 50000 元只在现金流量表记了，资产负债表未分配利润没扣 | 未分配利润期末扣掉分配股利；分红同时影响两张表，改一处就要改两处 |
| 期末现金不等于货币资金 | 筹资活动漏了吸收投资 300000 元（实收资本） | 筹资活动加一行"吸收投资收到的现金 300000"，再验算勾稽检查为 0 |
| 经营现金流算成 -330000 | 把购建固定资产 400000 元记进了经营活动 | 购建固定资产属于投资活动；经营活动只含日常买卖收付 |
| 所得税费用算成 54000 | 用营业利润 180000 乘了 30%，税率用错 | 本例所得税率 25%，公式 `=ROUND(利润总额*25%,0)` → 45000；税率变动时只改这一处 |
| PMT 结果是正数 3163.25 | 贷款本金写了 -500000，符号反了 | Excel 里 PMT 的现值写正数 500000，结果为负表示支出；要显示正数再套 ABS，不要改本金符号 |
| FV 结果是负数 | 每期付款写了正数 2000，定投方向反了 | 定投是现金流出，写 -2000，结果 327758.69 为正；符号口径与 PMT 一致 |
| NPER 返回 #NUM! | 每月还款额小于每月利息，还不清本金 | 检查还款额是否大于 `500000*4.5%/12`（1875 元）；小于这个数永远还不清，#NUM! 是正确提示 |

## 9. 练习题

1. 利润表：营业收入 1200000 元、营业成本 720000 元，写出毛利公式与毛利率公式，并算出结果。
2. 资产负债表：货币资金 120000 元、应收账款 150000 元、存货 180000 元，写出流动资产合计公式；固定资产原值 400000 元、累计折旧 80000 元，写出固定资产净值公式。
3. 未分配利润：期初 0、本年净利润 135000 元、分配股利 50000 元，写出期末公式并算出结果；再算所有者权益合计与资产总计，写出平衡检查公式。
4. 现金流量表：经营净流量 70000 元、投资净流量 -400000 元、筹资净流量 450000 元，写出净增加额与期末现金公式，并说明期末现金为什么等于货币资金 120000 元。
5. 间接法：从净利润 135000 元出发，只用折旧 80000 元与应收账款增加 150000 元两项调节，中间结果是多少？再把其余四项（存货 -180000、应付 +120000、应付职工薪酬 +50000、应交税费 +15000）加上，最终与直接法经营净流量比对。
6. 财务函数：贷款 50 万、年利率 4.5%、20 年，写出 PMT 公式与月供；每月定投 2000、年化 6%、10 年，写出 FV 公式与终值；并说出 PMT 结果为什么是负数。

## 10. 参考答案

<details>
<summary>点击查看答案</summary>

1. 毛利公式 `=1200000-720000` → 480000；毛利率公式 `=480000/1200000` → 40.00%。解析：毛利是收入减成本，毛利率是毛利除以收入；分母永远是营业收入，不是营业成本。
2. 流动资产合计 `=120000+150000+180000` → 450000；固定资产净值 `=400000-80000` → 320000。解析：流动资产合计是三项相加；固定资产净值是原值减累计折旧，累计折旧是备抵科目，要减不要加。
3. 未分配利润期末 `=0+135000-50000` → 85000；所有者权益合计 `=300000+85000` → 385000；资产总计 `=450000+320000` → 770000；平衡检查 `=770000-(385000+385000)` → 0。解析：未分配利润期末是期初加本年净利润减分配股利；资产 770000 等于负债 385000 加权益 385000，检查为 0 才算平。
4. 净增加额 `=70000-400000+450000` → 120000；期末现金 `=120000+0` → 120000。解析：期末现金等于货币资金，是因为货币资金就是账上现金的余额；现金流量表算的是现金的增减，资产负债表列的是现金的时点余额，两者靠期末数勾稽。
5. 中间结果：135000 + 80000 - 150000 = 65000。再加其余四项：65000 - 180000 + 120000 + 50000 + 15000 = 70000，与直接法经营净流量 70000 元一致。解析：折旧加回、应收增加减掉、存货增加减掉、应付增加加回，四项合计 +5000 元，65000 + 5000 = 70000。
6. PMT 公式 `=PMT(4.5%/12, 20*12, 500000)` → -3,163.25；FV 公式 `=FV(6%/12, 10*12, -2000)` → 327,758.69。解析：PMT 结果为负是因为还款是现金流出，负号表示支出，不是报错；FV 里定投写 -2000 同样是支出方向，结果为正表示 10 年后收到的终值。
