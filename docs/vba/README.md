# VBA 学习路线图

欢迎来到 VBA 世界。本路线图为零基础学习者设计，分为三个阶段，预计 4～6 周可达到独立开发小工具的水平。

## 第一阶段：入门（第 1～2 周）

**目标**：能看懂简单宏，能写 20 行以内的小程序。

1. **第 1～3 天**：打开 VBE，学会录制宏
   - 用「录制宏」做几个操作（设置格式、排序），然后看生成的代码
   - 录制宏是学习语法的捷径：不知道某操作怎么写，先录制再看代码
   - 读 [01-basics.md](01-basics.md) 第 1～4 节

2. **第 4～7 天**：变量与流程控制
   - 掌握 `Dim`、常用数据类型、`If`、`For`、`Do`
   - 练习：写程序计算 1～1000 中 3 的倍数之和
   - 读 [01-basics.md](01-basics.md) 第 5～9 节

3. **第 8～14 天**：对象模型入门
   - 理解 Application → Workbook → Worksheet → Range 层级
   - 掌握 `Range`/`Cells` 读写、`Value`/`Font`/`Interior`
   - 练习：给 A1:Z100 加边框、隔行变色
   - 读 [02-objects.md](02-objects.md) 第 1～7 节

**检验标准**：不看答案，独立写出"把 Sheet1 的 A 列空单元格填上'待补充'"。

---

## 第二阶段：进阶（第 3～4 周）

**目标**：能处理真实工作中的批量任务，代码有基本规范。

1. **数组与性能**
   - 理解为什么"数组批量读写"比逐格读写快 10 倍
   - 掌握 `Application.ScreenUpdating = False` 三件套
   - 练习：用数组方式给 1 万行数据加一列计算结果，对比两种写法的耗时

2. **错误处理**
   - 掌握 `On Error GoTo` / `Resume Next` / `Err` 对象
   - 理解什么时候该让程序报错（开发期），什么时候该优雅处理（交付后）
   - 读 [03-keywords.md](03-keywords.md) 第五节

3. **事件与交互**
   - 掌握 `Workbook_Open`、`Worksheet_Change`
   - 学会 `FileDialog` 让用户选文件、`InputBox` 接收输入
   - 读 [02-objects.md](02-objects.md) 第 10 节

4. **动手改实例**
   - 把 [04-examples.md](04-examples.md) 的 8 个实例逐个运行、读懂、改写
   - 尝试组合：比如"合并工作簿" + "数据去重" + "生成报表"串成一条流水线

**检验标准**：独立完成"合并 5 个结构相同的月报，生成带汇总的季度报表"。

---

## 第三阶段：实战（第 5～6 周及以后）

**目标**：能为部门开发可交付的小工具，代码健壮、可维护。

1. **用户窗体（UserForm）**
   - 制作带按钮、文本框、下拉框的交互界面
   - 学习 `Initialize` 事件、`Me` 关键字

2. **字典与正则**
   - `Scripting.Dictionary`：去重、计数、快速查找（需引用 Microsoft Scripting Runtime）
   - `VBScript.RegExp`：复杂文本提取（需引用 Microsoft VBScript Regular Expressions）

3. **外部交互**
   - 操作文件系统（`FileSystemObject`）
   - 发邮件（参考实例 7，可扩展为 HTML 格式正文）
   - 调用 Word/PowerPoint 生成文档

4. **工程化习惯**
   - 模块按功能拆分（数据层 / 逻辑层 / 界面层）
   - 统一的错误处理模板和日志
   - 关键过程写注释说明"为什么"，而不是"是什么"

## 常见坑（提前避开）

| 坑 | 后果 | 对策 |
|----|------|------|
| 不用 `Option Explicit` | 变量名拼错产生新变量，bug 难查 | 所有模块顶部加上 |
| 在循环里逐格读写 | 1 万行跑几分钟 | 数组批量读写 |
| `Select`/`Activate` 满天飞 | 代码慢且 fragile | 直接操作对象，如 `Range("A1").Value = 1` |
| Change 事件里改单元格 | 无限递归，Excel 卡死 | `EnableEvents = False/True` 包裹 |
| 整数用 `Integer` | 行数超 32767 溢出 | 用 `Long` |
| 公式里写中文函数名 | 在英文版 Excel 报错 | VBA 里公式一律英文函数名+逗号 |

## 学习资源

- **最好的老师**：录制宏。任何手工操作，先录制，看代码，再改写。
- **最快的查阅**：VBE 里按 `F2` 打开对象浏览器；选中关键字按 `F1` 看帮助。
- **调试三件套**：`F8` 单步执行、`Debug.Print` 输出到立即窗口、鼠标悬停看变量值。
