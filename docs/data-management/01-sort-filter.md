# 排序与筛选：单条件、多条件、自动筛选与高级筛选

- **所属栏目**：C05 数据管理 ／ C05-L2-1 排序与筛选
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：入门
- **预计阅读时长**：20 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 按数值、日期、文本与颜色排序，并理解排序前必须选中整个数据区
- 用多条件排序实现"先按部门、再按金额降序"这类两层排序
- 用自动筛选与文本/数字筛选快速找出目标行
- 用高级筛选实现多条件组合（与/或）与不重复记录提取

## 2. 基础概念

**排序的铁律**：排序前选中整个数据区，或点数据区内任一格直接排序（Excel 自动扩展选区）。只选中一列就排序，会把行与行之间的对应关系打乱——这是新手最常见的毁表操作，没有之一。排序前备份，或确认能 `Ctrl + Z` 撤销。

**单条件排序**：数据→排序，按一列升序/降序。数值按大小、日期按先后、文本按拼音/字母。金额列降序即"从大到小"，看 Top 5 直接取前 5 行。

**多条件排序**：数据→排序→添加条件，先按部门升序、再按金额降序。Excel 按条件顺序逐层排：部门相同的人内部再按金额排。层数没有实用上限，但超过 3 层就要想想是不是该用透视表了。

**自动筛选**：选中表头行，数据→筛选，每列出现下拉箭头。点箭头可选文本筛选（包含/开头是）、数字筛选（大于/前 10 项）、按颜色筛选。筛选只是隐藏行，不删除数据；清除筛选后全部恢复。

**高级筛选**：数据→高级筛选，条件区域单独写在表外。同一行多个条件是"与"（同时满足），不同行是"或"（满足其一）。还能勾选"选择不重复的记录"，一键提取不重复客户名单。高级筛选可把结果复制到其他位置，原表不动。

**按颜色排序**：先用条件格式或手动填充把异常行标色，再按颜色排序，异常行自动聚到一起。适合"先标后排"的人工复核流程。

## 3. 操作步骤

1. 单条件排序：点金额列内任一格，数据→降序（Z→A），确认弹出"扩展选定区域"时选扩展，再确定。
2. 多条件排序：数据→排序，主要关键字选"部门"、次序升序；点"添加条件"，次要关键字选"金额"、次序降序；确定。
3. 自动筛选：点表头行任一格，数据→筛选；点"部门"列箭头，只勾"销售部"，确定；再点"金额"箭头→数字筛选→大于→输入 5000。
4. 清除筛选：数据→清除（只清条件保留箭头），或再点一次数据→筛选（连箭头一起去掉）。
5. 高级筛选：表外写条件区（如 G1:H2：G1"部门"、H1"金额"，G2"销售部"、H2">5000"），数据→高级筛选→将筛选结果复制到其他位置，列表区域选数据区、条件区域选 G1:H2、复制到选目标格，确定。
6. 提取不重复：高级筛选中勾选"选择不重复的记录"，客户列一次去重，比逐行肉眼快得多。

## 4. 图文示例

销售明细 5 行：张三/销售部/8000、李四/市场部/3000、王五/销售部/6000、赵六/销售部/4500、钱七/市场部/7000。按金额降序排：8000、7000、6000、4500、3000。自动筛选"部门=销售部"得 3 行（张三、王五、赵六）；再加"金额>5000"得 2 行（张三、王五）。高级筛选条件区"部门=销售部"且"金额>5000"复制到别处，同样得 2 行。核对：8000+6000=14000，与条件求和结果一致。

## 5. 公式和代码

```excel
=SUMIF(A2:A6,"销售部",C2:C6) → 18500
=COUNTIF(A2:A6,"销售部") → 3
=LARGE(C2:C6,1) → 8000
```

- `=SUMIF(A2:A6,"销售部",C2:C6)` → 18500：销售部金额合计：8000+6000+4500=18500；与筛选后求和互相核对
- `=COUNTIF(A2:A6,"销售部")` → 3：销售部共 3 行：张三、王五、赵六
- `=LARGE(C2:C6,1)` → 8000：LARGE 取第 1 大值 8000，即金额最大值；等于 MAX 的结果

## 6. 实际工作场景

### 月度销售 Top 10

全月明细按金额降序排，前 10 行即 Top 10；再按部门多条件排一次，看各部门内部的排名。汇报时贴排序后的表，比只报数字有说服力。

### 从 1000 行里找异常订单

金额列按颜色筛选（先条件格式标红金额>10000 的行），或数字筛选"大于 10000"，异常行一次聚齐；再高级筛选把结果复制到新表做复核，原表不动。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 排序后数据错位 | 只选中一列就排序 | 点数据区内任一格直接排序，让 Excel 自动扩展选区；或排序前选中整个数据区 |
| 筛选后求和结果不对 | SUM 把隐藏行也算进去了 | 筛选后求和改用 SUBTOTAL(109, 区域)，109 表示"忽略隐藏行求和" |
| 高级筛选条件不起作用 | 条件区标题与数据区表头不一致 | 条件区第一行必须与数据区表头逐字相同（含空格）；"与"写同一行，"或"写不同行 |
| 筛选箭头不见了 | 误点了数据→筛选两次 | 再点一次数据→筛选恢复箭头；清除筛选（数据→清除）只清条件不去箭头 |
