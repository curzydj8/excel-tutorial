# 数据导入导出：文本/CSV 导入、从数据库与网页获取、导出格式

- **所属栏目**：C05 数据管理 ／ C05-L2-5 数据导入导出
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：进阶
- **预计阅读时长**：20 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 用文本导入向导正确导入 CSV，选对分隔符、编码与列格式
- 用 Power Query 从文件夹、数据库与网页获取数据并刷新
- 导出 CSV 与 PDF，知道每种格式会丢什么（格式、公式、多表）
- 处理导入时的乱码、长数字变科学计数法与日期错乱

## 2. 基础概念

**CSV 导入三要素**：分隔符（逗号/分号/制表符）、编码（UTF-8/GBK）、列格式（文本/日期/常规）。三者任一错，导入即乱：分隔符错会整行挤进一列，编码错会出乱码，列格式错会丢前导 0 或把长数字变科学计数法。

**两种导入路径**：直接双击打开 CSV（快，但分隔符与编码按系统默认猜，常猜错）；数据→从文本/CSV（走 Power Query 导入向导，可选分隔符、编码、列格式，推荐）。后者还能把导入步骤存成查询，下月同样文件一键刷新。

**从文件夹获取**：数据→获取数据→自文件→从文件夹，选文件夹后 Power Query 合并其中全部同结构文件。每月 12 个分表合并成一张总表，用它 1 分钟搞定；新文件丢进文件夹后刷新即可。

**从数据库与网页获取**：数据→获取数据→自数据库（SQL Server、Access 等）或自网站（输入 URL 抓表格）。网页表格结构一变就要重配查询，适合结构稳定的公开表格（如汇率表）。

**导出格式取舍**：另存为 CSV 只保留当前工作表、无格式无公式，适合导给其他系统；导出 PDF（文件→导出→创建 PDF）保留排版与格式，适合发给领导；发给对方继续编辑的，一律发 .xlsx 原文件。

**刷新**：Power Query 导入的数据，源文件更新后在 Excel 里点数据→全部刷新即可同步。查询步骤存在工作簿里，发给别人时对方刷新需要能访问源文件路径，路径变了会报错。

## 3. 操作步骤

1. 导入 CSV：数据→从文本/CSV，选文件；在预览里确认分隔符（逗号）、编码（UTF-8，如乱码改 GBK 936）、列格式（工号列设文本）；点加载。
2. 处理乱码：预览里中文是乱码时，把编码从 UTF-8 换成 GBK（936）再预览，中文正常后再加载。
3. 从文件夹合并：数据→获取数据→自文件→从文件夹，选文件夹→合并→选示例文件确认列→确定，全部同结构文件合并成一张表。
4. 从网页获取：数据→获取数据→自其他源→自网站，输入 URL，选要抓的表格→加载；结构变化时在 Power Query 编辑器里重配。
5. 导出 CSV：选中要导出的工作表，文件→另存为→CSV UTF-8（逗号分隔）；注意只保存当前工作表，多表要逐张另存。
6. 导出 PDF：文件→导出→创建 PDF/XPS 文档，选"整个工作簿"或"当前工作表"；打印设置（页面布局→纸张方向/缩放）先调好再导出。

## 5. 公式和代码

```excel
=SUM(C2:C6) → 28500（导入核对用）
=COUNTA(A2:A6) → 5
```

- `=SUM(C2:C6)` → 28500：导入后金额合计 8000+3000+6000+4500+7000=28500，与源系统报表一致才算导对
- `=COUNTA(A2:A6)` → 5：导入后非空行数 5，与源文件行数核对；行数不对先查分隔符与编码

## 6. 实际工作场景

### 每月 12 个分表合成总表

12 个分公司每月各交一个 CSV：建一个文件夹全丢进去，Power Query 从文件夹获取并合并。下月新文件直接丢进文件夹，打开总表点全部刷新即完成合并。

### 给外部系统导数据

对方系统只认 GBK 编码的 CSV：另存为时选"CSV（逗号分隔）"并确认编码；长数字列先设文本格式再导，否则对方收到的是科学计数法。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 导入后中文全是乱码 | 编码选错（UTF-8 文件按 GBK 解） | 导入向导里把编码换成 UTF-8 或 GBK（936）再预览，中文正常后再加载 |
| 整行数据挤在一列 | 分隔符选错（文件是分号分隔却按逗号切） | 导入向导里改分隔符；或导入后用数据→分列补救 |
| 订单号变科学计数法 | 导入时列格式是常规 | 导入向导里把该列格式设为文本；已变的无法恢复，需重新导入 |
| 刷新后报错找不到源文件 | 源文件被移动或改名 | 把源文件放回原路径，或在 Power Query 编辑器里改源路径；发给别人前先说明刷新依赖 |
| 导出 CSV 后多表没了 | CSV 只能存一张表 | CSV 只保存当前工作表；多表要逐张另存，或直接发 .xlsx |
