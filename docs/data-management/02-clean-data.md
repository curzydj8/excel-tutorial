# 数据清洗：分列、去重、TRIM/CLEAN 与查找替换清理

- **所属栏目**：C05 数据管理 ／ C05-L2-2 数据清洗
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：入门
- **预计阅读时长**：20 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 用分列把"张三,销售部,100"这类一格多值拆成多列
- 用删除重复项与 UNIQUE 去重，并说出两者的区别
- 用 TRIM 与 CLEAN 清掉空格与不可见字符
- 建立"先备份、再清洗、逐项核对"的清洗流程，清洗前后行数对得上

## 2. 基础概念

**脏数据的四种**：多余空格（"张三 "）、不可见字符（从系统导出的换行符、制表符）、文本型数字（"100" 当文本）、重复行（同一订单导了两次）。清洗就是按固定顺序把这四种逐一处理掉。

**分列**：数据→分列，把一格里的多个值按分隔符（逗号、分号、空格）或固定宽度拆成多列。系统导出的 CSV 常常是"姓名，部门，金额"挤在一格，分列是第一步。分列前先在右侧留出空列，否则会覆盖已有数据。

**删除重复项**：数据→删除重复项，勾选作为判断依据的列（如订单号），重复行整行删除，并报告删了几行。它是破坏性操作，清洗前必须先备份原表。

**TRIM 与 CLEAN**：`TRIM` 删首尾空格、把连续多个空格压成一个；`CLEAN` 删不可见字符（如换行符 CHAR(10) 以外的控制字符）。两者常组合用：`=TRIM(CLEAN(A2))`。注意 TRIM 不删不间断空格（CHAR(160)，从网页复制来的常见），那种要用 SUBSTITUTE 换掉：`=SUBSTITUTE(A2,CHAR(160),"")`。

**UNIQUE（2021／365）**：`=UNIQUE(A2:A100)` 一公式返回去重后的列表，原表不动。想保留原表、只在新位置看去重结果时用它；想直接在原表上删重复行时用"删除重复项"。

**清洗流程**：备份原表→分列→清空格与不可见字符→文本数字转数值→去重→核对（行数、合计值前后对比）。合计值清洗前后必须一致，否则就是洗掉了不该洗的东西。

## 3. 操作步骤

1. 备份：右键工作表标签→移动或复制→勾选"建立副本"，副本改名"原始备份"，再在原表上清洗。
2. 分列：选中要拆的列，数据→分列→分隔符号→勾逗号→下一步→完成；先确认右侧有足够空列。
3. 清空格：在辅助列输入 `=TRIM(CLEAN(A2))` 拖满全列，复制辅助列→选择性粘贴→数值覆盖回原列，再删辅助列。
4. 清不间断空格：网页复制来的数据先用 `=SUBSTITUTE(A2,CHAR(160),"")` 去 CHAR(160)，再套 TRIM。
5. 文本转数值：选中文本数字列，数据→分列→直接点完成（不改任何设置），分列会顺手把文本数字转成数值；或在空白格输入 1、复制、选中目标列→选择性粘贴→乘。
6. 去重：选中数据区，数据→删除重复项，勾选订单号列，确认报告"删除了 N 个重复值"；核对行数：原行数减删除数等于现行数。
7. 核对：清洗前后分别用 SUM 算金额合计，两数一致才算洗完；不一致就逐项回查哪一步动了数值。

## 4. 图文示例

导出的订单表 6 行：其中两行订单号重复，一行姓名带尾空格"张三 "，一行金额是文本型"6000"。清洗：备份→分列（无）→TRIM 清空格→文本转数值→删除重复项（按订单号，报告删除 1 行）→核对：清洗前金额合计（含文本 6000 时 SUM 忽略它）与清洗后合计相差 6000，恰好是那行文本数字——确认无误删后交表。清洗后 5 行金额 8000、3000、6000、4500、7000，合计 28500。

## 5. 公式和代码

```excel
=TRIM(CLEAN(A2)) → 张三（A2=张三带尾空格时）
=SUBSTITUTE(A2,CHAR(160),"") → 去不间断空格
=SUM(C2:C6) → 28500（清洗后 C2:C6 是 8000、3000、6000、4500、7000 时）
=UNIQUE(A2:A6) → 去重后的名单（2021／365）
```

- `=TRIM(CLEAN(A2))` → 张三：TRIM 删首尾空格，CLEAN 删不可见字符；组合是清洗标配
- `=SUBSTITUTE(A2,CHAR(160),"")` → 去不间断空格：网页复制来的空格常是 CHAR(160)，TRIM 删不掉，必须用 SUBSTITUTE 替换
- `=SUM(C2:C6)` → 28500：8000+3000+6000+4500+7000=28500；清洗前后合计核对就用它
- `=UNIQUE(A2:A6)` → 去重后的名单：UNIQUE 一公式返回去重列表，原表不动；2021／365 可用

## 6. 实际工作场景

### 每月接系统导出的报表

系统导出的表每月都带同样的脏：空格、文本数字、重复行。把清洗步骤记成固定流程（备份→分列→TRIM/CLEAN→转数值→去重→核对），每月 10 分钟走完；熟练后录成 Power Query（见 Power Query 篇）实现一键清洗。

### 合并三个部门交来的表

三张表格式不一：先统一列顺序与表头，再逐张清洗（空格、文本数字），最后追加合并。用删除重复项按"姓名+日期"两列去重，防止同一人同一天被算两次。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 分列覆盖了右侧数据 | 分列前右侧没有留空列 | 分列前先插入足够空列；或先分列到新表再粘回来 |
| 去重删错了行 | 勾选的列不对（如只勾了姓名，同名不同人被误删） | 去重依据列要能唯一标识一行（如订单号，或姓名+日期两列组合） |
| TRIM 清不掉空格 | 那是网页来的不间断空格 CHAR(160) | 先 SUBSTITUTE(CHAR(160),"") 再 TRIM |
| 清洗后合计对不上 | 某步误删或改了数值 | 每步前后都用 SUM 核对合计；备份表在手，随时可回滚重洗 |
| 文本数字转完还是文本 | 只改了格式没重新确认 | 改格式不够：用分列直接完成，或选择性粘贴→乘 1，强制重算 |
