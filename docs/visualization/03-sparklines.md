## 1. 学习目标

学完本篇，你将能够：
- 给月度销售额列做出折线迷你图，并读出 2 月升、3 月跌、4 月冲高的趋势
- 给 KPI 完成率列做出柱形迷你图，并说出哪两项达标、哪两项未达标
- 用数据条给 1–4 月销售额排序，并算出每根数据条的相对长度
- 用图标集给 4 个月的完成率分段（达标／接近／未达标），并说出每段的阈值
- 判断什么时候用迷你图、什么时候用完整图表，并说出迷你图的 3 个局限

本篇是 C14-L2-3 的专篇，分工说明：条件格式的规则设置（突出显示、项目选取、数据条、色阶、图标集的完整做法与公式规则）见 C06《条件格式》，本篇不重复讲；本篇只讲数据条与图标集在仪表盘里的可视化用法，以及 C06 没有的迷你图。迷你图的数据源直接用两个配套模板的现有列，不新建文件。

## 2. 基础概念

### 2.1 迷你图：一个单元格里的微型图表

迷你图是放在单个单元格里的微型图表，大小只有一个单元格，不占图表位置。Excel 提供三种类型：

| 类型 | 样子 | 适合看什么 | 本篇实例 |
|---|---|---|---|
| 折线迷你图 | 一根小折线 | 随时间的变化趋势 | 月度销售额 120000 → 135000 → 98000 → 152000 的起伏 |
| 柱形迷你图 | 几根小柱子 | 各期数值的大小对比 | 4 项 KPI 完成率 92.00%、115.00%、92.63%、103.33% 的高低 |
| 盈亏迷你图 | 正值向上、负值向下的小方块 | 正负分布 | 环比的正负：+12.50%、-27.41%、+55.10%（2 正 1 负） |

迷你图只显示形状，不显示坐标轴与数字——读数要回表格里看原值。它适合放在数据旁边做"一眼趋势"，不适合单独讲结论。

### 2.2 迷你图的三个局限

- **没有坐标轴**：看不出绝对值，只能看形状。月度销售额迷你图能看出 3 月跌了，但看不出跌到了 98000 元。
- **不随筛选自动换源**：源数据区域写死后，筛选掉的行仍留在迷你图里；要跟筛选联动得配合透视表，见 C08。
- **打印易糊**：行高太矮时迷你图会被压扁，打印前要把行高调到 15 磅以上再检查。

### 2.3 数据条：用长度代替读数

数据条是在单元格里画一根横条，数值越大条越长。条的长度比例就是数值除以区域最大值的比例：1–4 月销售额里最大值是 4 月的 152000 元，1 月 120000 元的条长就是 120000 / 152000 = 78.95%，3 月 98000 元的条长是 64.47%。数据条适合做完成率、销售额这类"一眼比大小"的列。数据条的规则设置（颜色、最小值／最大值类型、仅显示数据条）见 C06《条件格式》第 2.4 节，本篇只讲长度比例的算术与仪表盘里的用法。

### 2.4 图标集：用符号代替文字

图标集是在单元格旁加一个符号（箭头、旗帜、信号灯），表示该值落在哪个分段。本篇用的分段是：完成率大于等于 100% 显示绿旗（达标）、90% 至 100% 显示黄旗（接近）、低于 90% 显示红旗（未达标）。图标集的规则入口与阈值写法见 C06《条件格式》，本篇只讲分段阈值的定法与仪表盘里的读法。

### 2.5 什么时候用迷你图，什么时候用完整图表

| 场景 | 用什么 | 原因 |
|---|---|---|
| 每行数据旁都要一个趋势 | 迷你图 | 一行一个小图，完整图表放不下 100 行 |
| 仪表盘 KPI 卡片旁的趋势 | 迷你图 | 卡片空间小，只够放一个单元格的图 |
| 要讲一个正式结论（给老板看） | 完整图表 | 完整图表有标题、坐标轴与数据标签，见 C07 |
| 要比较 10 个以上类别 | 完整图表 | 迷你图太小，10 根以上柱子挤成一团 |

## 3. 操作步骤

### 3.1 给月度销售额做折线迷你图

数据源：`图表-销售仪表盘模板.xlsx` 的"月度销售"表 B 列（销售额 120000、135000、98000、152000）。

1. 在"月度销售"表右侧空列（如 G 列）写表头"趋势"，选中 G2 单元格作为迷你图的位置（待补图）。
2. 点插入 → 迷你图 → 折线图，数据范围选 B2:B5，位置范围选 G2，点确定（待补图）。
3. 选中 G2，在迷你图工具 → 设计里勾选"标记最大值点"与"标记最小值点"，最高点 152000（4 月）与最低点 98000（3 月）会标出来（待补图）。
4. 把 G2 下拉填充到 G5，每行一个迷你图——注意每行迷你图的数据范围仍是整段 B2:B5，不是单行，这样 4 个迷你图形状相同；如果只要一个总趋势，只留 G2 一个即可（待补图）。
5. 检查：迷你图形状应是升、跌、冲高三段；如果形状是平的，检查数据范围是不是只选了一格（待补图）。

### 3.2 给 KPI 完成率做柱形迷你图

数据源：`图表-KPI看板模板.xlsx` 的"KPI看板"表 D 列（完成率 92.00%、115.00%、92.63%、103.33%）。

1. 在"KPI看板"表右侧空列（如 G 列）写表头"完成率对比"，选中 G2（待补图）。
2. 点插入 → 迷你图 → 柱形图，数据范围选 D2:D5，位置范围选 G2，点确定（待补图）。
3. 在设计里把"负值点"颜色改成红色——完成率没有负值，这一步是为以后复用准备的（待补图）。
4. 检查：4 根柱子里第 2 根（新客户数 115.00%）最高、第 1 根（销售额 92.00%）最矮，与 D 列数字一致（待补图）。

### 3.3 给月度销售额加数据条

1. 选中"月度销售"表的 B2:B5（销售额列）（待补图）。
2. 点开始 → 条件格式 → 数据条 → 选一种蓝色实心填充（待补图）。
3. 检查条长比例：4 月的条最长（100.00%）、3 月的条最短（64.47%），与第 5 节算出的比例一致；不一致就检查是不是选区多选了合计行（待补图）。
4. 规则细节（最小值／最大值类型、仅显示数据条）见 C06《条件格式》第 2.4 节，本篇不重复（待补图）。

### 3.4 给月度完成率加图标集

1. 选中"月度销售"表的 D2:D5（完成率列）（待补图）。
2. 点开始 → 条件格式 → 图标集 → 选三色旗帜（待补图）。
3. 点条件格式 → 管理规则 → 编辑规则，把阈值改成：大于等于 1 显示绿旗、0.9 至 1 显示黄旗、低于 0.9 显示红旗（待补图）。
4. 检查：1 月 120.00% 绿旗、2 月 122.73% 绿旗、3 月 89.09% 红旗、4 月 126.67% 绿旗；3 月是唯一红旗，与它是唯一未达标月份一致（待补图）。

| 4 月 | 152000 | 冲到最高点（环比 +55.10%） |

读法：迷你图一眼看出"升—跌—冲高"的趋势，但具体数值要回 B 列看：最低点 98000 元、最高点 152000 元，两者相差 54000 元。

数据源：KPI 看板模板"KPI看板"表 D 列。

| 指标 | 完成率 | 状态 |
|---|---|---|
| 销售额 | 92.00% | 未达标 |
| 新客户数 | 115.00% | 达标 |
| 回款率 | 92.63% | 未达标 |
| 客户满意度 | 103.33% | 达标 |

| 月份 | 销售额 | 数据条相对长度 |

## 5. 公式和代码

### 5.1 迷你图的数据源公式（先把数算对再画图）

```excel
= B2/C2                          → 120.00%（1 月完成率：120000/100000）
= B3/C3                          → 122.73%（2 月完成率：135000/110000）
= B4/C4                          → 89.09%（3 月完成率：98000/110000）
= B5/C5                          → 126.67%（4 月完成率：152000/120000）
= B3/B2-1                        → 12.50%（2 月环比）
= B4/B3-1                        → -27.41%（3 月环比，盈亏迷你图的唯一负值）
= B5/B4-1                        → 55.10%（4 月环比）
= MAX(B2:B5)                     → 152000（迷你图最高点：4 月）
= MIN(B2:B5)                     → 98000（迷你图最低点：3 月）
= C2/B2                          → 92.00%（销售额完成率：460000/500000）
= C3/B3                          → 115.00%（新客户数完成率：230/200）
```

要点：迷你图本身没有公式，它画的是引用区域里的值；区域里的值必须先用公式算对，迷你图画出来才是对的。最高点与最低点用 MAX 与 MIN 单独算出来，核对迷你图上标记的点对不对。

### 5.2 数据条相对长度公式

```excel
= 120000/152000                  → 78.95%（1 月数据条长度）
= 135000/152000                  → 88.82%（2 月数据条长度）
= 98000/152000                   → 64.47%（3 月数据条长度）
= 152000/152000                  → 100.00%（4 月数据条长度）
= 92.00%/115.00%                 → 80.00%（销售额完成率数据条长度，最大值 115.00% 为 100%）
= 92.63%/115.00%                 → 80.55%（回款率完成率数据条长度）
= 103.33%/115.00%                → 89.85%（客户满意度完成率数据条长度）
```

要点：数据条长度 = 该值 / 区域最大值；换一个区域（销售额列与完成率列）最大值就变了，比例要重算，不能把销售额列的比例套到完成率列上。

### 5.3 图标集分段判断公式（阈值写成公式才可核对）

```excel
= IF(D2>=1,"绿旗",IF(D2>=0.9,"黄旗","红旗"))   → 绿旗（1 月完成率 120.00%）
= IF(D4>=1,"绿旗",IF(D4>=0.9,"黄旗","红旗"))   → 红旗（3 月完成率 89.09%）
= IF(D2>=1,"达标","未达标")                   → 未达标（KPI 看板销售额完成率 92.00%）
= COUNTIF(D2:D5,">=1")                        → 3（月度达标月数：4 个月里 3 个月绿旗）
```

要点：图标集的分段阈值（1 与 0.9）先写成 IF 公式验算一遍，确认每行的旗子颜色与公式结果一致，再去条件格式里设同样的阈值；阈值只在条件格式里设、不在公式里验算，设错了很难发现。

## 6. 实际工作场景

### 6.1 场景一：月度销售跟踪表，每行一个趋势

场景：你是销售助理，要维护一张 12 个月的销售跟踪表，老板要求"不用点开图表，每行就能看出趋势"。

做法：在销售额列旁加一列"趋势"，用折线迷你图画整段 B2:B5 的走势；在完成率列加图标集（大于等于 100% 绿旗、90% 至 100% 黄旗、低于 90% 红旗）。以 1–4 月为例：迷你图显示升—跌—冲高，图标集里 3 月是唯一红旗。每月追加一行后，把迷你图的数据范围与图标集的适用区域向下扩一行即可。

结果：老板扫一眼跟踪表就知道 3 月出了问题、4 月冲到了 152000 元；想看具体数字再读 B 列与 D 列，不用另开图表页。

### 6.2 场景二：KPI 看板一屏放下 4 项指标的对比

场景：部门周会要投屏 KPI 看板，4 项指标的完成率要一屏讲清，但投屏位置只够放一张表。

做法：在 KPI 看板表的完成率列旁加柱形迷你图（D2:D5），再在同一列加数据条（最大值 115.00% 为 100.00%）：销售额 92.00% 的条长 80.00%、新客户数 115.00% 的条长 100.00%、回款率 92.63% 的条长 80.55%、客户满意度 103.33% 的条长 89.85%。状态列保留"达标／未达标"文字，图标集只做辅助。

结果：投屏上一眼看出新客户数最高、销售额最低；状态列文字说明 92.00% 与 92.63% 都是未达标，不会因为柱子高一点就误判为达标。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 迷你图是一条平线，看不出起伏 | 数据范围只选了一格，或 4 个月数值差异被行高压缩 | 数据范围改成整段 B2:B5；行高调到 15 磅以上 |
| 迷你图形状与数字对不上 | 数据源列是手填的，某月改了数迷你图没变 | 数据源列全改公式（如完成率 `=B/C`），不许手填 |
| 数据条长短与数值比例不符 | 选区多选了合计行，最大值变成了合计 505000 | 数据条选区只选 B2:B5，不含合计行；重算比例核对 |
| 3 月完成率 89.09% 显示绿旗 | 图标集阈值是默认的 67% 与 33%，不是按 100% 分段 | 管理规则 → 编辑规则，把阈值改成 1 与 0.9 |
| 完成率列的数据条把 92.00% 与 92.63% 画成一样长 | 两值只差 0.63 个百分点，条长差 0.55%，肉眼难分辨 | 条长接近时不要只看条，读 D 列数字与状态列文字 |
| 迷你图打印出来糊成一团 | 行高太矮，迷你图被压扁 | 打印前把行高调到 15 磅以上，打印预览检查 |
| 筛选后迷你图形状不变 | 迷你图数据源区域写死，不跟随筛选 | 迷你图不跟筛选联动是正常局限；要联动改用透视表加切片器，见 C08 |
| 只用颜色表示达标，黑白打印后分不清 | 颜色是唯一信息载体，打印丢色即丢信息 | 状态列保留"达标／未达标"文字，颜色与图标只做辅助 |

6. 一张 12 个月的销售跟踪表，老板要求每行都能看出趋势、又不想另开图表页，应该用什么？它有哪两个局限需要在使用时注明？

## 10. 参考答案

1. 最高点：`=MAX(B2:B5)` → 152000（4 月）；最低点：`=MIN(B2:B5)` → 98000（3 月）。迷你图形状是升（2 月 135000）、跌（3 月 98000）、冲高（4 月 152000）。解析：迷你图只显示形状，最高点与最低点要单独用 MAX／MIN 算出来核对。
2. 最高的是第 2 根（新客户数 115.00%），最矮的是第 1 根（销售额 92.00%）。柱子高低不能直接判断是否达标：92.63% 的柱子比 92.00% 高一点，但两项都是未达标；达标与否要看状态列的文字。解析：迷你图只比大小，达标是阈值判断，两回事。
3. 1 月 `=120000/152000` → 78.95%；2 月 `=135000/152000` → 88.82%；3 月 `=98000/152000` → 64.47%；4 月 `=152000/152000` → 100.00%。如果选区含合计行 505000，最大值变成 505000，4 月的条长只剩 152000/505000 = 30.10%，全部条子缩成一小截。解析：数据条长度 = 该值 / 区域最大值，合计行不是月份数据，不能进选区。
4. 3 月公式：`=IF(D4>=1,"绿旗",IF(D4>=0.9,"黄旗","红旗"))` → 红旗（89.09% 低于 0.9）。1 月公式：`=IF(D2>=1,"绿旗",IF(D2>=0.9,"黄旗","红旗"))` → 绿旗（120.00% 大于等于 1）。解析：阈值先写成 IF 公式验算，再去条件格式里设同样的值。
5. 销售额条长：`=92.00%/115.00%` → 80.00%；客户满意度条长：`=103.33%/115.00%` → 89.85%。解析：不能套用销售额列的比例，因为两个区域的最大值不同（销售额列是 152000，完成率列是 115.00%），比例要按各自区域的最大值重算。
6. 用折线迷你图放在每行旁。两个局限：① 没有坐标轴，只能看形状、看不出绝对值，读数要回原值列；② 不跟随筛选，筛选掉的行仍留在迷你图里。解析：迷你图适合"每行一个趋势"的轻量场景，要讲正式结论或跟筛选联动时改用完整图表或透视表加切片器。
