## 1. 学习目标

学完本篇，你将能够：
- 用"结论层—对比层—趋势层"三层布局搭出一页仪表盘，并说出每层放什么、不放什么
- 用 KPI 看板模板的 4 项指标做出 KPI 卡片，写出完成率与达标状态公式并报出每项的结果
- 用销售仪表盘模板的月度销售表做出柱线组合图，并算出 1–4 月合计、总体完成率与每月环比
- 用一个切片器联动多张数据透视表，并说出联动的前提条件（同源数据模型）
- 写出随筛选变化的动态标题公式，并报出筛选前后的标题文字
- 指出仪表盘数据源的 3 种常见错误（手填数字、跨表直链明细、区域写死）并逐一修复

本篇是 C14-L2-2 的专篇，是 C14 的核心实操篇：C14-L2-1《可视化原则》讲选图与配色的道理，本篇讲把道理落成一页能用的仪表盘。图表本身的创建步骤见 C07《柱形图与条形图》《组合图》，透视表与切片器的完整做法见 C08《数据透视表》，本篇只讲仪表盘层面的布局与集成，不重复讲单种图的步骤。

## 2. 基础概念

### 2.1 三层布局：结论在上，细节在下

一页仪表盘从上到下分三层，阅读顺序就是结论的展开顺序：

| 层 | 内容 | 回答的问题 | 本篇实例 |
|---|---|---|---|
| 结论层 | KPI 卡片（3–4 张） | 结果怎么样 | 总销售额 505000、总体完成率 114.77%、达标月数 3 个月、最高月 152000 |
| 对比层 | 实际 vs 目标的组合图 | 哪里好、哪里差 | 柱线组合图：3 月 98000 是唯一低于目标的月份 |
| 趋势层 | 月度折线图 | 怎么走过来的 | 2 月升、3 月跌、4 月冲到最高 |

结论层只放数字与状态，不放图；对比层与趋势层各放一张图。任何一层超了（例如结论层放 6 张卡片），整页就失去"一眼看懂"的作用，见 C14-L2-1 的密度上限（每页 6 个元素）。

### 2.2 KPI 卡片：一个数字、一个状态、一句话

一张 KPI 卡片只有三个部分：大字号数字、达标状态、单位与口径说明。例如销售额卡片写"¥460,000 元"（大字）、"未达标"（状态）、"目标 ¥500,000 元，完成率 92.00%"（口径）。数字必须用公式链到汇总表或模板的公式列，不许手填；手填的数字在源数据更新后不会变，仪表盘就成了静态图。KPI 看板模板里完成率列 D 列本身就是公式 `=C/B`，状态列 E 列是公式 `=IF(D>=1,"达标","未达标")`，卡片直接引用这两列即可。

### 2.3 切片器联动：一个筛选，全页跟着变

切片器是透视表的可视化筛选按钮。联动的意思是：点一下切片器里的"华东"，页上所有透视表与透视图同时只显示华东的数据。联动的前提是**多张透视表来自同一份源数据**：同一个数据源做的透视表，才能被同一个切片器连上；来自两份不同明细表的透视表，点切片器时只会动其中一张。做法细节见 C08《数据透视表》的切片器与日程表一节，本篇第 3 节只给仪表盘里的操作顺序。

### 2.4 动态标题：标题跟着筛选走

动态标题是用公式拼出来的标题文字，筛选条件一变，标题里的数字与范围跟着变。例如标题公式引用总体完成率，1–4 月的标题是"1–4 月销售仪表盘：完成率 114.77%"；如果切片器只选了 4 月，标题就变成"4 月销售仪表盘：完成率 126.67%"。标题的数字部分必须是公式结果，不许手填；手填的标题在筛选后会撒谎。

### 2.5 数据源单一来源原则

仪表盘上所有数字只能来自一张汇总表（或模板的公式列），不许有的数字链汇总表、有的数字直接链原始明细。销售仪表盘模板里图表的数据源是"月度销售"表的 B 列与 C 列，KPI 卡片引用同一张表的合计行——全页只有一个数字源头。源头一变，全页跟着变；源头错了，全页一起错，排查时只用查一个地方。

## 3. 操作步骤

本节以两个配套模板为操作对象：`图表-KPI看板模板.xlsx` 的"KPI看板"表与 `图表-销售仪表盘模板.xlsx` 的"月度销售"表。

1. 准备数据源：打开 `图表-销售仪表盘模板.xlsx`，确认"月度销售"表 1–4 月齐全，D 列完成率是公式 `=B/C`、E 列环比是公式 `=B/上一月-1`；再打开 `图表-KPI看板模板.xlsx`，确认"KPI看板"表 D 列完成率是公式 `=C/B`、E 列状态是公式 `=IF(D>=1,"达标","未达标")`（待补图）。
2. 核对总量：在"月度销售"表底部检查三处——销售额合计 `=SUM(B2:B5)` → 505000；目标合计 `=SUM(C2:C5)` → 440000；总体完成率 `=SUM(B2:B5)/SUM(C2:C5)` → 114.77%。任何一处不对，先查明细，不要往下搭仪表盘（待补图）。
3. 新建仪表盘页：新建一张工作表，命名为"仪表盘"，作为唯一展示页；两张模板表只做数据源，不在展示页上重复贴明细（待补图）。
4. 做 KPI 卡片区：在仪表盘页顶部留 4 个卡片位，每张卡片三行——大字号数字、状态、口径。销售额卡片数字引用 KPI 看板表的实际值 460000，状态引用 E 列的公式结果"未达标"，口径行写"目标 500000，完成率 92.00%"（待补图）。
5. 做组合图：选中"月度销售"表的"月份＋销售额＋目标"三列，插入 → 组合图 → 簇状柱形图 - 折线图（销售额用柱、目标用线），图表标题写结论句"3 月是唯一未达标月份"，放到仪表盘页中部（待补图）。
6. 做趋势图：选中"月份＋销售额"两列，插入 → 折线图，标题写"4 月 152000 元，1–4 月最高"，放到仪表盘页底部（待补图）。
7. 做切片器联动：选中月度销售明细做的透视表（做法见 C08），插入 → 切片器 → 勾选"月份"；再点切片器右键 → 报表连接，勾选本页另一张透视表，让一个切片器同时控制两张表。联动前确认两张透视表来自同一份源数据，否则报表连接里看不到另一张表（待补图）。
8. 写动态标题：在仪表盘页顶部写标题公式 `="1–4 月销售仪表盘：完成率 "&TEXT(SUM(月度销售!B2:B5)/SUM(月度销售!C2:C5),"0.00%")`，结果为"1–4 月销售仪表盘：完成率 114.77%"（待补图）。
9. 上色与对齐：全页只用一套配色——达标绿色、未达标红色、主色商务蓝；4 张卡片等宽等高、左对齐；两张图同宽、左右对齐（待补图）。
10. 验收：数元素——4 张卡片＋2 张图＝6 个，正好在上限内；逐项核对卡片数字与图表数字（销售额 460000、新客户 230、回款率 0.88、满意度 0.93、合计 505000、总体完成率 114.77%），点一下切片器确认两张透视表同时变化、标题跟着变（待补图）。

## 5. 公式和代码

### 5.1 KPI 卡片公式（KPI 看板模板）

```excel
= C2/B2                          → 92.00%（销售额完成率：460000/500000）
= C3/B3                          → 115.00%（新客户数完成率：230/200）
= C4/B4                          → 92.63%（回款率完成率：0.88/0.95）
= C5/B5                          → 103.33%（客户满意度完成率：0.93/0.90）
= IF(D2>=1,"达标","未达标")      → 未达标（销售额状态）
= IF(D3>=1,"达标","未达标")      → 达标（新客户数状态）
= COUNTIF(D2:D5,">=1")           → 2（达标指标数：4 项里 2 项达标）
```

要点：完成率列 D 列是公式 `=C/B`，状态列 E 列是公式 `=IF(D>=1,"达标","未达标")`，卡片直接引用这两列的结果；判断达标用完成率大于等于 1，不是看实际值本身——回款率实际值 0.88 看起来不小，但目标是 0.95，完成率只有 92.63%，仍是未达标。

### 5.2 仪表盘合计与环比公式（销售仪表盘模板）

```excel
= SUM(B2:B5)                     → 505000（1–4 月销售额合计）
= SUM(C2:C5)                     → 440000（1–4 月目标合计）
= SUM(B2:B5)/SUM(C2:C5)          → 114.77%（总体完成率）
= B2/C2                          → 120.00%（1 月完成率）
= B3/C3                          → 122.73%（2 月完成率）
= B4/C4                          → 89.09%（3 月完成率）
= B5/C5                          → 126.67%（4 月完成率）
= B3/B2-1                        → 12.50%（2 月环比）
= B4/B3-1                        → -27.41%（3 月环比）
= B5/B4-1                        → 55.10%（4 月环比）
= COUNTIF(D2:D5,">=1")           → 3（达标月数：4 个月里 3 个月达标）
```

要点：总体完成率 114.77% 是合计除以合计目标，不能用 4 个月完成率的简单平均 114.62% 代替；环比是本月除以上一月减 1，1 月没有上一月，环比列留空不写 0。

### 5.3 动态标题与卡片文字公式

```excel
= "1–4 月销售仪表盘：完成率 "&TEXT(SUM(月度销售!B2:B5)/SUM(月度销售!C2:C5),"0.00%")   → 1–4 月销售仪表盘：完成率 114.77%
= TEXT(SUM(月度销售!B2:B5),"¥#,##0")&" 元"   → ¥505,000 元（总销售额卡片）
= TEXT(SUM(月度销售!B2:B5)-SUM(月度销售!C2:C5),"¥#,##0")&" 元"   → ¥65,000 元（超额完成卡片：505000-440000）
= "3 月缺口 "&TEXT(110000-98000,"#,##0")&" 元"   → 3 月缺口 12,000 元（唯一未达标月份卡片）
```

要点：卡片文字用 TEXT 拼出来，数字部分仍是公式引用的汇总值，汇总表一变卡片跟着变；不要把"505000"写死在卡片里，写死了就是一张静态图。

## 6. 实际工作场景

### 6.1 场景一：月度销售复盘会，一页仪表盘讲清 1–4 月

场景：你是销售助理，每月初要向老板汇报上月销售。老板的问题永远是三个：卖了多少、哪个月最好、哪个月出了问题。

做法：打开 `图表-销售仪表盘模板.xlsx`，按第 3 节搭一页仪表盘：顶部 4 张 KPI 卡片（总销售额 ¥505,000 元、总体完成率 114.77%、达标月数 3 个月、最高月 152000 元），中间柱线组合图（3 月柱子低于目标线），底部月度折线图（3 月跌、4 月涨）。再打开 `图表-KPI看板模板.xlsx`，把 4 项 KPI 的完成率与状态做成第二组卡片。

结果：汇报时可以直接说结论——"1–4 月总体完成率 114.77%，超额 65000 元；4 月 152000 元是最高月，环比 +55.10%；3 月 98000 元是唯一未达标的月份，完成率 89.09%、环比 -27.41%、缺口 12000 元"。数字全部链到模板的公式列，老板追问任何一个数，都能当场点开公式溯源。

### 6.2 场景二：区域经理只看自己区域，切片器一点就切换

场景：公司有华东、华南、华北、华西四个区域，每位区域经理开会时只想看自己区域的数据，但仪表盘只有一页。

做法：按 C08 的做法，以 12 行订单明细做两张透视表（分产品、分月），插入一个"地区"切片器并用报表连接同时连上两张表；动态标题公式引用筛选后的汇总值。开会时点"华东"，两张表与标题同时切到华东（4 笔订单、销售额 29600 元）；点"华南"，同时切到华南（4 笔订单、销售额 28000 元）。数字来源见 C13《销售数据分析》第 4.3 节的分地区汇总表。

结果：不用为每个区域各做一页仪表盘，一页加一个切片器就覆盖四个区域；标题跟着筛选变，不会出现"标题写华东、图表是华南"的错位。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 卡片数字与汇总表对不上 | 卡片数字是手填的，汇总表更新后卡片没变 | 卡片数字一律用公式引用汇总表或模板公式列，不许手填 |
| 总体完成率写成 114.62% | 用了 4 个月完成率的简单平均，忽略各月目标权重 | 总体完成率用合计除以合计目标：505000 / 440000 → 114.77% |
| 1 月环比显示 0% | 1 月没有上一月，公式 `=B2/B1-1` 引用了表头 | 1 月环比列留空；环比公式从 2 月开始写 `=B3/B2-1` |
| 点切片器只有一张透视表变化 | 另一张透视表来自不同的源数据，或没勾报表连接 | 两张透视表用同一份源数据重做；切片器右键 → 报表连接 → 勾选另一张表 |
| 筛选后标题还是"1–4 月完成率 114.77%" | 标题是手填文字，不随筛选变 | 标题改用公式拼接，如 `="1–4 月销售仪表盘：完成率 "&TEXT(总体完成率,"0.00%")` |
| 仪表盘数字有的链汇总表、有的链明细 | 数据源不唯一，排查时不知道信哪一个 | 全页数字只链一张汇总表（或模板公式列），明细表只做源头 |
| 每月追加一行后图表不更新 | 图表数据源区域写死到第 5 行，新增行不在区域内 | 图表右键 → 选择数据 → 把区域扩展到新增行；或把明细转成超级表 |
| KPI 卡片放了 6 张，页面挤不下 | 结论层超载，违反每页 6 个元素上限 | 只留最重要的 4 张卡片，其余指标放到第二页或附表 |

## 9. 练习题

1. 用 KPI 看板模板的数据，写出销售额与回款率的完成率公式与结果，并说出两项的状态（达标／未达标）与缺口。

4. 写出动态标题公式，使标题显示"1–4 月销售仪表盘：完成率 114.77%"；如果只看 4 月，标题里的完成率应该变成多少？
5. 一页仪表盘上有两张透视表，点"地区"切片器后只有一张表变化。列出两种可能原因与对应的修复方法。

## 10. 参考答案

<summary>点击查看答案</summary>

1. 销售额：`=C2/B2` → 92.00%，未达标，缺口 500000 - 460000 = 40000 元。回款率：`=C4/B4` → 92.63%，未达标，缺口 95.00% - 88.00% = 7 个百分点。解析：完成率 = 实际值 / 目标值，大于等于 100% 为达标；缺口是目标减实际。
2. 合计：`=SUM(B2:B5)` → 505000；目标合计：`=SUM(C2:C5)` → 440000；总体完成率：`=SUM(B2:B5)/SUM(C2:C5)` → 114.77%。解析：不能用 4 个月完成率的平均数 (120.00% + 122.73% + 89.09% + 126.67%) / 4 = 114.62% 代替，因为各月目标权重不同，正确算法是合计除以合计目标。
3. 3 月环比公式：`=B4/B3-1` → -27.41%。3 月缺口：110000 - 98000 = 12000 元。解析：环比是本月除以上一月减 1，负值表示下跌；缺口是目标减实际。
4. 标题公式：`="1–4 月销售仪表盘：完成率 "&TEXT(SUM(月度销售!B2:B5)/SUM(月度销售!C2:C5),"0.00%")` → 1–4 月销售仪表盘：完成率 114.77%。只看 4 月时完成率变成 126.67%（152000 / 120000）。解析：标题数字必须是公式结果，筛选后跟着变。
5. 原因一：两张透视表来自不同的源数据，切片器连不上另一张——修复：用同一份源数据重做另一张透视表。原因二：没勾报表连接——修复：点切片器右键 → 报表连接 → 勾选另一张透视表。解析：联动的前提是同源数据，操作是报表连接，两步缺一不可。
6. 完成率 126.67% 回答"4 月实际比目标好多少"（152000 / 120000）；环比 +55.10% 回答"4 月比 3 月涨了多少"（152000 / 98000 - 1）。解析：一个比目标、一个比上一月，分母不同，不能互相代替；4 月两个数字都是正的，但含义完全不同。
