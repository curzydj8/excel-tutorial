# 公式审核与调试：追踪引用、公式求值与错误检查

- **所属栏目**：C03 公式基础与高级公式 ／ C03-L2-5 公式审核与调试
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：进阶
- **预计阅读时长**：15 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 用追踪引用单元格与追踪从属单元格画出公式的来龙去脉
- 用公式求值一步步看公式的中间结果，定位算错的那一步
- 用错误检查与监视窗口批量排查全表的公式错误
- 用显示公式与定位条件快速找到"看起来是数、实际是文本"的单元格

## 2. 基础概念

**追踪引用单元格**：选中一个公式格，公式→追踪引用单元格，箭头从它引用的格指向它。箭头指错地方，就是引用错了。**追踪从属单元格**反过来：箭头从它指向引用它的公式格，删格、删行前先看它，知道谁会受影响。

**公式求值**：公式→公式求值，打开逐步求值窗口，每点一次"求值"就算一步，能看到 `VLOOKUP` 的查找值、`IF` 的条件判断、`SUM` 的求和范围每一步的中间结果。公式结果不对但不知道哪一步错时，用它逐段定位。

**错误检查**：公式→错误检查，逐个扫描全表的错误值（#VALUE!、#N/A、#REF! 等），每个错误给"帮助"、"显示计算步骤"、"忽略错误"等选项。左上角绿色小三角就是错误检查的标记：有三角不一定真有错，可能是"公式与相邻公式不一致"这类提醒。

**监视窗口**：公式→监视窗口，把关键结果格（如合计、税率）加进去，窗口常驻显示它们的当前值。改动源数据时不用翻页找合计格，在监视窗口直接看变化。

**显示公式**：公式→显示公式（`Ctrl + ``），全表切换显示公式文本而非结果。检查引用、核对公式结构时用它；检查完再按一次切回。

**定位条件找问题格**：`F5`→定位条件→公式/常量，可一次选中全表所有公式格或所有文本格。"看起来是数、实际是文本"的格（左上角绿三角、左对齐显示）最适合这样批量找出来。

## 3. 操作步骤

1. 追踪引用：点结果异常的公式格，公式→追踪引用单元格，看箭头指向的源格对不对；点"移去箭头"清除。
2. 追踪从属：点要删除的源数据格，公式→追踪从属单元格，看哪些公式在用它；确认无误再删。
3. 公式求值：点算错的公式格，公式→公式求值，反复点"求值"，看到哪一步的中间结果与预期不符，问题就在那一步。
4. 错误检查：公式→错误检查→错误检查，逐个过全表错误；每个错误看提示再决定修还是忽略。
5. 监视关键格：公式→监视窗口→添加监视，选中合计格与参数格；改动数据时在窗口里实时看合计变化。
6. 显示公式核对：按 `Ctrl + `` 显示全表公式，逐列核对引用范围有没有错位（如 SUM 范围少了一行），核对完再按一次切回。

## 4. 图文示例

求和结果少算了：D7 的 `=SUM(D2:D6)` 结果是 4000，但手算应是 5000。追踪引用单元格看箭头：D2:D6 的范围没问题；公式求值逐步看：D4 的值是 0——点 D4 看编辑栏，里面是文本"1000"（带前导单引号，左对齐）。文本不参与求和，所以少了 1000。修复：D4 分列或乘 1 转数值，求和恢复 5000。教训：求和少算先查文本型数字。

## 5. 公式和代码

```excel
=SUM(D2:D6) → 5000（修复文本数字后）
=IFERROR(VLOOKUP(A2,表1!A:B,2,0),"未找到") → 未找到（A2 不在表1时）
```

- `=SUM(D2:D6)` → 5000：D4 文本"1000"转数值后，500+1000+750+1500+1250=5000，恢复正确
- `=IFERROR(VLOOKUP(A2,表1!A:B,2,0),"未找到")` → 未找到：IFERROR 兜底：VLOOKUP 报错时显示"未找到"而不是 #N/A，便于排查是数据缺失还是公式写错

## 6. 实际工作场景

### 接手一张公式全乱的旧表

先按 `Ctrl + `` 显示全表公式，逐列看引用范围；再用错误检查扫一遍全表错误；关键合计格加进监视窗口。修之前先备份一份，修完逐项核对合计值。

### VLOOKUP 查不到值

公式求值看查找值：A2 是"张三 "（带尾空格），表里是"张三"，空格导致匹配失败。用 TRIM 清空格或在公式里包一层 TRIM 再查。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 公式结果错但不报错 | 引用范围错位或文本型数字混入 | 公式求值逐步定位；定位条件找文本格；追踪引用单元格看箭头 |
| 追踪箭头满屏都是 | 多次追踪没清除 | 公式→移去箭头→移去所有箭头，一次清干净 |
| 绿色小三角到处都是 | 错误检查的提醒（如"与相邻公式不一致"） | 点格子看提示：真错就修，只是提醒可"忽略错误"；不要全表忽略 |
| 公式求值点不动 | 选中的不是公式格 | 先点含公式的单元格，再打开公式求值；文本格没有求值过程 |
