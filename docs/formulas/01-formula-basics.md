- **适用版本**：Excel 2016／2019／2021／365

## 1. 学习目标

学完本篇，你将能够：
- 说出公式的四个组成部分（等号、操作数、运算符、函数），并用 = 开头输入公式
- 正确使用算术、比较、文本连接三类运算符，并说出运算优先级
- 区分公式与结果：编辑栏看公式、单元格看结果，双击或按 F2 编辑公式
- 用公式审核的"显示公式"与"追踪引用单元格"快速检查公式

## 2. 基础概念

**公式结构**：所有公式都以 `=` 开头，如 `=B2+C2`。等号后面是操作数（数字、单元格引用、函数结果）与运算符的组合。`SUM`、`IF` 这类现成的计算单元叫函数，写法是 `函数名(参数1, 参数2)`，参数之间用英文逗号分隔。

**运算符三类**：算术运算符 `+ - * / % ^`（加减乘除、百分号、乘方）；比较运算符 `= > < >= <= <>`（返回 TRUE 或 FALSE）；文本连接符 `&`（把两段文本拼成一段，如 `=A2&"部"`）。优先级：括号最先，接着乘方、乘除、加减，最后是连接与比较；记不住就加括号，括号永远最优先。

**公式与结果**：单元格显示的是计算结果，编辑栏显示的是公式本身。双击单元格或按 `F2` 可进入编辑状态，光标定位到公式末尾；按 `Esc` 放弃修改，按 `Enter` 确认。公式→显示公式（`Ctrl + ``，反引号键）可让全表显示公式而不是结果，检查时用它。

**相对引用入门**：公式里的 `B2` 是相对引用，复制到下一行会自动变成 `B3`，复制到右一列会变成 `C2`。这是公式能"一写多用"的关键；想让它不跟着变，见下一篇引用方式（加 `$` 锁定）。

**常见第一错**：公式不以 `=` 开头（直接写 `SUM(B2:B10)` 只会显示文本）；用了中文括号 `（）` 或中文逗号 `，`（Excel 只认英文半角符号）；单元格是文本格式，公式被当文本显示（改回常规格式后双击回车重新确认）。

## 3. 操作步骤

1. 输入第一个公式：点 C2 输入 `=B2*2` 回车，C2 显示结果；再点 C2 看编辑栏，确认公式本身是 `=B2*2`。
2. 复制公式：选中 C2，拖填充柄向下到 C6，各行自动变成 `=B3*2`、`=B4*2`……（相对引用自动递增）。
3. 用函数求和：在 C7 输入 `=SUM(C2:C6)`，或点 C7 后按 `Alt + =` 自动求和。
4. 检查公式：公式→显示公式（或按 `Ctrl + ``）切换全表显示公式，核对每行引用是否正确，再按一次切回结果。
5. 改公式：双击单元格或按 `F2`，改完按 `Enter`；改错了按 `Esc` 放弃、按 `Ctrl + Z` 撤销。
6. 固定结果：公式算好后如需发给别人，复制区域→右键→选择性粘贴→数值，把公式变成结果值，防止对方改动源数据后结果跟着变。

## 4. 图文示例

工资表示例：A 列姓名，B 列基本工资（5000、6000、5500、7000、6500），C 列绩效系数（1.1、1.0、1.2、1.0、1.1）。D2 输入 `=B2*C2` 得 5500，拖填充柄到 D6 得 6000、6600、7000、7150；D7 用 `=SUM(D2:D6)` 得 32250；D8 用 `=AVERAGE(D2:D6)` 得 6450。核对：5500+6000+6600+7000+7150=32250，32250÷5=6450。

## 5. 公式和代码

```excel
=B2*C2 → 5500（B2=5000，C2=1.1 时）
=SUM(D2:D6) → 32250
=AVERAGE(D2:D6) → 6450
=B2&"部" → 销售部（B2=销售时）
```

- `=B2*C2` → 5500：5000×1.1=5500，实发工资=基本工资×绩效系数
- `=SUM(D2:D6)` → 32250：5500+6000+6600+7000+7150=32250，五人实发合计
- `=AVERAGE(D2:D6)` → 6450：32250÷5=6450，人均实发
- `=B2&"部"` → 销售部：& 连接文本："销售"+"部"拼成"销售部"

## 6. 实际工作场景

### 销售提成表

销售额在 B 列，提成比例 5% 写在 E1。C2 写 `=B2*$E$1`（E1 要锁定，见引用方式篇），拖填充柄全员一次算完；月底比例改成 6% 时只改 E1，全表跟着变。

### 成绩单：总分与平均分

语文、数学、英语在 B、C、D 列，E 列 `=SUM(B2:D2)` 求总分，F 列 `=AVERAGE(B2:D2)` 求平均分。拖填充柄一次完成全班，公式→显示公式检查一遍引用无错位。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 公式显示为文本不计算 | 没以 = 开头，或单元格是文本格式 | 补 =；或改回常规格式后双击单元格回车重新确认 |
| 公式里出现中文括号或中文逗号 | 输入法是中文状态 | 切英文输入法重输；公式体检工具可批量查全角符号 |
| 复制公式后结果全一样 | 引用被 $ 锁死了（绝对引用） | 去掉不需要的 $；相对引用才随复制递增 |
| 结果是 #VALUE! | 文本参与了数值运算 | 检查参与运算的格有没有文本型数字；用分列或乘 1 转数值 |
| 按 Enter 后光标乱跑 | 不知道 Enter 是下移、Tab 是右移 | Enter 下移一格、Shift+Enter 上移、Tab 右移、Shift+Tab 左移 |
