# 引用方式：相对引用、绝对引用、混合引用与跨表引用

- **所属栏目**：C03 公式基础与高级公式 ／ C03-L2-2 引用方式
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：入门
- **预计阅读时长**：20 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 说出相对引用、绝对引用、混合引用的区别，并用 $ 正确锁定行或列
- 用 F4 在四种引用状态间快速切换
- 写出跨表引用与跨工作簿引用，并理解三维引用的适用场景
- 诊断"复制公式后结果错位"，定位是引用没锁对

## 2. 基础概念

**相对引用**：`B2` 这样不带 `$` 的引用。公式复制到别处时，引用跟着目标位置同步移动：下移一行变 `B3`，右移一列变 `C2`。它是公式"一写多用"的基础。

**绝对引用**：`$B$2`，行列都锁定。公式复制到任何地方都指向 B2 不变。适用场景：引用某个固定参数格（如税率、提成比例、单价），全表共用一个格。

**混合引用**：`$B2`（锁列不锁行）或 `B$2`（锁行不锁列）。乘法表是经典场景：行标题在 A 列、列标题在第 1 行，公式 `=$A2*B$1` 往右拖时 A 列锁定、往下拖时第 1 行锁定，一张乘法表一个公式搞定。

**F4 切换**：编辑公式时光标放在引用上，按 `F4` 循环切换 `B2` → `$B$2` → `B$2` → `$B2` → `B2`。记住顺序，锁引用不用手敲 `$`。

**跨表引用**：引用其他工作表的单元格，写法是 `表名!地址`，如 `='11月'!C10`。表名含中文或空格时必须加单引号。跨工作簿引用还要带工作簿名，如 `[报表.xlsx]11月!C10`，源文件改名或移动后链接会断，慎用。

**三维引用**：对多个连续工作表的同一位置求和，如 `=SUM(一月:三月!B2)`，表示一月到三月这三张表 B2 的和。要求各表结构完全一致，适合"每月一张表、结构相同"的汇总场景。

## 3. 操作步骤

1. 写相对引用：D2 输入 `=B2*C2`，拖填充柄向下，各行自动递增；这是默认行为，不用加任何符号。
2. 写绝对引用：提成比例在 E1，C2 输入 `=B2*$E$1`（光标放在 E1 上按一次 F4 变成 $E$1），再拖填充柄，E1 始终不变。
3. 写混合引用：做 9×9 乘法表，B2 输入 `=$A2*B$1`，向右、向下拖满，行标题与列标题各锁一维。
4. 跨表引用：在汇总表输入 `=` 后直接点另一张表的单元格回车，Excel 自动写出 `='11月'!C10` 这样的引用，不用手敲表名。
5. 三维引用：汇总表输入 `=SUM(一月:三月!B2)`，一月到三月三张表 B2 相加；增删中间月份表时范围自动变化。
6. 检查引用：公式→追踪引用单元格，看箭头指向的格是不是你想要的；箭头指错就是引用锁错了。

## 4. 图文示例

提成表示例：B2:B6 是销售额 10000、20000、15000、30000、25000，提成比例 5% 写在 E1。C2 写 `=B2*$E$1` 得 500，拖到 C6 得 1000、750、1500、1250，合计 `=SUM(C2:C6)` 得 5000。验算：销售额合计 100000×5%=5000，与提成合计一致。反例：C2 写 `=B2*E1` 再拖，C3 会变成 `=B3*E2`（E2 是空值当 0），提成全变 0——这就是没锁定的后果。

## 5. 公式和代码

```excel
=B2*$E$1 → 500（B2=10000，E1=5% 时）
=SUM(C2:C6) → 5000
=$A2*B$1 → 6（A2=2，B1=3 时）
=SUM(一月:三月!B2) → 三张表 B2 之和
```

- `=B2*$E$1` → 500：10000×0.05=500；$E$1 绝对引用，复制到 C6 仍指向 E1
- `=SUM(C2:C6)` → 5000：500+1000+750+1500+1250=5000；与销售额合计 100000×5% 互相核对
- `=$A2*B$1` → 6：混合引用：$A2 锁列、 B$1 锁行，乘法表一公式通用
- `=SUM(一月:三月!B2)` → 三张表 B2 之和：三维引用：对一月、二月、三月三张表同一位置求和

## 6. 实际工作场景

### 提成比例月中调整

比例只写在 E1 一个格，全表公式都引用 `$E$1`。月中比例从 5% 调到 6%，只改 E1，全表提成自动重算——这就是绝对引用的价值：参数单点存放。

### 12 个月汇总表

每月一张表、结构相同，汇总表用三维引用 `=SUM(一月:十二月!B2)` 一次加总 12 张表。某月表插到中间，范围自动包含；表名改了要同步改公式。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 复制公式后结果全变 0 | 参数格没锁定，引用跟着跑到了空格 | 参数格用 $E$1 绝对引用；复制后用追踪引用单元格检查箭头 |
| F4 按了没反应 | 光标不在引用上，或在输入中文时按的 | 编辑公式时把光标放在引用字母上再按 F4；每按一次变一种状态 |
| 跨表引用显示 #REF! | 被引用的表被删或改名了 | 恢复表名或重建引用；删表前用追踪从属单元格检查谁在引用它 |
| 混合引用锁反了 | $A2 与 A$2 搞混 | $ 在谁前面就锁谁：$A2 锁列 A，A$2 锁行 2；乘法表行标题锁列、列标题锁行 |
