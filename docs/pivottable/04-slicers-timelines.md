# 切片器与日程表：点一点就换口径

- **所属栏目**：C08 数据透视表 ／ C08-L2-4 切片器与日程表
- **适用版本**：Excel 2016／2019／2021／365（切片器／日程表需 2013+）
- **难度**：进阶
- **预计阅读时长**：25 分钟
- **更新日期**：2026-11-10

## 1. 学习目标

学完本篇，你将能够：
- 插入切片器并用按钮筛选透视表，调整列数与样式
- 插入日程表并按年、季度、月、日切换时间段
- 用报表连接让一个切片器联动多张透视表，并说出联动的前提条件

## 2. 基础概念

### 2.1 切片器：可视化筛选按钮

切片器是透视表的可视化筛选器：一排可点击的按钮，点选即筛选，比下拉框直观，适合做仪表盘与汇报。入口：点透视表，“数据透视表分析”→“插入切片器”→勾选字段（如“产品类别”）。生成后点按钮即筛选，点“清除筛选”恢复全部。

### 2.2 日程表（时间线）：日期专用筛选器

日程表专门用于日期字段：点透视表，“数据透视表分析”→“插入日程表”→勾选日期字段，拖动滑块筛选时间段；可按年／季度／月／日切换粒度。比切片器更适合时间筛选。

### 2.3 切片器与日程表的区别

| 工具 | 适用字段 | 操作方式 | 典型场景 |
|---|---|---|---|
| 切片器 | 任意字段（类别、销售员、区域） | 点选按钮 | 汇报时切换区域、产品类别 |
| 日程表 | 只用于日期字段 | 拖滑块、切换粒度 | 月报仪表盘拖月份 |

月报仪表盘两者常一起用：切片器选区域，日程表拖月份。

### 2.4 多表联动：一个切片器控制多张表

一个切片器可以同时控制**多个**透视表：右键切片器→“报表连接”，勾选其他透视表——做联动仪表盘的核心技巧。联动前提是多张透视表基于同一数据源（或同一数据模型）。日程表同样可以联动多张透视表，做法相同。

### 2.5 切片器的外观：列数与样式

切片器可以调列数（按钮排几列）、调高度（一次显示几个按钮）、换样式（切片器工具→选项里的配色）。按钮太多放不下时，调列数为 3–4 列比拉高更省地方；仪表盘上的切片器建议统一配色，与图表配色一致。

## 3. 操作步骤

1. 插切片器：点透视表，“数据透视表分析”→“插入切片器”，勾选字段，确定。
2. 点按钮即筛选；点切片器右上角“清除筛选”恢复全部。
3. 调外观：选中切片器，调列数与高度，换一套样式。
4. 联动多表：右键切片器→“报表连接”，勾选其他透视表，确定。
5. 插日程表：点透视表，“数据透视表分析”→“插入日程表”，勾选日期字段。
6. 拖滑块选时间段，点年／季度／月／日切换粒度。
7. 联动检查：联动不生效时，先确认两张透视表基于同一数据源。

## 4. 图文示例

以练习数据文件（数据-透视表练习数据.xlsx，销售明细 500 行，总金额 20957073）为例：

- 销售员切片器点“王芳”，透视表只显示她的 89 笔、4214138 元，占总销售额 20.11%（4214138 / 20957073 = 20.11%）；点“清除筛选”回到 500 笔、20957073 元。

- 报表连接：区域透视表与产品透视表基于同一张源表，右键切片器→“报表连接”勾选另一张，点“华南”两张表同时只剩华南（5452113 元）。

## 5. 公式和代码

切片器与日程表没有公式要写，核对靠透视表外的引用：

```excel
=GETPIVOTDATA("金额", $A$3, "销售员", "王芳") → 4214138
```

切片器点“王芳”后，在透视表外用 GETPIVOTDATA 取王芳的金额汇总，应为 4214138；点“清除筛选”后同一公式取到的是总计 20957073。公式跟着切片器走，是核对联动是否生效的办法。

```excel
=4214138 / 20957073 → 20.11%
```

王芳占总销售额的比例：4214138 / 20957073 = 20.11%。

## 6. 实际工作场景

### 6.1 汇报仪表盘：切片器+日程表联动

月度经营会仪表盘：顶部放区域切片器与月份日程表，下面两张透视表（一张按区域、一张按产品类别）加一张透视图。开会时点“华南”、拖到“2026-Q1”，三张图一起变，不用逐张筛选。会前检查报表连接：两张透视表必须基于同一数据源，否则“报表连接”里不出现对方。

### 6.2 销售复盘：个人业绩一点即看

8 个销售员的业绩表，插销售员切片器：点名字即时看个人（王芳 4214138 元、89 笔第一），点全部回总览。复盘时不用翻筛选下拉，点一点就能换人，适合投屏汇报。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 切片器不能联动另一张透视表 | 两张透视表数据源不同，“报表连接”里不出现对方 | 联动要求同一数据源（或同一数据模型）；基于同一张源表重建两张透视表再联动 |
| 日程表插不出来 | 日期字段不是真日期（如文本型日期） | 先把文本型日期用“数据”→“分列”转成真正的日期，再插日程表 |
| 切片器按钮太多放不下 | 一列排到底，高度不够 | 调列数为 3–4 列；或把不常用的项先筛掉再插切片器 |
| 点切片器后透视表没变 | 切片器连的是另一张透视表 | 右键切片器→“报表连接”，确认勾选了当前这张表 |
| 刷新后切片器选项少了 | 源数据里某项没了（如某销售员离职） | 刷新后切片器自动去掉消失的项；想保留全部项，在切片器设置里改 |
| 日程表拖到某月是空的 | 该月本来就没有数据 | 先看透视表月度趋势：练习数据 2026 年只有 1–9 月，拖到 10 月自然是空的 |
