# 样式与主题：单元格样式、套用表格格式与主题配色

- **所属栏目**：C02 单元格与表格格式 ／ C02-L2-4 样式与主题
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：入门
- **预计阅读时长**：12 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 用内置单元格样式一键套用标题、强调、好/差等语义格式
- 用套用表格格式快速生成带隔行变色的表格
- 新建自定义单元格样式并在全工作簿复用
- 换主题一键改全表的配色与字体，并理解主题色的联动规则

## 2. 基础概念

**单元格样式**：开始→单元格样式，内置"标题"、"强调"、"好"（绿底）、"差"（红底）、"适中"（黄底）等语义样式。点一下即套用一整套字体、填充与边框，比逐项点工具栏快；语义样式还能让"好/差"一眼可辨。

**套用表格格式**：选一个样式，一键生成带表头色、隔行变色、首列加粗的表格。它只刷格式，不带筛选功能；想要筛选与结构化引用，改用 `Ctrl + T` 创建超级表（见下一篇）。

**自定义样式**：开始→单元格样式→新建单元格样式，把"公司红标题"存成样式，全工作簿点一下即用。样式存在工作簿里，换电脑、发给别人都跟着走。

**主题**：页面布局→主题，一键换全表的配色方案与字体组合（标题字体＋正文字体）。主题色是联动的：用主题色做的填充与字体，换主题后自动跟着变；用标准色做的则不变。做公司模板时一律用主题色，换 VI 色一次改全套。

## 3. 操作步骤

1. 套语义样式：选中结果格，开始→单元格样式→点"好"/"差"/"适中"；达标绿、超标红，状态一眼可见。
2. 套表格样式：选中数据区，开始→套用表格格式，选一个带隔行变色的样式，勾选"表包含标题"。
3. 新建样式：设置好一个单元格的全部格式，开始→单元格样式→新建单元格样式，起名"公司标题"，以后点一下即用。
4. 换主题：页面布局→主题，选一个主题；再点"颜色"可只换配色、点"字体"可只换字体组合。
5. 清理样式：开始→单元格样式→右键自定义样式→删除；或选中区域→清除→清除格式，回到常规格式。

## 5. 公式和代码

```excel
=IF(B2>=90,"好",IF(B2>=60,"适中","差")) → 好（B2=95 时）
=COUNTIF(B2:B6,">=90") → 2（B2:B6 是 95、88、92、58、76 时）
```

- `=IF(B2>=90,"好",IF(B2>=60,"适中","差"))` → 好：B2=95 时第一层为真返回"好"；配合单元格样式，好/差/适中三档自动上色
- `=COUNTIF(B2:B6,">=90")` → 2：95 与 92 两个≥90，计数为 2；与"好"样式的格数一致，可互相核对

## 6. 实际工作场景

### 公司统一报表模板

新建样式"公司标题"、"公司表头"、"公司合计"，主题色用公司 VI 蓝。以后每张报表点三下样式即成型，换 VI 时改一次主题色，全公司模板跟着变。

### 考核结果公示表

分数列用 IF 分档＋语义样式（好绿/差红/适中黄），公示时不用逐行解释，颜色即结论。注意色盲友好：同时保留文字档位，不要只靠颜色。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 套用表格格式后筛选箭头没了 | 把"套用表格格式"当成了超级表 | 套用表格格式只刷格式；要筛选与结构化引用用 Ctrl + T 创建超级表 |
| 换主题后部分颜色没变 | 那些颜色用的是标准色而非主题色 | 做模板时一律用主题色；标准色不参与主题联动 |
| 样式越用越乱 | 自定义样式起名随意、无人维护 | 样式名写清用途（如"公司标题-16号蓝"），定期清理无用样式 |
| 语义样式只靠颜色传达信息 | 色盲用户无法区分红绿 | 颜色之外保留文字（好/差/及格），不要只用颜色做唯一信号 |

## 9. 练习题

1. B2:B6 是 95、88、92、58、76，=COUNTIF(B2:B6,">=90") 的结果是多少？哪两个数被数进去了？
2. 套用表格格式与 Ctrl + T 创建超级表有什么区别？
3. 为什么做公司模板要用主题色而不是标准色？

1. 结果 2，数进去的是 95 与 92。88、58、76 都小于 90。

2. 前者只刷格式（边框、隔行色），不带筛选与结构化引用；后者是结构化表格，带筛选箭头、汇总行与结构化引用。

3. 主题色随主题联动：换一次主题色，全表用主题色的地方自动跟着变；标准色不变，换 VI 时要逐格改。
