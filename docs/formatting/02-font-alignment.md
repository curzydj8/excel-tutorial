# 字体与对齐：字号颜色、对齐缩进与自动换行

- **所属栏目**：C02 单元格与表格格式 ／ C02-L2-2 字体与对齐
- **适用版本**：Excel 2016／2019／2021／365
- **难度**：入门
- **预计阅读时长**：15 分钟
- **更新日期**：2026-11-09

## 1. 学习目标

学完本篇，你将能够：
- 用字体、字号、颜色与加粗区分标题、表头与数据
- 用水平/垂直对齐与缩进让表格对齐整齐
- 用自动换行与合并居中处理长文本标题
- 用格式刷快速复制格式而不复制内容

## 2. 基础概念

**字体三要素**：字体、字号、颜色。报表惯例：标题 16 号加粗、表头 11 号加粗配填充色、数据 11 号常规。同一张表字体不超过两种，字号不超过三个档次，否则显乱。

**对齐**：水平对齐分左对齐（文本默认）、居中、右对齐（数值默认）；垂直对齐分靠上、居中、靠下。数字右对齐、文本左对齐、标题居中，是表格的默认美学；跨列居中（设置单元格格式→对齐→水平对齐→跨列居中）能让标题居中又不破坏数据区结构，比合并单元格更安全。

**缩进**：增加缩进量可以把层级关系可视化（如"销售部"下一级"华东区"缩进一格），比用空格对齐可靠——空格缩进在换字体后会错位。

**自动换行**：长文本超出列宽时，自动换行让它在格内折成多行显示，同时行高自动撑高；配合"缩小字体填充"可在不换行时把字缩到能放下。两者不要同时开。

**格式刷**：选中带格式的格点格式刷，再点目标格，只刷格式不刷内容；双击格式刷可连续刷多个区域，按 Esc 退出。格式刷是"复制格式"最快的方式，比逐项点工具栏快一个数量级。

## 3. 操作步骤

1. 设标题：选中标题行，字号 16、加粗、居中；表头行字号 11、加粗、填充浅灰、居中。
2. 调对齐：选中数据区，开始→对齐方式组，数值列点右对齐、文本列点左对齐；标题行点"合并后居中"或改用"跨列居中"。
3. 长文本换行：选中长文本列，开始→自动换行；行高不够时双击行号下边界自适应行高。
4. 缩进层级：选中下级行，开始→增加缩进量（每点一次缩进一格）。
5. 复制格式：选中样板格，点格式刷（双击可连续用），再刷目标区域；完成后按 Esc 退出。
6. 检查：按 `Ctrl + End` 看全表，确认没有字体混用、没有某列突然左对齐/右对齐不一致。

## 4. 图文示例

## 5. 公式和代码

```excel
=SUM(C2:C6) → 4860（C2:C6 是 1200、980、1500、640、540 时）
=C2/SUM($C$2:$C$6) → 24.69%（C2=1200 时）
```

- `=SUM(C2:C6)` → 4860：1200+980+1500+640+540=4860；格式不影响求和，只影响显示
- `=C2/SUM($C$2:$C$6)` → 24.69%：1200÷4860≈0.2469，显示为百分比两位小数 24.69%

## 6. 实际工作场景

### 给领导看的周报

标题 16 号加粗、表头浅灰加粗、金额右对齐货币格式、关键合计行加粗并加顶边框。领导 10 秒扫完要能抓住总额与最大项——格式就是信息的优先级。

### 接手同事的乱表

字体五花八门时：全选→字体统一为等线 11 号→清除多余加粗与颜色→表头单独加粗加填充。先统一再局部强调，比逐格改快。

## 7. 常见错误

| 错误现象 | 原因 | 解决方案 |
|---|---|---|
| 标题用合并单元格后无法排序 | 合并破坏了矩形数据区 | 标题行用"跨列居中"代替合并；数据区绝不合并 |
| 自动换行开了但行高没撑起来 | 行高被手动固定过 | 双击行号下边界自适应行高，或选中行→开始→格式→自动调整行高 |
| 格式刷刷完内容也被复制了 | 用了复制粘贴而不是格式刷 | 格式刷只刷格式；粘贴时想只粘格式用选择性粘贴→格式 |
| 数字左对齐、文本右对齐显得乱 | 对齐方式与数据类型不匹配 | 数值右对齐、文本左对齐、标题居中；整列统一改，不要逐格点 |
