# Excel 教程大全

从入门到精通：函数大全 · VBA 编程 · 高级方法。

## 目录

### 📊 函数大全（`docs/functions/`）
| 分类 | 内容 |
|------|------|
| 数学函数 | SUM/AVERAGE/ROUND/INT/RAND 等 |
| 文本函数 | LEFT/RIGHT/MID/CONCAT/TEXT 等 |
| 日期时间 | TODAY/NOW/DATEDIF/EOMONTH 等 |
| 逻辑函数 | IF/AND/OR/NOT/IFS 等 |

- 基础语法：变量/循环/条件/数组
- 对象模型：Application/Workbook/Worksheet/Range
- 关键字大全：Dim/Set/If/For/While 等
- 实战实例：批量处理/自动报表

### 🚀 高级方法（`docs/advanced/`）
- 数据透视表、数组公式、Power Query
- 条件格式、数据验证、快捷键大全
